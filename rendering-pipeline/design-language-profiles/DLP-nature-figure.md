## 1. name

`DLP-nature-figure`

## 2. anchor

`"Nature 期刊配图规范 2024"`

锚定《Nature》期刊 2024 年版配图规范。Nature 对配图有极其严格的要求：矢量图输出（SVG/PDF）、印刷级分辨率（300dpi+）、Arial 字体最小 7pt、子图标注 a/b/c 加粗、图注位于图下方、颜色无障碍友好。Nature 配图是全球学术出版界的最高标准之一，其规范被广泛引用为学术配图的黄金准则。

**字号使用规则**：
- 图标题位于图上方或下方，常规（400），8pt
- 子图标题（a/b/c 标注）位于子图左上角，**加粗（700）**，7pt
- 图注位于图下方，常规（400），7pt，包含图表说明和数据来源
- 数据标签和刻度标签，常规（400），6pt（最小字号）

**Nature 最小字号规则**：Nature 规定配图中所有文字最小字号为 7pt（约 9.33px），刻度标签等次要文字可至 6pt（约 8px），但不得低于 6pt。

## 融入内容：Scientific Visualization

> **来源技能**: Scientific Visualization
> **融入形式**: Nature/Science 绘图规范

### Nature/Science 绘图核心规范

1. **矢量图输出（SVG/PDF）**：Nature 强制要求配图以矢量格式提交（SVG/PDF/EPS），确保在任何缩放级别下均保持锐利。位图（PNG/TIFF）仅适用于照片类配图，且分辨率不得低于 300dpi。矢量图是学术出版的黄金标准——可缩放、可编辑、印刷级清晰。

2. **印刷级分辨率（300dpi+）**：对于必须使用位图的场景（如显微镜照片、卫星图像），分辨率不得低于 300dpi。Nature 推荐使用 600dpi 以确保最高印刷质量。线宽和字号在 300dpi 下必须清晰可辨。

3. **Arial 字体 7pt 最小字号**：Nature 规定配图中所有文字必须使用 Arial 或 Helvetica 字体，最小字号 7pt（约 9.33px）。刻度标签等次要文字可至 6pt（约 8px），但不得低于 6pt。禁止使用 Times New Roman 等衬线字体作为配图标签字体。

4. **子图标注 a/b/c 加粗**：多子图组合时，每个子图左上角必须标注小写字母 a/b/c（加粗，7pt），用于正文引用（如"如图 1a 所示"）。子图标注必须加粗（bold/700），这是 Nature 的强制规范。

5. **图注在图下方**：图注必须位于图表下方，包含以下结构：
   - 图标题（简短描述）
   - 详细说明（数据来源、实验条件、统计方法）
   - 缩写定义（首次出现的缩写必须全称定义）
   - 数据来源标注

6. **颜色无障碍友好**：Nature 要求配图颜色必须通过色盲友好测试。推荐使用 ColorBrewer 或 Wong's color palette 等无障碍色板。对于需要更高区分度的场景，应辅以线型差异（实线/虚线/点线）或标记差异（圆形/方形/三角形），而非仅依赖颜色区分。

### Nature 配图尺寸规范

| 图表类型 | 宽度 | 适用场景 |
|---------|------|---------|
| 单栏图 | 89mm | 单列数据图、简单折线/柱状图 |
| 双栏图 | 183mm | 多子图组合、热力图、机制图 |
| 全页图 | 183mm x 247mm | 大型多子图组合、流程图 |

### Nature 配图分辨率规范

| 输出格式 | 分辨率 | 适用场景 |
|---------|--------|---------|
| 矢量图（SVG/PDF/EPS） | 无限 | 线图、柱状图、散点图、机制图 |
| TIFF | 300dpi+ | 照片类配图、复合图 |
| PNG | 300dpi+ | 屏幕展示用位图 |

### 禁止事项

- 禁止使用低分辨率位图（< 300dpi）
- 禁止使用非矢量格式提交线图
- 禁止使用衬线字体作为配图标签字体
- 禁止字号低于 6pt
- 禁止子图标注不加粗
- 禁止图注位于图上方
- 禁止使用未通过色盲测试的配色
- 禁止使用 3D 效果
- 禁止使用渐变填充

## 融入内容：PaperBanana Skill

> **来源技能**: PaperBanana Skill
> **融入形式**: 5智能体流水线 + 低饱和专业色系

### PaperBanana 5智能体流水线规范

PaperBanana Skill 采用 5 智能体流水线协作模式生成学术配图，每个智能体承担明确职责，确保配图从需求分析到最终交付的全流程质量可控：

| 智能体序号 | 智能体名称 | 职责描述 | 输入 | 输出 |
|-----------|-----------|---------|------|------|
| 1 | analyze（分析智能体） | 解析配图需求：识别图表类型（机制图/数据图/照片）、目标期刊规范、数据结构、关键信息层级 | 配图需求文本 + 数据源 | 配图需求规格书（含图表类型、尺寸、配色、字体约束） |
| 2 | plan（规划智能体） | 制定配图布局方案：确定子图组合方式、元素排布、标注位置、图注结构、留白分配 | 配图需求规格书 | 配图布局蓝图（含栅格规划、元素坐标、标注方案） |
| 3 | generate（生成智能体） | 执行配图渲染：按布局蓝图生成矢量图（SVG/PDF），应用配色、字体、线宽规范，渲染数据系列与标注 | 配图布局蓝图 + DLP 规范 | 初版配图（矢量格式） |
| 4 | review（审查智能体） | 质量审查：检查字号是否≥7pt、子图标注是否加粗、配色是否通过色盲测试、图注是否位于图下方、分辨率是否≥300dpi | 初版配图 + Nature 规范检查清单 | 审查报告（含问题清单与修正建议） |
| 5 | refine（精修智能体） | 精修定稿：按审查报告修正所有问题，微调间距/线宽/对齐，输出最终交付版（矢量图 + 高分辨率位图） | 初版配图 + 审查报告 | 最终配图（SVG/PDF + TIFF/PNG @300dpi+） |

**流水线执行规则**：
- 5 智能体严格顺序执行，前一智能体输出为后一智能体输入
- review 智能体发现问题后，必须回流至 generate 智能体重新渲染，不得跳过
- refine 智能体输出的最终配图必须通过 review 智能体的二次审查方可交付
- 流水线最多循环 3 轮，3 轮后仍有问题则标记为"需人工介入"

### 低饱和专业色系规范

PaperBanana Skill 强制采用低饱和专业色系，与 Nature 配图的低饱和要求保持一致：

| 色彩参数 | 规范值 | 说明 |
|---------|--------|------|
| 饱和度（Saturation） | 60%-75% | 所有颜色饱和度控制在此区间，禁止高饱和色 |
| 明度（Lightness） | 40%-70% | 确保印刷品中色彩层次清晰 |
| 禁止色相 | 高饱和原色 | 禁止使用 #FF0000（纯红）、#00FF00（纯绿）、#0000FF（纯蓝）等高饱和原色 |
| 推荐色板 | Nature 无障碍色板 | 使用本 DLP 第 4 节定义的 6 色板，所有颜色经色盲模拟测试 |

**低饱和执行规则**：
- 所有生成的配图颜色必须通过饱和度校验（HSL 模型中 S 值 ∈ [60%, 75%]）
- 禁止使用"塑料感"高饱和色（S > 75%），违反则 review 智能体直接打回
- 数据系列区分优先依赖明度差异和线型差异，而非饱和度差异
- 与 Nature 配图规范对接：Nature 要求颜色无障碍友好，低饱和色板在色盲模拟下区分度更稳定

### 全类型学术配图质感统一规则

PaperBanana Skill 强制所有类型学术配图保持统一的视觉质感，无论是机制图、数据图还是照片类配图：

| 配图类型 | 质感统一规则 |
|---------|------------|
| 机制示意图 | 矢量渲染、直角无阴影、Arial 7pt、低饱和色、子图标注 a/b/c 加粗 |
| 数据图（折线/柱状/散点） | 矢量渲染、细轴线 0.75pt、网格线 #E5E5E5 0.5px、数据系列低饱和色 |
| 照片类配图（显微镜/卫星） | 300dpi+ 位图、标注层矢量叠加、标尺线 0.75pt 黑色、标注 Arial 7pt |
| 复合图（多子图组合） | 子图间距 2-4px、子图标注 a/b/c 加粗 7pt、统一图注位于下方 |

**质感统一强制规则**：
- 所有配图必须使用同一字体栈（Arial/Helvetica + 黑体 fallback）
- 所有配图必须使用同一色板（本 DLP 第 4 节 6 色板）
- 所有配图必须使用同一字号阶梯（图标题 8pt / 子图标题 7pt / 图注 7pt / 标签 6pt）
- 所有配图必须使用同一线宽规范（数据线 1.5pt / 轴线 0.75pt / 网格线 0.5px）
- 所有配图禁止圆角、阴影、3D 效果、渐变填充

### PaperBanana 与 Nature 配图规范的对接规则

| 对接维度 | PaperBanana 规范 | Nature 配图规范 | 对接规则 |
|---------|-----------------|----------------|---------|
| 输出格式 | 矢量图（SVG/PDF）优先 | 矢量图强制（线图）/ 300dpi+ 位图（照片） | PaperBanana 默认输出矢量，照片类自动切换 300dpi+ 位图 |

| 配色规范 | 低饱和 60%-75% | 无障碍友好色板 | PaperBanana 低饱和色板即 Nature 推荐色板 |
| 子图标注 | a/b/c 加粗 7pt | a/b/c 加粗 7pt | 完全一致，直接继承 |

### 图形摘要（Graphical Abstract）专用生成规范

Scientific Image Prompting Skill 为 §1 摘要自动生成 1 张图形摘要，遵循以下规范：

| 规范维度 | 规范值 | 说明 |
|---------|--------|------|
| 生成数量 | 1 张/篇 | 每篇论文摘要自动生成 1 张图形摘要 |
| 尺寸 | 183mm × 85mm | Nature 图形摘要标准尺寸（双栏宽 × 固定高） |
| 输出格式 | 矢量格式（SVG/PDF） | 强制矢量，确保缩放锐利；附带 PNG @300dpi 用于预览 |
| 分辨率 | 矢量无限 / 位图 300dpi+ | 矢量优先，位图不低于 300dpi |
| 字体 | Arial 7pt 最小 | 与 Nature 配图字体规范一致 |
| 配色 | 低饱和 6 色板 | 使用本 DLP 第 4 节定义的 Nature 无障碍色板 |
| 内容要求 | 单图概括全文核心 | 用一张图传达论文核心发现、机制或数据结论 |

**图形摘要生成流程**：
1. 解析论文摘要，提取核心发现、关键机制、主要数据结论
2. 规划图形摘要布局（183mm × 85mm 横向画布），确定核心元素排布
3. 生成矢量图形摘要，应用 Nature 配图规范（字体/配色/线宽）
4. 审查图形摘要是否符合 Nature 尺寸和格式要求
5. 输出 SVG/PDF + PNG @300dpi 预览版

**图形摘要禁止事项**：
- 禁止包含正文中的所有数据（仅传达核心结论）
- 禁止使用照片类素材（仅矢量图形）
- 禁止字号低于 7pt
- 禁止使用高饱和色
- 禁止超出 183mm × 85mm 尺寸

### AI提示词工程规范

Scientific Image Prompting Skill 定义学术配图生成的 AI 提示词模板，包含风格约束、分辨率约束、字体约束：

**学术配图提示词模板**：

```
[风格约束]
- 学术出版级配图，Nature 期刊配图规范 2024
- 矢量风格，平面化呈现，禁止 3D 效果和渐变填充
- 低饱和专业色系（饱和度 60%-75%），无障碍友好色板
- 直角无阴影，印刷级平面质感

[分辨率约束]
- 矢量图输出（SVG/PDF），缩放无限锐利
- 位图输出不低于 300dpi（推荐 600dpi）
- 尺寸：单栏图 89mm / 双栏图 183mm / 图形摘要 183mm×85mm

[字体约束]
- Arial 或 Helvetica 无衬线字体
- 最小字号 7pt（刻度标签可至 6pt）
- 子图标注 a/b/c 加粗（bold/700）
- 图注位于图下方，常规（regular/400）

[内容约束]
- {配图类型：机制示意图/数据图/图形摘要}
- {核心元素描述}
- {数据系列与配色}
- {标注与图注内容}
```

**提示词工程规则**：
- 风格约束必须置于首位，确保 AI 生成器优先遵循学术配图规范
- 分辨率约束必须明确数值（300dpi/600dpi），禁止使用"高分辨率"等模糊表述
- 字体约束必须指定具体字体名（Arial/Helvetica），禁止使用"无衬线字体"等泛化表述
- 内容约束必须提供具体的配图类型和元素描述，禁止使用"学术配图"等泛化表述
- 生成的配图必须通过 review 智能体审查，不符合规范则重新生成
