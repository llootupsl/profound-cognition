# Golden Set 距离校验器 — 审美 CI 机制

> **定位**: profound-cognition skill 的 Visual DNA 审美进化项目的审美 CI 机制
> **核心职能**: 防止适配器微调失控，通过多维距离度量判断待校验输出是否偏离 DLP 规范
> **Golden 样本总数**: 48 个（16 DLP × 3 样本/DLP）
> **校验维度**: 配色距离 / 排版距离 / 间距距离 / 语义距离

---

## 一、Golden 样本库定义

每个 DLP 对应 3 个 Golden 样本，共 48 个。每个样本为"满分"渲染输出片段，其关键视觉特征严格锚定对应 DLP 文件的字段值。

## 二、距离度量算法

### 2.1 配色距离（余弦距离）

**算法原理**: 将配色转换为 HSL 空间的向量，计算待校验输出配色向量与 Golden 样本配色向量的余弦距离。

**HSL 向量构造**:
- 将 DLP 的 6 色板（primary / secondary / accent / neutral / background / text）分别转换为 HSL 空间
- 每个颜色转换为 3 维向量 [H, S, L]
- 6 个颜色组成 18 维向量 A = [H₁, S₁, L₁, H₂, S₂, L₂, ..., H₆, S₆, L₆]

**数学公式**:

```
d_color = 1 - cos(θ) = 1 - (A · B) / (|A| × |B|)
```

其中：
- A = 待校验输出的 18 维 HSL 配色向量
- B = Golden 样本的 18 维 HSL 配色向量
- A · B = Σ(Aᵢ × Bᵢ)（向量点积）
- |A| = √(Σ Aᵢ²)（向量模长）
- |B| = √(Σ Bᵢ²)（向量模长）

**HSL 转换规则**:
- H（色相）: 0-360°，归一化到 0-1
- S（饱和度）: 0-100%，归一化到 0-1
- L（亮度）: 0-100%，归一化到 0-1

**距离范围**: [0, 2]
- d_color = 0: 配色完全一致
- d_color = 1: 配色正交（无相关性）
- d_color = 2: 配色完全相反

### 2.2 排版距离（欧氏距离）

**算法原理**: 将字号/字重/行高组成特征向量，计算欧氏距离。

**特征向量构造**:
- 提取 DLP 的 typography_scale 中的 7 个层级（h1/h2/h3/h4/body/caption/footnote）
- 每个层级提取 3 个特征：字号（px）、字重、行高
- 7 个层级组成 21 维特征向量

**数学公式**:

```
d_typo = √(Σ(Aᵢ - Bᵢ)²)
```

其中：
- A = 待校验输出的 21 维排版特征向量 [h1_size, h1_weight, h1_line_height, h2_size, ..., footnote_line_height]
- B = Golden 样本的 21 维排版特征向量
- i = 1, 2, ..., 21（特征维度索引）

**特征归一化**:
- 字号（px）: 归一化到 0-1（除以 72px 最大字号）
- 字重: 归一化到 0-1（除以 900）
- 行高: 归一化到 0-1（除以 3.0）

**距离范围**: [0, +∞)
- d_typo = 0: 排版完全一致
- d_typo 越大: 排版差异越大

### 2.3 间距距离（曼哈顿距离）

**算法原理**: 将外边距/内边距/栅格槽宽组成特征向量，计算曼哈顿距离。

**特征向量构造**:
- 提取 DLP 的 spacing_system 和 grid_system 中的关键间距值
- 特征向量包含：基准间距、页边距、栅格槽宽、段落间距、章节间距、图表间距

**数学公式**:

```
d_space = Σ|Aᵢ - Bᵢ|
```

其中：
- A = 待校验输出的 6 维间距特征向量 [base, margin, gutter, paragraph_spacing, section_spacing, chart_spacing]
- B = Golden 样本的 6 维间距特征向量
- i = 1, 2, ..., 6（特征维度索引）

**特征归一化**:
- 所有间距值（px）: 归一化到 0-1（除以 96px 最大间距）
- cm 单位转换为 px（1cm ≈ 37.8px）
- inch 单位转换为 px（1inch = 96px）

**距离范围**: [0, +∞)
- d_space = 0: 间距完全一致
- d_space 越大: 间距差异越大

### 2.4 语义距离（余弦相似度）

**算法原理**: 将内容主题与 DLP 场景标签转换为词向量，计算余弦相似度。

**词向量构造**:
- 将 DLP 的 applicable_scenarios 场景标签转换为词向量
- 将待校验输出的内容主题关键词转换为词向量
- 使用词袋模型或预训练词向量（如 word2vec / fastText）

**数学公式**:

```
d_semantic = 1 - cos_sim(content, scenario_tags)

cos_sim(content, scenario_tags) = (content · scenario_tags) / (|content| × |scenario_tags|)
```

其中：
- content = 待校验输出内容主题的词向量
- scenario_tags = DLP 场景标签的词向量
- content · scenario_tags = Σ(contentᵢ × scenario_tagsᵢ)（向量点积）
- |content| = √(Σ contentᵢ²)（向量模长）
- |scenario_tags| = √(Σ scenario_tagsᵢ²)（向量模长）

**距离范围**: [0, 2]
- d_semantic = 0: 语义完全一致
- d_semantic = 1: 语义正交（无相关性）
- d_semantic = 2: 语义完全相反

## 三、综合距离计算

### 3.1 加权综合距离公式

```
D_combined = 0.3 × d_color + 0.3 × d_typo + 0.2 × d_space + 0.2 × d_semantic
```

**权重设计依据**:
- 配色距离（0.3）: 配色是 DLP 最高辨识度特征，权重最高
- 排版距离（0.3）: 排版是 DLP 核心规范，权重最高
- 间距距离（0.2）: 间距影响布局质感，权重中等
- 语义距离（0.2）: 语义匹配影响 DLP 选择正确性，权重中等

### 3.2 多样本最小距离策略

待校验输出与同 DLP 的 3 个 Golden 样本分别计算综合距离，取最小值作为最终校验距离：

```
D_final = min(D_combined(output, GS-xxx-01), D_combined(output, GS-xxx-02), D_combined(output, GS-xxx-03))
```

**最小距离策略依据**:
- 3 个 Golden 样本覆盖同一 DLP 的不同渲染场景（如首页/图表/参考文献）
- 取最小距离确保待校验输出只要与任一 Golden 样本足够接近即可通过
- 避免因场景差异导致的误判

### 3.3 距离归一化

各维度距离在计算综合距离前需归一化到 [0, 1] 区间：

```
d_color_normalized = d_color / 2
d_typo_normalized = min(d_typo / 10, 1)
d_space_normalized = min(d_space / 10, 1)
d_semantic_normalized = d_semantic / 2
```

归一化后的综合距离：

```
D_combined = 0.3 × d_color_normalized + 0.3 × d_typo_normalized + 0.2 × d_space_normalized + 0.2 × d_semantic_normalized
```

## 四、阈值判定

### 4.1 三级判定机制

| 综合距离范围 | 判定结果 | 处理策略 |
|-------------|---------|---------|
| D < 0.3 | PASS（通过） | 输出符合 DLP 规范，正常交付 |
| 0.3 ≤ D ≤ 0.5 | WARN（警告） | 允许通过但标记"需关注"，建议优化 |
| D > 0.5 | FAIL（失败） | 拒绝输出，触发重试机制 |

### 4.2 阈值设计依据

- **PASS 阈值 0.3**: 综合距离低于 0.3 表示待校验输出与 Golden 样本高度一致，配色/排版/间距/语义四维度均接近 DLP 规范，可放心交付
- **WARN 阈值 0.3-0.5**: 综合距离在 0.3-0.5 之间表示待校验输出与 Golden 样本有适度偏差，但仍在可接受范围内，允许通过但标记"需关注"以便后续优化
- **FAIL 阈值 0.5**: 综合距离超过 0.5 表示待校验输出与 Golden 样本偏差过大，可能已偏离 DLP 规范，必须拒绝并触发重试

### 4.3 重试机制

当判定结果为 FAIL 时，触发重试机制：
1. **第一次重试**: 调整待校验输出的配色/排版/间距参数，使其更接近 Golden 样本
2. **第二次重试**: 如果第一次重试仍 FAIL，进一步强制对齐 DLP 的 design_tokens
3. **最终失败**: 如果两次重试后仍 FAIL，报告"审美 CI 失败"，需要人工介入
