# 语义自动识别规则 (Semantic Auto-Detect Rules)

> **定位**: 渲染管道的内容解析层，自动识别文本段落语义类型，触发对应的可视化渲染。
> **输入**: 已完成的正文内容（来自 T22-T26 综合叙事）
> **输出**: 标注了语义类型的段落映射表，供渲染器消费

---

## 方法论原理

语义自动检测基于"内容语义决定呈现形式"的认知假设：不同语义类型的内容（数据、流程、概念、叙事）需要不同的视觉表达方式。通过自动识别段落的语义类型，为渲染管道提供结构化的类型标注，使后续的布局选择、动效匹配、容器渲染能够基于语义而非格式做出设计决策。

---

## 一、通用规则

### 1.1 识别流程
```
正文内容 → 逐段扫描 → 正则匹配 → 语义类型标注 → 渲染指令生成
```

### 1.2 优先级
当一段落同时匹配多个规则时，按以下优先级裁决：
1. 标题段检测 > 2. 数据段检测 > 3. 流程段检测 > 4. 概念段检测

### 1.3 位置嵌入规则
- 图表紧接对应段落之后（不插入段落中间打断阅读流）
- 图表编号格式：`图{章节号}-{序号}`（如 `图2-3`）
- 图表与前后段落保持 1 个空行间距

## 二、数据段检测 → 自动生成图表

### 2.1 触发模式

| 模式类型 | 正则/关键词 | 置信度 | 渲染指令 |
|---------|------------|--------|---------|
| 百分比序列 | `\d{1,3}(\.\d{1,2})?%[\s\S]*?\d{1,3}(\.\d{1,2})?%` (同一段出现 ≥2 个百分比) | HIGH | 柱状图/条形图 |
| 数值对比 | `\d+[\s\S]*?(相比|比|较|高出|低于|增长|下降|增加|减少)` | HIGH | 对比柱状图 |
| 时间序列 | `\d{4}年[\s\S]*?\d{4}年` (同一段出现 ≥2 个年份) | HIGH | 折线图/面积图 |
| 占比描述 | `(占比|占|比例|份额|构成|分布)[\s\S]*?\d{1,3}(\.\d{1,2})?%` | MEDIUM | 饼图/环形图 |
| 统计表关键词 | `(如表|下表|统计|数据来源|调查显示|数据显示|据统计)` | HIGH | 表格 |
| 排名描述 | `(排名|位列|第[一二三四五六七八九十\d]+位|TOP|前三|前五)` | MEDIUM | 排行榜条形图 |
| 相关性描述 | `(相关性|相关系数|正相关|负相关|r\s*=|R²|p\s*<)` | HIGH | 散点图/气泡图 |
| 分布描述 | `(分布|正态|偏态|中位数|四分位|标准差|方差)` | MEDIUM | 箱线图/直方图 |

### 2.2 渲染管线
```
数据段识别 → 数据提取（数值/标签/单位） → 选择图表类型
  → 注入 visual_dna.color_scheme → 生成图表代码（ECharts/Plotly/Observable-Plot）
  → 嵌入对应段落后
```

### 2.3 示例
```
输入文本:
"2023年全球AI市场规模为5000亿美元，2024年增长至6500亿美元，预计2025年将达到8500亿美元。"

识别结果:
  - type: "data_chart"
  - chart_type: "line_chart"
  - data: {2023: 5000, 2024: 6500, 2025: 8500}
  - unit: "亿美元"
  - label: "全球AI市场规模"
```

## 三、流程段检测 → 自动生成流程图

### 3.1 触发模式

| 模式类型 | 正则/关键词 | 置信度 | 渲染指令 |
|---------|------------|--------|---------|
| 步骤序号 | `(第[一二三四五六七八九十\d]+步\|步骤[一二三四五六七八九十\d]+\|Step\s*\d+\|首先.*其次.*最后)` | HIGH | 流程框图 |
| 时序词 | `(首先\|然后\|接着\|随后\|最后\|最终\|最初\|之后\|此前)` (同一段出现 ≥2 个) | HIGH | 时间线/流程图 |
| 箭头指示 | `(→\|->\|→\|➔)` 或 `(流向\|传递\|传导\|转换\|演变)` | HIGH | 箭头流程图 |
| 阶段描述 | `(第一阶段\|第二阶段\|初期\|中期\|后期\|起步\|成熟\|衰退)` | MEDIUM | 阶段流程图 |
| 循环描述 | `(循环\|反馈\|闭环\|往复\|迭代\|回路)` | MEDIUM | 循环图 |
| 决策分支 | `(如果\|若\|当.*时\|否则\|反之\|取决于)` | MEDIUM | 决策树/分支图 |
| 层级递进 | `(一级\|二级\|三级\|层次\|深度\|层层)` | MEDIUM | 层级图 |

### 3.2 渲染管线
```
流程段识别 → 节点提取（步骤/阶段/决策点） → 连线提取（顺序/分支/循环）
  → 选择图表类型 → 生成 Mermaid/PlantUML 代码
  → 嵌入对应段落后
```

### 3.3 示例
```
输入文本:
"首先，用户输入查询关键词。然后，系统进行语义解析和意图识别。接着，搜索引擎检索相关文档。最后，排序模型对结果进行重排并返回。"

识别结果:
  - type: "flowchart"
  - nodes: ["用户输入查询", "语义解析与意图识别", "检索相关文档", "排序重排与返回"]
  - edges: sequential (1→2→3→4)
  - direction: "TB" (top to bottom)
```

## 四、概念段检测 → 自动生成概念图

### 4.1 触发模式

| 模式类型 | 正则/关键词 | 置信度 | 渲染指令 |
|---------|------------|--------|---------|
| 定义句式 | `(是指\|指的是\|定义为\|即\|所谓.*是指\|被称为)` | HIGH | 概念卡片/定义框 |
| 分类列表 | `(分为.*类\|包括.*种\|有以下.*类型\|可归为\|按.*可分为)` | HIGH | 分类树/思维导图 |
| 层级关键词 | `(属于\|包含\|由.*组成\|分为\|下属\|上层\|底层\|顶层)` | MEDIUM | 层级图/组织图 |
| 对比句式 | `(与.*不同\|相比.*而言\|区别在于\|不同于\|区别于)` | MEDIUM | 对比表/维恩图 |
| 因果关系 | `(因为\|所以\|由于\|导致\|引起\|造成\|源于\|归因于)` | HIGH | 因果图/鱼骨图 |
| 组成关系 | `(由.*构成\|包括.*部分\|组成部分\|构成要素\|关键要素)` | MEDIUM | 组成图/饼图 |
| 类比描述 | `(好比\|如同\|类似于\|就像\|仿佛\|相当于)` | MEDIUM | 类比示意图 |

### 4.2 渲染管线
```
概念段识别 → 概念实体提取 → 关系提取（包含/因果/对比/类比）
  → 选择图表类型 → 生成 Markmap/Mermaid/概念图 代码
  → 嵌入对应段落后
```

### 4.3 示例
```
输入文本:
"人工智能可分为三个主要分支：符号主义AI（基于逻辑推理）、连接主义AI（基于神经网络）和行为主义AI（基于感知-行动循环）。"

识别结果:
  - type: "concept_map"
  - root: "人工智能"
  - children: ["符号主义AI（逻辑推理）", "连接主义AI（神经网络）", "行为主义AI（感知-行动循环）"]
  - visual_type: "mindmap" (Markmap)
```

## 五、标题段检测 → 自动生成封面

### 5.1 触发模式

| 模式类型 | 正则/关键词 | 置信度 | 渲染指令 |
|---------|------------|--------|---------|
| Markdown H1 | `^#\s+.+` | HIGH | 封面标题 |
| Markdown H2 | `^##\s+.+` | HIGH | 章节页标题 |
| 章节声明 | `(第[一二三四五六七八九十\d]+章\|Chapter\s*\d+\|Part\s*\d+)` | HIGH | 章节封面 |
| 封面句式 | `(研究报告\|深度分析\|白皮书\|年度报告\|关于.*的研究)` | MEDIUM | 封面生成 |
| 摘要/引言 | `^(摘要\|Abstract\|引言\|前言\|概述\|背景)` | MEDIUM | 特殊排版（摘要框） |

### 5.2 渲染管线
```
标题段识别 → 标题层级判定 → 提取标题文本 + 副标题/作者/日期
  → 注入 visual_dna.color_scheme + font_scheme
  → 生成封面页/章节页 HTML/CSS
```

### 5.3 示例
```
输入文本:
"# 全球人工智能治理框架深度研究报告"
"## 第一章 技术演进与治理挑战"

识别结果:
  - [0] type: "cover_page", title: "全球人工智能治理框架深度研究报告", level: "H1"
  - [1] type: "chapter_page", title: "第一章 技术演进与治理挑战", level: "H2"
```

## 六、段落类型映射表

| 段落类型 | 渲染组件 | 生成的图表类型 | 优先级 |
|---------|---------|--------------|--------|
| `title` | 封面/章节页 | — | 1 |
| `data_chart` | 数据图表 | 柱状图/折线图/饼图/散点图/表格 | 2 |
| `flowchart` | 流程图 | 流程框图/时间线/决策树/循环图 | 3 |
| `concept_map` | 概念图 | 思维导图/分类树/因果图/对比表 | 4 |
| `body` | 正文段落 | — | 5 |
| `quote` | 引用块 | — | 6 |
| `code` | 代码块 | — | 7 |
| `table` | 表格 | — | 8 |
| `image` | 图片 | — | 9 |

---

## 七、强制规则

1. **逐段扫描**: 渲染前必须对整个文档逐段执行语义识别，不得跳过任何段落。
2. **图表紧接段落**: 生成的图表必须紧接触发段落之后，不得插入段落中间或跨段落远距离放置。
3. **置信度过滤**: 仅 `HIGH` 和 `MEDIUM` 置信度的匹配触发渲染；`LOW` 置信度匹配仅记录日志，不渲染。
4. **去重规则**: 同一段落若触发多个渲染指令，仅保留优先级最高的一条。
5. **连续段落合并**: 连续 2 段以上触发同一类型图表时，合并为 1 张复合图表，避免图表碎片化。

## 穷尽重试策略

### 穷尽尝试完整语义检测
自动识别4种段落类型（数据/流程/概念/标题）+ 子类型细分

### 置信度不足时穷尽尝试替代检测方案
- 置信度<0.7的段落标记为content（通用类型）
- 仅对高置信度段落应用语义驱动渲染
- 低置信度段落使用默认布局

### 语义检测不可用时穷尽尝试替代方案
- 所有段落标记为content
- 使用通用布局规则
- 禁用语义驱动的动效和容器选择

### 检测系统不可用时穷尽尝试格式驱动检测
- 穷尽尝试格式驱动检测（基于Markdown语法标记）
- 标题→heading, 列表→list, 代码→code, 其他→content
