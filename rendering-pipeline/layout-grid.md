# 统一栅格排版系统 (Unified Layout Grid System)

> **定位**: 渲染管道的空间布局引擎，所有输出形态（PPT/Word/PDF/MD/长图/手机）共用同一套 12 列栅格系统，仅通过页面尺寸和分栏数切换形态。
> **统一规则**: 不分 PPT/Word/PDF/MD，同一套栅格系统，仅通过页面尺寸和分栏数切换形态。

---

## 方法论原理

栅格布局系统基于"结构化空间分配提升信息获取效率"的设计理论：通过将页面划分为等宽列和固定间距，建立可预测的视觉节奏，降低读者的认知负荷。12列栅格系统提供2/3/4/6的整除灵活性，适配从单栏到多栏的多样化布局需求，同时保持视觉一致性。

## 一、12 列栅格系统

### 1.1 栅格定义

| 参数 | 值 | 说明 |
|------|-----|------|
| 总列数 | 12 | 标准 12 列栅格 |
| 列宽 | 自适应（总宽 - 总间距）/ 12 | 每列等宽 |
| 列间距 (gutter) | 16px (4×4px) | 列与列之间的间距 |
| 最小列宽 | 48px | 单列最低宽度保护 |

### 1.2 列占用规则

| 占用列数 | 占比 | 典型用途 |
|---------|------|---------|
| 12/12 | 100% | 全宽标题、封面、大图、全宽表格 |
| 8/12 | 66.7% | 主内容区、正文 |
| 6/12 | 50% | 双栏对比、图文并排 |
| 4/12 | 33.3% | 三栏卡片、指标面板、侧边栏 |
| 3/12 | 25% | 四栏数据卡片、图标网格 |
| 2/12 | 16.7% | 六栏标签、小图标组 |

### 1.3 列偏移规则

| 偏移量 | 用途 |
|--------|------|
| offset-1 | 轻微缩进内容 |
| offset-2 | 引用块、注释块 |
| offset-3 | 居中的窄内容（6/12 宽 + offset-3） |

### 3.2 页面尺寸切换逻辑

```
输入: output_type + target_medium
  ↓
查询页面尺寸表 → 确定 width/height
  ↓
栅格系统自动适配: 列宽 = (width - 2×margin - 11×gutter) / 12
  ↓
分栏规则自动应用
```

## 五、响应式断点

### 5.1 断点定义

| 断点名 | 最小宽度 | 最大宽度 | 分栏策略 |
|--------|---------|---------|---------|
| xs (手机) | 0 | 575px | 1 栏全宽 |
| sm (大手机/小平板) | 576px | 767px | 1 栏全宽 |
| md (平板) | 768px | 991px | 最多 2 栏 |
| lg (桌面) | 992px | 1199px | 最多 3 栏 |
| xl (大桌面) | 1200px | — | 最多 4 栏 |

### 5.2 断点切换规则

- 当视口宽度 < 768px 时，所有多栏布局强制折叠为 1 栏全宽
- 当视口宽度 < 576px 时，页面边距减半（左右边距各 16px）
- 表格在 xs 断点下启用横向滚动，不强制折叠

## 六、栅格系统 CSS 变量

```css
:root {
  /* 栅格基础 */
  --grid-columns: 12;
  --grid-gutter: 16px;
  --grid-min-column: 48px;

  /* 页面尺寸（根据输出形态动态设置） */

  --page-margin-top: 20mm;
  --page-margin-bottom: 20mm;
  --page-margin-left: 25mm;
  --page-margin-right: 25mm;

  /* 间距 */
  --spacing-para: 16px;
  --spacing-heading-top: 32px;
  --spacing-heading-bottom: 16px;
  --spacing-image: 24px;
  --spacing-list-item: 8px;

  /* 内边距 */

  --padding-blockquote: 16px 24px;

  --padding-table-cell: 12px 16px;
  --padding-button: 8px 20px;

```

## 七、强制规则

1. **统一栅格**: 所有输出形态共用同一套 12 列栅格系统，不得为不同形态单独定义栅格。
2. **尺寸切换**: 页面尺寸切换时仅修改 `--page-width` / `--page-height` 及相关 margin 变量，栅格逻辑不变。
3. **4px 基准**: 所有间距值必须是 4px 的整数倍，确保像素对齐。
4. **分栏自动适配**: 多栏布局在窄屏下自动折叠为 1 栏，不需要手动干预。
5. **栅格不可覆盖**: 任何渲染模块不得绕过栅格系统使用绝对定位或硬编码坐标。

## DLP grid_system 字段对接

栅格列数/槽宽/边距优先使用 DLP 规范：

### 优先级规则
1. 若 DLP 的 grid_system 字段已定义列数/槽宽/边距，优先使用 DLP 值
2. 若 DLP 未定义，回退到本文档的默认 12 列栅格
3. 若 LA 原子库有更匹配的栅格原子，使用 LA 原子

### DLP grid_system 字段映射
- DLP.grid_system.columns → 栅格列数
- DLP.grid_system.gutter → 栅格槽宽
- DLP.grid_system.margin → 页面边距
- DLP.grid_system.breakpoints → 响应式断点

### 示例
DLP-nature: 双栏, 列宽 8.5cm/栏, 槽宽 0.5cm, 页边距 2cm
DLP-linear: 12 列, 槽宽 24px, 边距 32px, 断点 sm 640px/md 768px/lg 1024px/xl 1280px
DLP-economist: 4 栏, 列宽 6cm/栏, 槽宽 0.5cm, 页边距 1.5cm

## 穷尽重试策略

### 穷尽尝试完整栅格系统
12列栅格 + 响应式断点 + 自动分栏

### 栅格计算部分失败时穷尽尝试简化栅格
- 穷尽尝试6列简化栅格
- 禁用响应式断点
- 使用固定分栏规则

### 栅格系统不可用时穷尽尝试Flexbox布局
- 穷尽尝试CSS Flexbox布局
- 无列对齐，仅保留顺序排列
- 使用固定边距和间距

### 布局系统不可用时穷尽尝试纯文本流式布局
- 穷尽尝试纯文本流式布局
- 无分栏、无对齐
- 标注为穷尽重试布局
