# 五维门禁审查器 (Taste Validator)

> **定位**: 渲染管道的审美质量终审中枢。对渲染输出进行 5 个维度的独立评分，每个维度满分 100 分，五维总分 500 分。任一维度未达 100 分即触发打回审查，由熔断机制（`fuse-mechanism.md`）接管重试与质量保持逻辑。
> **强制规则**: 所有渲染输出在通过 ASR 硬门（`asr-hard-gate.md`）和 Golden Set 距离校验（`golden-set-validator.md`）后，必须经五维门禁审查器全维满分通过方可进入导出阶段。
> **DLP 对接**: 每个维度的判定逻辑以命中的 DLP（Design Language Profile）12 字段规范为具象基准，禁止以抽象形容词作为评分依据。

---

## 方法论原理

五维门禁审查器基于"满分追求 + 定向修复"理论：将渲染输出的审美质量分解为 5 个正交维度（排版/审美/配图/语义一致性/品牌 DNA 一致性），每个维度独立评分、独立打回、独立修复。其核心设计原理是"任一短板即拒绝"——只有 5 个维度全部达到 100 分，渲染输出才被视为审美合格。

与 ASR 硬门的区别在于：ASR 硬门是"负向清单"（违反即拒），五维门禁是"正向满分"（未达满分即打回）。ASR 防住"最差"，五维门禁追求"特别棒"。

### 评分总则

| 属性 | 值 |
|------|-----|
| 维度数量 | 5 |
| 每维度满分 | 100 分 |
| 五维总分 | 500 分 |
| 通过条件 | 5 个维度均达 100 分 |
| 打回条件 | 任一维度未达 100 分 |
| 评分基准 | 命中的 DLP 12 字段规范 + TA/LA/VCA 原子库 |
| 评分粒度 | 子项级（每个子项有独立的判定逻辑和扣分规则） |

## 一、维度 1：排版门禁（Typography Gate）— 100 分

> **判定基准**: DLP `typography_scale` 字段 + DLP `font_weight_pairing` 字段 + TA 原子库（`typography-atoms.md`）
> **子项数**: 5 项，每项 20 分

### 1.1 字号阶梯符合 DLP 规范（20 分）

**判定逻辑**:

1. 提取渲染输出中所有元素的 `font-size` 值（CSS）或 `text(size:)` 值（Typst）
2. 将提取值与命中的 DLP `typography_scale` 字段定义的字号阶梯逐级比对
3. 比对规则：
   - 每个层级（h1/h2/h3/h4/body/caption/footnote）的字号必须与 DLP `typography_scale` 对应层级值一致
   - 允许 1pt = 1.333px 的单位换算误差（±0.5px）
   - 中文内容按 1.2 倍放大规则校验（TA 原子库中英文双轨规则）
   - 相邻标题层级差异必须 ≥ 4px（TA-SCALE 原子层级规则）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 某层级字号与 DLP `typography_scale` 不一致（超出换算误差） | 扣 5 分/个 |
| 相邻标题层级差异 < 4px | 扣 5 分/处 |
| 使用了 DLP `typography_scale` 未定义的字号值（硬编码字号） | 扣 5 分/个 |
| 中文内容未按 1.2 倍放大规则设置字号 | 扣 5 分/处 |

**满分条件**: 所有层级字号与 DLP `typography_scale` 一致，相邻层级差异 ≥ 4px，无硬编码字号，中文按 1.2 倍放大。

### 1.2 字重搭配符合 DLP 规范（20 分）

**判定逻辑**:

1. 提取渲染输出中所有元素的 `font-weight` 值（CSS）或 `text(weight:)` 值（Typst）
2. 将提取值与命中的 DLP `font_weight_pairing` 字段定义的字重搭配规则比对
3. 比对规则：
   - 标题字重必须与 DLP `font_weight_pairing.heading` 一致
   - 正文字重必须与 DLP `font_weight_pairing.body` 一致
   - 强调字重必须与 DLP `font_weight_pairing.emphasis` 一致
   - 标题与正文字重差异 ≥ 200（TA-WEIGHT 原子规则，含豁免场景）
   - 豁免场景判定：DLP 属于 publication-typesetting 族且 `font_weight_pairing.heading` 为 400（编辑式排版）或 300（奢侈品牌）时，字重差异规则豁免

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 标题/正文/强调字重与 DLP `font_weight_pairing` 不一致 | 扣 5 分/个 |
| 标题与正文字重差异 < 200（非豁免场景） | 扣 5 分/处 |
| 使用了 DLP `font_weight_pairing` 未定义的字重值 | 扣 5 分/个 |
| 豁免场景判定错误（误豁免或漏豁免） | 扣 5 分/处 |

**满分条件**: 所有字重与 DLP `font_weight_pairing` 一致，字重差异规则满足（含正确豁免），无未定义字重值。

### 1.3 行高与字距符合 TA 原子规范（20 分）

**判定逻辑**:

1. 提取渲染输出中所有元素的 `line-height` 和 `letter-spacing` 值
2. 将提取值与 TA 原子库（`typography-atoms.md`）的行高/字距原子比对：
   - 正文行高：TA-LEADING-001（西文 1.75 / 中文 1.8）
   - 标题行高：TA-LEADING-002（1.1-1.3 范围）
   - 说明文字行高：TA-LEADING-003（1.4）
   - 标题字距：TA-TRACKING-001（西文 -0.02em / 中文 0.01em）
   - 正文字距：TA-TRACKING-002（0）
   - 大写字距：TA-TRACKING-003（0.05em）
3. 行高值必须与 4px 基线网格对齐（行高 × 字号的乘积取整为 4px 整数倍，允许 ±1px 取整偏差）
4. 行高范围校验：正文行高 1.5-1.8，标题行高 1.1-1.3

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 行高值不在 TA 原子定义的范围内 | 扣 5 分/处 |
| 字距值与 TA 原子规范不一致 | 扣 5 分/处 |
| 行高 × 字号乘积未对齐 4px 基线网格（超出 ±1px 偏差） | 扣 5 分/处 |
| 正文行高 < 1.5（违反可读性底线） | 扣 5 分/处 |

**满分条件**: 所有行高/字距值与 TA 原子规范一致，4px 基线网格对齐，行高范围合规。

### 1.4 段落排版符合 TA 原子规范（20 分）

**判定逻辑**:

1. 提取渲染输出中段落相关的 CSS/Typst 属性：`text-indent`、`margin-bottom`（段间距）、`list-style-position`（悬挂缩进）、`float`（图文绕排）、`column-count`（多栏）
2. 将提取值与 TA 原子库的段落原子比对：
   - 段首缩进：TA-PARA-001（中文 2em，英文 0，首段不缩进）
   - 段间距：TA-PARA-002（1em，与行高区分）
   - 悬挂缩进：TA-PARA-003（列表项/参考文献 1.5em）
   - 首字下沉：TA-PARA-004（仅 L3-沉浸 + 杂志场景启用）
   - 图文绕排：TA-PARA-005（图片 float + margin 0.5em）
   - 多栏排版：TA-PARA-006（栏宽受行长控制：中文 35-50 字/行，英文 45-75 字符/行）
3. 段间距与行高区分校验：段间距 ≠ 行高（段间距必须 > 行高，视觉上明确区分段落边界）
4. 段首缩进与段间距互斥校验：同一段落不得同时使用段首缩进和段间距

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 段落排版属性与 TA 原子规范不一致 | 扣 5 分/处 |
| 段间距 = 行高（无法区分段落边界） | 扣 5 分/处 |
| 段首缩进与段间距同时使用（互斥违规） | 扣 5 分/处 |
| 行长超出控制范围（中文 > 50 字/行 或 英文 > 75 字符/行） | 扣 5 分/处 |

**满分条件**: 所有段落排版属性与 TA 原子规范一致，段间距与行高区分，互斥规则满足，行长控制合规。

### 1.5 中西文混排符合 TA 原子规范（20 分）

**判定逻辑**:

1. 检测渲染输出内容是否包含中英文混排（中文 + 英文/数字同时出现）
2. 若包含混排，校验以下 TA 原子规范：
   - 中英文间距：TA-MIX-001（中英文之间 0.25em 间距）
   - 中文与数字间距：TA-MIX-002（中文与数字之间 0.25em 间距）
   - 标点挤压：TA-MIX-003（连续标点去除多余间距）
   - 避头尾规则：TA-MIX-004（行首/行尾禁止字符不出现在错误位置）
3. 避头尾字符校验：
   - 行首禁止：句号（。）、逗号（，）、顿号（、）、分号（；）、感叹号（！）、问号（？）、右引号、右括号、省略号
   - 行尾禁止：左引号、左括号
4. 标点挤压校验：连续标点（如"。"和"」"）之间不得有多余间距

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 中英文之间缺少 0.25em 间距 | 扣 5 分/处 |
| 中文与数字之间缺少 0.25em 间距 | 扣 5 分/处 |
| 连续标点未挤压（有多余间距） | 扣 5 分/处 |
| 避头尾规则违规（禁止字符出现在行首/行尾） | 扣 5 分/处 |

**满分条件**: 中英文/数字间距合规，标点挤压合规，避头尾规则合规（仅当内容包含中文时校验本项；纯英文内容本项默认满分）。

## 二、维度 2：审美门禁（Aesthetic Gate）— 100 分

> **判定基准**: DLP `color_palette` 字段 + DLP `radius_shadow` 字段 + 视觉层级/留白/装饰的量化标准
> **子项数**: 4 项，每项 25 分

### 2.1 配色符合 DLP 配色规范（25 分）

**判定逻辑**:

1. 提取渲染输出中所有颜色值（CSS `color`/`background-color`/`border-color`/`box-shadow` 颜色分量，Typst `fill`/`stroke` 颜色分量）
2. 将提取的颜色值与命中的 DLP `color_palette` 6 色板比对：
   - `primary`（主色）、`secondary`（辅色）、`accent`（强调色）、`neutral`（中性色）、`background`（背景色）、`text`（文本色）
3. 色相偏移校验：允许 ±10% 色相偏移（HSL 色彩空间中 H 通道 ±36°）
4. 派生色校验：若使用了 DLP 6 色板之外的色值，必须能追溯到派生链（基于 DLP 基色调亮/调暗 10-20%）
5. 禁止色校验：不得出现 ASR 硬门禁止的色值（AI 紫 #7C3AED 系、纯黑 #000000、纯白 #FFFFFF 作为大面积背景、Tailwind 默认蓝 #3B82F6）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 颜色值与 DLP `color_palette` 不一致且色相偏移 > 10% | 扣 5 分/个 |
| 使用了无法追溯到 DLP 派生链的色值 | 扣 5 分/个 |
| 出现 ASR 硬门禁止的色值（此项应已被 ASR 拦截，若漏过则加倍扣分） | 扣 10 分/个 |
| DLP `color_palette` 6 色板未完整使用（缺少某角色色值） | 扣 5 分/个 |

**满分条件**: 所有颜色值与 DLP `color_palette` 一致（含 ±10% 色相偏移内），派生色有完整派生链，无禁止色，6 色板完整使用。

### 2.2 视觉层级清晰（25 分）

**判定逻辑**:

1. 提取渲染输出中所有标题层级（h1-h6）和正文层级的字号、字重值
2. 视觉层级清晰度量化校验：
   - 相邻标题层级字号差异 ≥ 4px（TA-SCALE 原子规则）
   - 标题与正文字重差异 ≥ 200（TA-WEIGHT 原子规则，含豁免场景）
   - 标题层级最多 4 级（h1-h4），超过 4 级视为层级过深
3. 视觉权重排序校验：字号 × 字重的视觉权重必须从 h1 到 body 单调递减
4. 层级跳跃校验：不得跳级使用标题（如 h1 后直接 h3，跳过 h2）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 相邻标题层级字号差异 < 4px | 扣 5 分/处 |
| 标题与正文字重差异 < 200（非豁免场景） | 扣 5 分/处 |
| 标题层级超过 4 级（使用了 h5/h6） | 扣 5 分/处 |
| 视觉权重非单调递减（某低层级视觉权重大于高层级） | 扣 5 分/处 |
| 标题跳级使用（如 h1 → h3，跳过 h2） | 扣 5 分/处 |

**满分条件**: 字号差异 ≥ 4px，字重差异 ≥ 200（含豁免），层级 ≤ 4 级，视觉权重单调递减，无跳级。

### 2.3 留白克制舒适（25 分）

**判定逻辑**:

1. 计算渲染输出的留白率：留白面积 / 总页面面积 × 100%
2. 留白率范围校验：
   - 最佳范围：20%-40%
   - < 20%：留白不足（信息密度过高，视觉拥挤）
   - > 40%：留白过度（信息密度过低，视觉松散）
3. 留白分布均匀性校验：页面四周留白（margin）与内容区间距（padding/gap）应遵循 DLP `spacing_system` 阶梯
   - **"区域"定义**：将页面按视觉块（header/main/footer/sidebar/card）划分为 N 个区域，计算每个区域的留白率（留白面积 / 区域总面积）
   - **不均匀判定**：若 `max(区域留白率) / min(区域留白率) > 3`，则判定为"留白分布严重不均匀"
   - 示例：header 留白率 60%、main 留白率 15% → 60/15 = 4 > 3，判定为严重不均匀
4. 间距值校验：所有间距值必须是 DLP `spacing_system.base`（4px）的整数倍

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 留白率 < 20% | 扣 10 分 |
| 留白率 > 40% | 扣 5 分 |
| 间距值不是 4px 整数倍（违反 DLP `spacing_system` 基准） | 扣 5 分/处 |
| 留白分布严重不均匀（某区域留白与其他区域差异 > 3 倍） | 扣 5 分/处 |

**满分条件**: 留白率在 20%-40% 范围内，所有间距值为 4px 整数倍，留白分布均匀。

### 2.4 装饰克制高级（25 分）

**判定逻辑**:

1. 提取渲染输出中所有装饰性元素：`box-shadow`（阴影）、`border-radius`（圆角）、渐变（`linear-gradient`/`radial-gradient`）、滤镜（`filter`）
2. 阴影层数校验：页面中同时使用的阴影层数 ≤ 3（DLP `radius_shadow` 规范）
3. 圆角值校验：圆角值必须与 DLP `radius_shadow.radius` 一致（学术期刊族强制 0px 直角）
4. 廉价装饰检测（以下任一即判定为廉价装饰）：
   - 高饱和度渐变（渐变两端色相差异 > 180° 且饱和度 > 80%）
   - 霓虹发光效果（`box-shadow` 的 spread > 10px 且颜色饱和度 > 90%）
   - 毛玻璃效果用于正文区域（`backdrop-filter: blur()` 应用于正文容器）
   - emoji 作为装饰元素
   - em-dash（—）作为分隔符
5. DLP 族装饰规范校验：
   - academic-journal 族：全直角（0px），零阴影，零渐变，零滤镜
   - interface-brand 族：中等圆角（6-12px），柔和阴影（elevation 分层），微渐变允许
   - publication-typesetting 族：直角为主，零阴影，叙事性装饰允许
   - data-visualization 族：直角，零阴影，数据精确性优先

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 阴影层数 > 3 | 扣 10 分 |
| 圆角值与 DLP `radius_shadow.radius` 不一致 | 扣 5 分/处 |
| 出现廉价装饰（高饱和渐变/霓虹发光/毛玻璃正文/emoji 装饰/em-dash 分隔） | 扣 10 分/个 |
| DLP 族装饰规范违规（如学术期刊族使用了圆角或阴影） | 扣 10 分/处 |

**满分条件**: 阴影层数 ≤ 3，圆角值与 DLP 一致，无廉价装饰，DLP 族装饰规范完全遵守。

## 三、维度 3：配图门禁（Illustration Gate）— 100 分

> **判定基准**: DLP `applicable_scenarios` 字段 + VCA 原子库（`visual-creative-atoms.md`）+ 配图技术规范
> **子项数**: 5 项，每项 20 分

### 3.1 配图数量充足（20 分）

**判定逻辑**:

1. 统计渲染输出的正文字数（不含标题、图注、脚注、参考文献）
2. 统计渲染输出中的配图数量（`<img>`/`<figure>`/`<svg>`/Typst `figure`/`image`）
3. 配图密度校验：每 500 字至少 1 张配图
   - 配图密度 = 配图数量 / (正文字数 / 500)
   - 配图密度 ≥ 1.0 为合格
4. 特殊场景豁免：
   - 纯数据摘要（L1-极简，字数 < 500）：至少 1 张配图
   - 纯文字叙事（文学/散文）：配图密度要求降为每 1000 字至少 1 张

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 配图密度 < 1.0（每 500 字少 1 张） | 扣 10 分/张 |
| 正文字数 > 500 但配图数量为 0 | 扣 20 分（本项零分） |
| 特殊场景豁免下仍不满足质量保持要求 | 扣 10 分 |

**满分条件**: 配图密度 ≥ 1.0（每 500 字至少 1 张），或满足特殊场景豁免的质量保持要求。

### 3.2 配图风格与 DLP 一致（20 分）

**判定逻辑**:

1. 提取每张配图的风格特征（通过配图的元数据/Alt 文本/生成参数/视觉特征分析）
   - **视觉特征分析算法**（当元数据/Alt 文本不足时启用）：
     - ① **颜色直方图**：计算配图的颜色饱和度分布。低饱和度（平均饱和度 < 30%）→ 学术插图；高饱和度（平均饱和度 > 60%）→ 编辑摄影
     - ② **边缘密度**：通过 Canny 边缘检测计算边缘像素占比。高边缘密度（> 15%）→ 线稿/示意图；低边缘密度（< 5%）→ 照片
     - ③ **字体检测**：检测配图内嵌文字字体。含 Arial/Helvetica → 学术风格；含衬线字体（Times/Garamond）→ 编辑风格
     - ④ **构图分析**：分析主体位置。居中对称构图 → 学术插图；黄金分割/三分法构图 → 编辑摄影
   - 综合以上 4 项特征与 DLP 族特征比对，判定配图风格归属
2. 将配图风格与命中的 DLP `applicable_scenarios` 和 DLP 族特征比对：
   - academic-journal 族：配图风格应为学术插图/数据图表/机制示意图（矢量图优先）
   - interface-brand 族：配图风格应为产品截图/品牌视觉/界面元素
   - publication-typesetting 族：配图风格应为编辑摄影/杂志插画/信息图
   - data-visualization 族：配图风格应为数据图表/统计可视化
3. VCA 原子库对接校验：配图风格应能映射到 VCA 原子库中的某个原子（VCA-ART/VCA-GEN/VCA-DATA/VCA-BRAND）
4. 风格一致性校验：同一文档内所有配图的风格应统一（不得混用学术插图和卡通插画）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 配图风格与 DLP 族特征不匹配 | 扣 5 分/张 |
| 配图风格无法映射到 VCA 原子库的任何原子 | 扣 5 分/张 |
| 同一文档内配图风格不统一（混用不同风格） | 扣 5 分/张 |

**满分条件**: 所有配图风格与 DLP 族特征匹配，可映射到 VCA 原子，全文风格统一。

### 3.3 配图分辨率达标（20 分）

**判定逻辑**:

1. 提取每张配图的分辨率信息（像素尺寸 / DPI）
2. 分辨率门槛校验：
   - 印刷媒介（PDF/纸质输出）：≥ 300 DPI
   - 数字媒介（Web/HTML 输出）：宽度 ≥ 1920px 或 ≥ 2× 显示尺寸
   - 矢量图（SVG/PDF）：分辨率不适用，默认通过
3. 模糊度校验：配图不得有明显模糊（通过图像锐度分析，拉普拉斯方差 < 100 判定为模糊）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 印刷媒介配图 DPI < 300 | 扣 20 分/张（本项零分） |
| 数字媒介配图宽度 < 1920px 且非矢量图 | 扣 10 分/张 |
| 配图明显模糊（拉普拉斯方差 < 100） | 扣 10 分/张 |
| 配图拉伸变形（宽高比与原始比例不一致） | 扣 5 分/张 |

**满分条件**: 所有配图分辨率达标（印刷 ≥ 300 DPI / Web ≥ 1920px / 矢量图豁免），无模糊，无变形。

### 3.4 配图 Alt 文本完整（20 分）

**判定逻辑**:

1. 检查每张配图是否有 Alt 文本（HTML `alt` 属性 / Markdown `![alt]` / Typst `figure(caption:)`）
2. Alt 文本质量校验：
   - Alt 文本不得为空字符串
   - Alt 文本不得为纯文件名（如 "image1.png"）
   - Alt 文本应描述配图内容（长度 ≥ 10 个字符）
3. 图注完整性校验：学术场景（research_report）下每张配图必须有图注（`<figcaption>` / Typst `figure.caption`）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 配图缺少 Alt 文本 | 扣 5 分/张 |
| Alt 文本为空字符串或纯文件名 | 扣 5 分/张 |
| Alt 文本长度 < 10 字符（描述不充分） | 扣 5 分/张 |
| 学术场景下配图缺少图注 | 扣 5 分/张 |

**满分条件**: 所有配图有完整 Alt 文本（≥ 10 字符，非文件名），学术场景下图注完整。

### 3.5 配图排版与正文协调（20 分）

**判定逻辑**:

1. 提取配图在文档中的位置和排版属性（`float`/`margin`/`width`/`text-align`）
2. 配图宽度校验：配图宽度不得超过内容区宽度的 100%，不得小于内容区宽度的 30%（过小影响可读性）
3. 配图间距校验：配图与正文之间必须有间距（TA-PARA-005 图文绕排规则：margin 0.5em ≈ 8px = 2×4px 基准）
4. 配图对齐校验：配图应与正文栅格对齐（不得超出内容区边界）
5. 配图位置校验：配图应在首次引用的段落附近（引用段落前后 2 段范围内）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 配图与正文之间无间距 | 扣 5 分/张 |
| 配图宽度超出内容区边界 | 扣 5 分/张 |
| 配图宽度 < 内容区宽度的 30% | 扣 5 分/张 |
| 配图位置远离首次引用段落（超过 2 段范围） | 扣 5 分/张 |

**满分条件**: 所有配图与正文有间距，宽度合规，栅格对齐，位置靠近引用段落。

### 4.1 内容主题与 DLP 场景标签匹配（25 分）

**判定逻辑**:

1. 提取渲染输出的内容主题（从标题、摘要、关键词推断）
   - **关键词提取方法**：从 UIR v2.0 §1 标题和 §2 摘要中提取名词短语作为主题关键词
     - 使用 jieba 分词 + 词性标注，取名词（`n`/`nr`/`ns`/`nt`/`nz`）和名词短语
     - 去除停用词后，保留 Top-10 高频名词短语作为主题关键词集合
   - **匹配度计算**：将提取的主题关键词集合与 DLP `applicable_scenarios` 字段中的场景标签计算 Jaccard 相似度
     - Jaccard 相似度 = |关键词集合 ∩ 场景标签集合| / |关键词集合 ∪ 场景标签集合|
     - 相似度 ≥ 0.8 为满分（对应命中率 ≥ 80%）
2. 提取命中的 DLP `applicable_scenarios` 场景标签列表
3. 匹配度计算：
   - 匹配度 = 内容主题关键词与 DLP 场景标签的命中率
   - 命中率 ≥ 80%：满分
   - 命中率 60%-80%：扣分
   - 命中率 < 60%：严重扣分
4. DLP 族一致性校验：内容主题应与 DLP 族特征一致（如学术论文内容不应命中 interface-brand 族 DLP）
5. **协同参考**：可参考 `semantic-auto-detect.md` 的段落映射表辅助验证内容主题——段落映射表中 `title`/`data_chart`/`flowchart`/`concept_map` 等类型的分布比例可反映内容主题倾向（如数据段占比高 → 数据驱动型主题，流程段占比高 → 方法流程型主题），作为内容主题与 DLP 场景标签匹配度的交叉验证依据。

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 匹配度 < 80%（但 ≥ 60%） | 扣 15 分 |
| 匹配度 < 60% | 扣 25 分（本项零分） |
| 内容主题与 DLP 族特征不一致 | 扣 10 分 |

**满分条件**: 内容主题与 DLP 场景标签匹配度 ≥ 80%，DLP 族特征一致。

### 4.2 段落类型与呈现形式匹配（25 分）

**判定逻辑**:

1. **消费 `semantic-auto-detect.md` 的段落映射表**：维度 4.2 不再独立执行段落类型识别，而是直接读取 `semantic-auto-detect.md` 在渲染阶段生成的段落映射表，获取每个段落的语义类型标注（`title`/`data_chart`/`flowchart`/`concept_map`/`body`/`quote`/`code`/`table`/`image`）。
   - **数据来源**：段落映射表通过 UIR v2.0 文档传递，由 `semantic-auto-detect.md` §六 段落类型映射表定义。
   - **优先级继承**：维度 4.2 继承 `semantic-auto-detect.md` §1.2 的优先级裁决规则（标题段 > 数据段 > 流程段 > 概念段），不重新裁决。
2. 校验段落类型与呈现形式的匹配（基于 §4.0.3 分类映射表）：
   - 数据段（`data_chart`） → 表格/图表呈现（不得用纯文字描述数据）
   - 流程段（`flowchart`） → 步骤列表/流程图呈现（Mermaid/PlantUML）
   - 概念段（`concept_map`） → 定义+示例呈现（概念卡片/思维导图/分类树）
   - 标题段（`title`） → 封面/章节页呈现
   - 正文段（`body`） → 正文段落排版（TA-PARA-001/002）
   - 引用段（`quote`） → 引用块样式（`<blockquote>` / Typst `quote`）
   - 代码段（`code`） → 代码块样式（等宽字体 + 语法高亮）
   - 表格段（`table`） → 表格呈现
   - 图片段（`image`） → 图片呈现
3. 段落类型与呈现形式不匹配的典型情况：
   - 数据段用纯文字描述（应有表格/图表）
   - 引用段无引用块样式
   - 代码段未使用等宽字体
   - 流程段未生成流程图（仅有纯文字步骤描述）
4. **回溯检查**（§4.0.4 回溯机制）：当判定不匹配时，首先检查渲染器是否正确消费了 `semantic-auto-detect.md` 的段落映射表。若为渲染器消费逻辑缺陷则扣分；若为映射表类型标注有误则不扣分并标记待修正。

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 段落类型与呈现形式不匹配（渲染器消费缺陷） | 扣 5 分/处 |
| 数据段缺少表格/图表呈现 | 扣 5 分/处 |
| 引用段缺少引用块样式 | 扣 5 分/处 |
| 代码段未使用等宽字体 | 扣 5 分/处 |
| 流程段缺少流程图/步骤列表呈现 | 扣 5 分/处 |

**满分条件**: 所有段落类型与呈现形式匹配（基于 `semantic-auto-detect.md` 段落映射表），数据段有表格/图表，引用段有引用块，代码段用等宽字体，流程段有流程图。

### 4.3 图表类型与数据类型匹配（25 分）

**判定逻辑**:

1. **图表类型选择规则统一**：维度 4.3 的图表类型选择规则与 `semantic-auto-detect.md` §二 数据段检测的 8 种触发模式保持一致。维度 4.3 不再独立判定图表类型选择是否合理，而是校验渲染器是否按照 `semantic-auto-detect.md` 的 8 种触发模式选择了正确的图表类型。
   - **8 种触发模式对应关系**（引用 `semantic-auto-detect.md` §2.1）：

     | semantic-auto-detect.md 触发模式 | 图表类型 | 维度 4.3 校验要点 |
     |--------------------------------|---------|----------------|
     | 百分比序列（同段 ≥2 个百分比） | 柱状图/条形图 | 校验百分比序列数据是否用柱状图/条形图呈现 |
     | 数值对比（相比/比/较/增长/下降） | 对比柱状图 | 校验数值对比数据是否用对比柱状图呈现 |
     | 时间序列（同段 ≥2 个年份） | 折线图/面积图 | 校验时序数据是否用折线图/面积图呈现 |
     | 占比描述（占比/占/比例/份额/构成/分布） | **饼图/环形图** | 校验占比描述是否用饼图/环形图呈现（**统一为饼图/环形图，与 semantic-auto-detect.md 一致，不再期望柱状图**） |
     | 统计表关键词（如表/下表/统计/数据显示） | 表格 | 校验统计表关键词段落是否用表格呈现 |
     | 排名描述（排名/位列/TOP/前三） | 排行榜条形图 | 校验排名描述是否用排行榜条形图呈现 |
     | 相关性描述（相关性/相关系数/正相关/R²） | 散点图/气泡图 | 校验关系数据是否用散点图/气泡图呈现 |
     | 分布描述（分布/正态/中位数/标准差） | 箱线图/直方图 | 校验分布数据是否用箱线图/直方图呈现 |

2. 补充图表类型校验（`semantic-auto-detect.md` 8 种触发模式未覆盖的场景）：
   - 地理数据 → 地图/等值线图
   - 层级数据 → 树状图/旭日图/矩形树图
3. 禁止图表类型校验（与 ASR 硬门数据可视禁令协同）：
   - 禁止 3D 饼图
   - 禁止无坐标轴标签的图表
   - 禁止图例遮挡数据
   - 禁止彩虹色板用于顺序数据

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 图表类型与 `semantic-auto-detect.md` 触发模式不匹配 | 扣 5 分/处 |
| 占比描述场景未使用饼图/环形图（误用柱状图） | 扣 5 分/处 |
| 使用了禁止的图表类型（3D 饼图等） | 扣 5 分/处 |
| 图表缺少坐标轴标签 | 扣 5 分/处 |
| 图例遮挡数据 | 扣 5 分/处 |
| 顺序数据使用了彩虹色板 | 扣 5 分/处 |

**满分条件**: 所有图表类型与 `semantic-auto-detect.md` 的 8 种触发模式匹配，占比描述使用饼图/环形图，无禁止图表类型，坐标轴标签完整，图例不遮挡，色板使用正确。

### 4.4 标题层级与内容结构匹配（25 分）

**判定逻辑**:

1. 提取渲染输出的标题层级结构（h1-h4 的嵌套关系）
2. 提取内容结构（章节/小节/子节的逻辑层级）
3. 匹配校验：
   - 标题层级深度必须与内容结构深度一致（内容 3 级结构 → h1/h2/h3）
   - 标题文本应概括对应章节的核心内容（标题与首段主题词重合度 ≥ 50%）
     - **主题词提取与重合度计算算法**：
       - 使用 jieba 分词提取标题的 Top-5 TF-IDF 关键词（去停用词）
       - 使用 jieba 分词提取首段前 100 字的 Top-5 TF-IDF 关键词（去停用词）
       - 计算两组关键词的 Jaccard 相似度作为重合度：`重合度 = |标题关键词集 ∩ 首段关键词集| / |标题关键词集 ∪ 首段关键词集|`
       - 重合度 ≥ 0.5 为满分（对应 ≥ 50%），重合度 < 0.5 按差距扣分
   - 同级标题应保持并列关系（不得出现同级标题一个是另一个的子集）
4. 标题编号校验（学术场景）：学术论文标题应有编号（1/1.1/1.1.1），编号连续不间断
5. **协同参考**：可参考 `semantic-auto-detect.md` 的标题段识别结果辅助验证标题层级——`semantic-auto-detect.md` §五 标题段检测将标题段标注为 `title` 类型并判定层级（H1/H2），维度 4.4 可交叉校验渲染输出的标题层级结构是否与 `semantic-auto-detect.md` 的标题段识别结果一致（如 `semantic-auto-detect.md` 识别为 H1 的标题段在渲染输出中应为 h1 层级）。

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 标题层级深度与内容结构深度不一致 | 扣 5 分/处 |
| 标题文本与章节内容主题不匹配（重合度 < 50%） | 扣 5 分/处 |
| 同级标题非并列关系 | 扣 5 分/处 |
| 学术场景标题编号不连续 | 扣 5 分/处 |

**满分条件**: 标题层级与内容结构匹配，标题文本概括章节内容，同级标题并列，编号连续。

---

## 五、维度 5：品牌 DNA 一致性门禁（Brand DNA Consistency Gate）— 100 分

> **判定基准**: `visual_dna` 对象 + DLP 12 字段规范 + 全文统一性校验
> **子项数**: 4 项，每项 25 分
> **DLP 质量保持场景说明**: DLP 质量保持场景下（`dlp-retriever.md` §七 质量保持策略触发），品牌 DNA 一致性评分基准为质量保持后的 DLP（非原任务类型 DLP）。即当 DLP 检索器质量保持为 Level 1/2/3 默认 DLP 时，维度 5 的 `visual_dna` 对象和 DLP 12 字段规范均以质量保持后的 DLP 为基准，不以原任务类型应命中的 DLP 为基准。

### 5.1 Visual DNA 贯穿全文（25 分）

**判定逻辑**:

1. 提取渲染输出中所有视觉元素的参数值（配色/字体/间距/圆角/线条/动效）
2. 将提取值与 `visual_dna` 对象的对应字段逐一比对
3. 贯穿性校验：
   - 文档开头（前 20% 内容）、中间（20%-80%）、结尾（后 20%）的视觉参数必须一致
   - 所有页面/组件共享同一份 `visual_dna`（visual-dna.md §七 全局统一规则）
4. DNA 偏离检测：任何视觉元素的参数不得偏离 `visual_dna` 定义（visual-dna.md §七 零偏离原则，由熔断机制替换为"熔断可控偏离"）

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 某视觉元素参数偏离 `visual_dna` 定义 | 扣 5 分/处 |
| 文档不同区段的视觉参数不一致 | 扣 5 分/处 |
| 某页面/组件使用了独立的视觉参数（未共享 `visual_dna`） | 扣 5 分/处 |
| 出现硬编码视觉值（绕过 `visual_dna`） | 扣 5 分/处 |

**满分条件**: 所有视觉元素参数与 `visual_dna` 一致，全文区段一致，所有页面/组件共享 `visual_dna`，无硬编码值。

### 5.2 配色全文统一（25 分）

**判定逻辑**:

1. 提取渲染输出全文中所有颜色值
2. 统一性校验：
   - 全文所有颜色值必须来自 DLP `color_palette` 6 色板或其派生链
   - 同一语义角色（如"标题色"）全文必须使用同一色值
   - 不得出现非 DLP 配色（如某段落突然使用了 DLP 未定义的颜色）
3. 暗色模式校验（如适用）：暗色模式配色必须与亮色模式配色保持同一 DLP 色板的明度反转

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 全文出现非 DLP `color_palette` 的色值 | 扣 5 分/处 |
| 同一语义角色全文使用不同色值 | 扣 5 分/处 |
| 某段落/区块使用了与全文不同的配色方案 | 扣 5 分/处 |
| 暗色模式配色未保持 DLP 色板明度反转 | 扣 5 分/处 |

**满分条件**: 全文所有颜色值来自 DLP `color_palette` 或派生链，同一语义角色全文统一，无非 DLP 配色。

### 5.3 字体全文统一（25 分）

**判定逻辑**:

1. 提取渲染输出全文中所有 `font-family` 值
2. 统一性校验：
   - 全文所有字体必须来自 DLP `font_stack` 三栈（西文/中文/等宽）
   - 标题字体全文统一（所有 h1-h6 使用同一字体族）
   - 正文字体全文统一（所有 body/p 使用同一字体族）
   - 代码字体全文统一（所有 code/pre 使用同一等宽字体族）
3. 字体栈完整性校验：`font-family` 必须包含 DLP `font_stack` 的西文 + 中文 fallback

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 全文出现非 DLP `font_stack` 的字体 | 扣 5 分/处 |
| 标题字体全文不统一 | 扣 5 分/处 |
| 正文字体全文不统一 | 扣 5 分/处 |
| `font-family` 缺少中文 fallback | 扣 5 分/处 |

**满分条件**: 全文所有字体来自 DLP `font_stack`，标题/正文/代码字体各自全文统一，字体栈含中文 fallback。

### 5.4 间距系统全文统一（25 分）

**判定逻辑**:

1. 提取渲染输出全文中所有间距值（`margin`/`padding`/`gap`/`grid-gap`）
2. 统一性校验：
   - 全文所有间距值必须来自 DLP `spacing_system` 阶梯表（如 4/8/12/16/24/32px）
   - 同一语义角色（如"段落间距"）全文必须使用同一间距值
   - 所有间距值必须是 DLP `spacing_system.base`（4px）的整数倍
3. 栅格系统统一性校验：全文所有栅格参数（列数/槽宽/边距）必须与 DLP `grid_system` 一致

**扣分规则**:

| 违规情况 | 扣分 |
|---------|------|
| 全文出现非 DLP `spacing_system` 阶梯的间距值 | 扣 5 分/处 |
| 同一语义角色全文使用不同间距值 | 扣 5 分/处 |
| 间距值不是 4px 整数倍 | 扣 5 分/处 |
| 栅格参数与 DLP `grid_system` 不一致 | 扣 5 分/处 |

**满分条件**: 全文所有间距值来自 DLP `spacing_system` 阶梯，同一语义角色统一，间距值为 4px 整数倍，栅格参数一致。

## 六、打回报告生成

当任一维度未达 100 分时，五维门禁审查器必须生成打回报告，交由熔断机制（`fuse-mechanism.md`）处理。

### 6.1 打回报告结构

```yaml
taste_validator_report:
  status: "FAIL"                    # FAIL（任一维度未满分）/ PASS（五维全满分）
  total_score: 465                  # 五维总分（满分 500）
  dimensions:
    - name: "Typography Gate"
      code: "GATE-TYPOGRAPHY"
      score: 100
      passed: true
    - name: "Aesthetic Gate"
      code: "GATE-AESTHETIC"
      score: 85
      passed: false
      failed_items:
        - item: "配色符合 DLP 配色规范"
          score: 20
          max_score: 25
          deductions:
            - rule: "颜色值与 DLP color_palette 不一致且色相偏移 > 10%"
              count: 1
              deduction: 5
              detail: "段落 3 的背景色 #F0F0F0 与 DLP-linear 的 background #FFFFFF 色相偏移超出 10%"
    - name: "Illustration Gate"
      code: "GATE-ILLUSTRATION"
      score: 80
      passed: false
      failed_items:
        - item: "配图数量充足"
          score: 10
          max_score: 20
          deductions:
            - rule: "配图密度 < 1.0（每 500 字少 1 张）"
              count: 1
              deduction: 10
              detail: "正文 1500 字，应有 ≥ 3 张配图，实际仅 2 张"
    - name: "Semantic Consistency Gate"
      code: "GATE-SEMANTIC"
      score: 100
      passed: true
    - name: "Brand DNA Consistency Gate"
      code: "GATE-BRAND-DNA"
      score: 100
      passed: true
  failed_dimensions:               # 未满分维度列表
    - code: "GATE-AESTHETIC"
      score: 85
      gap: 15                       # 距满分差距
    - code: "GATE-ILLUSTRATION"
      score: 80
      gap: 20
  repair_suggestions:               # 修复建议（定向修复，仅修复未满分维度）
    - dimension: "GATE-AESTHETIC"
      target_item: "配色符合 DLP 配色规范"
      action: "将段落 3 的背景色从 #F0F0F0 修正为 DLP-linear 的 background #FFFFFF"
      expected_score_after_fix: 25
    - dimension: "GATE-ILLUSTRATION"
      target_item: "配图数量充足"
      action: "在正文第 2 节（约第 1000 字处）补充 1 张配图，风格需与 DLP-linear 族特征一致"
      expected_score_after_fix: 20
  fuse_handoff:                     # 移交熔断机制
    retry_count: 1                  # 当前重试次数
    max_retry: 3                    # 最大重试次数
    exhaust_retry_threshold: 3          # 质量保持阈值
```

### 6.2 打回报告生成规则

1. **FAIL 状态**: 任一维度 score < 100，status = "FAIL"
2. **PASS 状态**: 五维全部 score = 100，status = "PASS"
3. **未满分维度**: 仅记录 `passed: false` 的维度，`passed: true` 的维度不记录 `failed_items`
4. **缺失项详情**: 每个扣分项必须记录违规规则、违规次数、扣分值、具体详情
5. **修复建议**: 仅针对未满分维度生成定向修复建议，不得要求重新渲染已满分维度
6. **熔断移交**: 打回报告末尾附 `fuse_handoff` 对象，移交熔断机制处理

### 6.3 修复建议生成规则

| 维度 | 修复策略 |
|------|---------|
| 排版门禁 | 定向修正不符合 DLP/TA 规范的字号/字重/行高/字距/段落/混排属性 |
| 审美门禁 | 定向替换不符合 DLP 配色/圆角/阴影的值，移除廉价装饰 |
| 配图门禁 | 补充缺失配图，调整配图风格/分辨率/Alt/排版 |
| 语义一致性门禁 | 调整段落呈现形式/图表类型/标题层级以匹配内容语义 |
| 品牌 DNA 一致性门禁 | 统一全文配色/字体/间距到 DLP 规范，消除硬编码值 |

## 八、强制规则

1. **全维满分通过**: 五维总分 500 分，任一维度未达 100 分即触发打回，不得以"综合分高"为由放行。
2. **独立评分**: 5 个维度独立评分，某维度的扣分不得影响其他维度的评分。
3. **具象基准**: 所有判定逻辑必须以 DLP 12 字段具象值和 TA/LA/VCA 原子库为基准，禁止以抽象形容词作为评分依据。
4. **定向修复**: 打回后仅修复未满分维度，不得重新渲染已满分部分（熔断机制重试策略）。
5. **扣分可追溯**: 每个扣分项必须记录违规规则、违规次数、扣分值、具体详情，供熔断机制生成修复建议。
6. **DLP 优先**: 当渲染输出的视觉参数与 `visual_dna` 冲突时，以 DLP 12 字段规范为最终基准（DLP 是 `visual_dna` 的具象锚点）。
7. **ASR 前置**: 五维门禁审查器在 ASR 硬门和 Golden Set 校验通过后执行，不得跳过前置门禁。
8. **熔断终止**: 五维门禁审查器不得自行决定质量保持或放行，质量保持逻辑由熔断机制（`fuse-mechanism.md`）统一处理。

## 九、穷尽重试策略

### L1: 五维全满分

五维门禁审查器返回 PASS，渲染输出进入导出阶段。不触发熔断机制。

### L2: 部分维度未满分

- 生成打回报告，移交熔断机制
- 熔断机制根据 `repair_suggestions` 定向修复未满分维度
- 修复后重新执行五维门禁审查（仅审查未满分维度，已满分维度跳过）
- 重试计数 +1

### L3: 多次重试后部分维度仍未满分

- 熔断机制在 3 次重试后质量保持为最高分方案
- 五维门禁审查器在质量保持方案上执行最终审查
- 质量保持方案的审查报告标注 `[FUSE-EXHAUST-RETRY]` 标记
- 审查报告记录最终综合得分（XX/500）

### L4: 五维门禁审查器自身不可用

- 穷尽尝试质量保持为仅执行 ASR 硬门 + Golden Set 校验
- 标注为"五维门禁质量保持"输出
- 记录质量保持原因供调试

### L5: 所有审查机制不可用

- 仅执行 ASR 硬门（如 ASR 也不可用则直接输出）
- 标注为"审查机制完全不可用"输出
- 输出包含风险警告
