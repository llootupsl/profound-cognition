# DLP-template: 自定义设计语言画像模板

> **定位**: 用户自定义 DLP（Design Language Profile）的起点模板。复制本文件到 `rendering-pipeline/user-dlps/` 目录下，重命名为 `DLP-{your-name}.md`，按本模板填写 12 字段即可创建自定义 DLP。
> **配套文件**:
> - 创建向导: `docs/dlp-creation-wizard.md`（交互式引导填写本模板）
> - 检索器扩展: `rendering-pipeline/dlp-retriever.md` §十一 自定义 DLP 检索
> - ASR 验证: `../../asr-rules.yaml`（项目根目录，自定义 DLP 必须通过 ASR 硬门验证）
> **版本**: v1.0.0 (R6-04)

> **【A6.4-F4 修复，Wave 7，2026-06-27】EXHAUST 合规声明**：
> DLP（Design Language Profile）的档位选择（含任何可选输出档位）仅缩减输出体积与渲染规模，不缩减 EXHAUST 模式四大铁律所要求的深度要求。即使用户选择精简版 DLP，研究内容的深度、维度覆盖、证据密度仍须满足 EXHAUST 四大铁律（Token 不设上限 / 时间不设限制 / 质量唯一优先 / 永远穷尽无档位无上限）。审计原引用 `DLP-template.md L9/L144 "简版档位"` 经核验当前文件无此措辞，本声明已预防性添加以落实审计意图。

## YAML frontmatter（12 字段完整定义）

> **填写说明**: 每个字段后的注释说明了填写要求。所有字段为必填，无默认值。填写完成后需通过 ASR 硬门验证（见本文件末尾 §验证清单）。

```yaml
---
# ============================================================
# 字段 1-3: 基础标识
# ============================================================
name: "DLP-{your-name}"           # 命名规范：DLP-{小写连字符名称}，如 DLP-my-brand
anchor: "{锚定实体描述}"            # 锚定真实世界的设计实体，如"XX 公司 2024 年品牌设计"
family: "{族归属}"                  # 4 族之一：academic-journal / interface-brand / publication-typesetting / data-visualization
                                   # 若不属于任何族，填 "custom"

# ============================================================
# 字段 4: 配色方案（6 色板）
# ============================================================
color_palette:
  primary: "#{主色十六进制}"         # 主色 — 标题、重点强调、链接（禁用 #7C3AED/#3B82F6/#000000/#FFFFFF）
  secondary: "#{辅色十六进制}"       # 辅色 — 次要强调、数据高亮
  accent: "#{强调色十六进制}"        # 强调色 — 关键警示、CTA
  neutral: "#{中性色十六进制}"       # 中性色 — 次要文字、图注
  background: "#{背景色十六进制}"    # 背景色 — 页面主背景（禁用 #000000/#FFFFFF 大面积）
  text: "#{文本色十六进制}"          # 文本色 — 正文主文字色

# ============================================================
# 字段 5: 字号阶梯
# ============================================================
typography_scale:
  h1: "{px/rem}"                   # 文章主标题（如 "32px/2rem"）
  h2: "{px/rem}"                   # 一级章节标题
  h3: "{px/rem}"                   # 二级章节标题
  h4: "{px/rem}"                   # 三级章节标题
  body: "{pt/px}"                  # 正文（如 "16px/1rem" 或 "10pt/13.33px"）
  caption: "{pt/px}"               # 图注
  footnote: "{pt/px}"              # 脚注

# ============================================================
# 字段 6: 字体栈
# ============================================================
font_stack:
  western: '{西文字体栈}'           # 如 '"Source Serif 4", "STIX Two Text", serif'
  chinese: '{中文字体栈}'           # 如 '"思源宋体", "Noto Serif SC", serif'
  monospace: '{等宽字体栈}'         # 如 '"JetBrains Mono", "Cascadia Code", monospace'

# ============================================================
# 字段 7: 字重配对
# ============================================================
font_weight_pairing:
  heading: "{标题字重}"             # 如 "bold(700)"
  body: "{正文字重}"               # 如 "regular(400)"
  emphasis: "{强调字重}"           # 如 "italic(400)"

# ============================================================
# 字段 8: 间距系统
# ============================================================
spacing_system:
  base: "{基准单位}"               # 如 "4px"（推荐 4px 栅格）
  scale: "{间距阶梯}"              # 如 "4/8/12/16/24/32px"

# ============================================================
# 字段 9: 栅格系统
# ============================================================
grid_system:
  columns: "{列数}"                # 如 "双栏" / "12列" / "单栏"
  column_width: "{列宽}"           # 如 "8.5cm/栏" 或 "N/A"
  gutter: "{槽宽}"                 # 如 "0.5cm" 或 "24px"
  margin: "{页边距}"               # 如 "2cm" 或 "32px"
  breakpoint: "{断点}"             # 如 "N/A(印刷媒介)" 或 "768px/1024px/1280px"

# ============================================================
# 字段 10: 圆角阴影
# ============================================================
radius_shadow:
  radius: "{圆角}"                 # 如 "0px"（学术直角）/ "8px"（现代圆角）
  shadow: "{阴影}"                 # 如 "none" / "0 4px 12px rgba(0,0,0,0.1)"

# ============================================================
# 字段 11: 动效曲线
# ============================================================
motion_curve:
  easing: "{缓动函数}"             # 如 "N/A(印刷媒介)" / "cubic-bezier(0.25, 0.1, 0.25, 1.0)"
  duration: "{时长}"               # 如 "N/A" / "300ms"

# ============================================================
# 字段 12: 场景标签（用于 DLP 检索器匹配）
# ============================================================
applicable_scenarios:
  - "{场景标签1}"                  # 如 "学术论文" / "品牌官网" / "数据可视化"
  - "{场景标签2}"
  - "{场景标签3}"
  - "{场景标签4}"
---
```

## 三、ASR 硬门验证清单（SubTask 5.9.4）

> 自定义 DLP 填写完成后，必须通过以下 ASR 硬门验证。验证规则完整定义见 `../../asr-rules.yaml`（项目根目录）。

### 3.1 必过项（blocking — 违反即拒）

| ASR 规则 | 验证内容 | 通过条件 | 本 DLP 状态 |
|---------|---------|---------|------------|
| ASR-COLOR-001 | 主色非 AI 紫 #7C3AED 系 | HSL 不在 [250°,280°] × S>60% × L[40%,60%] | ☐ PASS / ☐ FAIL |
| ASR-COLOR-002 | 背景非纯黑 #000000 | background != #000000 | ☐ PASS / ☐ FAIL |
| ASR-COLOR-004 | 主色非 Tailwind 默认蓝 | primary != #3B82F6 | ☐ PASS / ☐ FAIL |
| ASR-COLOR-005 | 无高饱和度渐变 | 渐变端点饱和度均 ≤ 80% | ☐ PASS / ☐ FAIL |
| ASR-FONT-001 | 主标题字体非 Inter（Premium 场景） | font_stack.western 首选非 Inter | ☐ PASS / ☐ FAIL |
| ASR-FONT-005 | 字体族 ≤ 3 族 | western + chinese + monospace ≤ 3 族 | ☐ PASS / ☐ FAIL |
| ASR-LAYOUT-005 | 栅格系统已定义 | grid_system.columns 非空 | ☐ PASS / ☐ FAIL |
| ASR-TYPO-002 | 正文行高 ≥ 1.5 | typography_scale.body 行高 ≥ 1.5 | ☐ PASS / ☐ FAIL |

### 3.2 警告项（warning — 建议修正）

| ASR 规则 | 验证内容 | 通过条件 | 本 DLP 状态 |
|---------|---------|---------|------------|
| ASR-COLOR-003 | 背景非纯白 #FFFFFF | background != #FFFFFF（或面积 < 50%） | ☐ PASS / ☐ FAIL |
| ASR-COLOR-006 | 灰调统一 | neutral 与 background 灰调一致（暖灰或冷灰） | ☐ PASS / ☐ FAIL |
| ASR-FONT-003 | 正文非 Arial | font_stack.western 首选非 Arial | ☐ PASS / ☐ FAIL |

### 3.3 验证结果

```
验证结果: {PASS|FAIL}
blocking 违规数: {N}
warning 警告数: {M}
验证时间: {ISO 8601 时间戳}
验证结论: {该自定义 DLP 是否可加入 user-dlps/ 库}
```

> **验证失败处理**: 若任一 blocking 项 FAIL，该自定义 DLP 不得加入 `user-dlps/` 库，需修正后重新验证。warning 项 FAIL 允许加入但标记待优化。

## 四、使用示例

### 4.1 复制模板

```bash
cp output/dlp-templates/DLP-template.md rendering-pipeline/user-dlps/DLP-my-brand.md
```

### 4.2 填写 12 字段

按 YAML frontmatter 中的注释填写所有字段。

### 4.3 运行 ASR 验证

按 §三 验证清单逐项检查。

### 4.4 注册到 DLP 检索器

自定义 DLP 放入 `rendering-pipeline/user-dlps/` 后，DLP 检索器会自动扫描并纳入检索候选池（详见 `dlp-retriever.md` §十一）。
