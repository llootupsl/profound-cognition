## 字段说明

| 字段 | 含义 | 数据来源 |
|------|------|---------|
| 课题名 | 用户输入的研究课题 | T00 研究大纲路由 |
| 报告类型 | research_report / wechat_article / course_material | T01 输入分流 |
| 总字数 | 最终交付物字数 | T20_output_guard |
| 激活节点 | DAG 实际执行的节点数 / 总节点数 | 执行轨迹 |
| 证据断言 | 报告中可追溯的断言数量 | T17 CoVe 事实核查 |
| 配图数量 | 报告中图表总数 | T20a 渲染 |
| Gate-α~终 | 五道阶段门控的通过状态 | T07/T14/T16/T28/T_gate_delta |
| G1-G6 | 交付前六道硬门控 | 交付守卫 T19 |
| 三路对抗 | 逻辑/证据/范围三路攻击结果 | T10/T11/T12 → T12b |
| Logistic 胜负比 | 对抗胜负的概率判定（0=完败, 1=完胜） | Logistic 公式 |
| 三维度裁决 | 内洽度/创新度/实用度 | Orchestrator |
