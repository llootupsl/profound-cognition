# 案例：AI对普通人工作的影响——wechat_article 模式

> 本案例展示 profound-cognition 以 `wechat_article` 模式执行一次公众号文章创作的关键步骤。

## 输入

```
写一篇关于AI对普通人工作影响的公众号文章
```

## 执行轨迹（关键节点）

```
▶ T01 — 输入分流：识别为 wechat_article 模式
▶ T02-T08 — 九层研究底座（精简版，聚焦工作场景）
  L1：全球AI替代岗位数据（McKinsey 3.75亿人需转岗）
  L2：2020→2026时间线（GPT-3→ChatGPT→GPT-4→Agent）
  L5：叙事扫描（"AI抢饭碗"vs"AI是工具"两种叙事）
  L8：反事实——如果没有AI，白领工作效率会怎样？
▶ T09-T13 — 认知深化+三路对抗
  逻辑对抗：攻击"3.75亿人需转岗"——McKinsey原文是"3.75亿人需学习新技能"，不是"被替代"
  证据对抗：攻击"AI提升生产力40%"——这是实验室数据，真实办公场景仅8-15%
  范围对抗：忽略了AI创造的新岗位（提示词工程师、AI审计员等）
▶ T15 — 领域引擎：psychology（工作身份认同）+ social（社会分层）+ economics（劳动力市场）
▶ T22-T27 — 全息框架（精简版，6维覆盖）
▶ T20b — 风格渲染：khazix人格锚自检（四问全通过）
  Q1"有见识"：是，引用了McKinsey和真实数据
  Q2"普通人"：是，用"你我"而非"读者们"
  Q3"认真聊"：是，不是蹭热点，是认真分析
  Q4"打动我"：是，"你的工作会不会被AI替代"这个问题打动了作者
```

## 输出片段

> **你的工作会不会被AI替代？先别急着回答**
>
> 事情是这样的。McKinsey说全球3.75亿人需要学习新技能——注意，是"学习新技能"，不是"被替代"。这两个词差远了。就像你从骑自行车换到开车，你确实需要学新技能，但你不是被替代了，你是升级了。
>
> 但升级是有代价的。实验室里AI能让白领效率提升40%，但真实办公场景里这个数字只有8-15%。为什么？因为真实工作不是"写一封邮件"或"做一个PPT"，真实工作是"搞清楚老板到底想要什么"、"在三个互相矛盾的deadline里找到活路"、"在会议上用三句话把技术问题讲给不懂技术的领导听"——这些事情AI目前帮不上忙。
>
> 真正值得担心的不是"AI替代你"，而是"会用AI的人替代不会用AI的人"。这个区别很重要。前者是技术决定论，后者是能力竞争论。前者让你焦虑但无能为力，后者让你焦虑但可以行动。
