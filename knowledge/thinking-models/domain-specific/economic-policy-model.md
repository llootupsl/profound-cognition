# 经济政策分析模型 — 政策传导、市场响应与福利效应评估

> **模块标识**: `knowledge/thinking-models/domain-specific/economic-policy-model`
> **领域**: 经济政策、宏观经济、产业政策、公共财政、发展经济学
> **依赖**: `knowledge/thinking-models/general/systems-thinking`、`knowledge/thinking-models/general/multidimensional-framework`、`knowledge/thinking-models/general/critical-thinking`、`knowledge/research-methods`
> **关联**: 影响评估引擎、成本效益分析器、福利分配分析器、政策一致性检测器、二阶效应追踪器

---

## 1. 定义

经济政策分析模型是一套用于评估经济政策的传导机制、市场响应和福利效应的领域特化框架。它将每一项政策视为对复杂经济系统的一次定向干预，通过追溯政策从"纸面"到"实际影响"的完整传导链，评估政策的直接效果、间接效果、意外后果和分配效应。

**核心法则**: 判断一项政策，不看"它想做什么"，看"激励机制改变了什么"。

## 2. 七步政策分析流程

```
步骤1: 政策意图重构
  ├─ 政策名称与法律依据
  ├─ 明确宣称的政策目标
  ├─ 政策工具的选择（财政/货币/监管/信息/行为）
  ├─ 目标群体与覆盖范围
  └─ 政策的激励机制是什么？（谁被激励做什么？）
        │
步骤2: 传导链分析（从纸面到实际）
  ├─ 第一级传导: 政策直接改变的经济变量
  ├─ 第二级传导: 受直接影响的行为响应
  ├─ 第三级传导: 市场均衡调整
  ├─ 第四级传导: 宏观经济反馈
  └─ 每一级标注: 传导强度、时间滞后、不确定性
        │
步骤3: 市场响应预测
  ├─ 供需弹性分析: 价格/数量如何变化？
  ├─ 替代效应: 被规制行为会被什么替代？
  ├─ 套利可能: 政策是否存在可被套利的漏洞？
  ├─ 合规成本: 遵守政策的直接和间接成本
  └─ 地下经济: 政策是否会催生规避行为？
        │
步骤4: 福利效应与分配分析
  ├─ 总体福利: 社会总福利增加还是减少？
  ├─ 分配效应: 谁获益？谁受损？获益/受损机制是什么？
  ├─ 效率vs公平: 政策在效率与公平之间的权衡
  ├─ 纵向公平: 不同收入阶层的影响
  ├─ 横向公平: 同一阶层内的影响差异
  └─ 代际公平: 成本收益在不同代际间的分配
        │
步骤5: 二阶三阶效应追踪
  ├─ 直接效应: 政策第一轮影响
  ├─ 二阶效应: 市场/行为调整的反馈
  ├─ 三阶效应: 结构性变化与长期重塑
  ├─ 意外后果: 政策设计未预见的结果
  └─ 跨领域溢出: 对非目标领域的影响
        │
步骤6: 政策可行性检验
  ├─ 政治可行性: 政治阻力与支持分析
  ├─ 行政可行性: 执行能力的约束
  ├─ 财政可行性: 资金来源与可持续性
  ├─ 法律可行性: 法律依据与合规性
  └─ 社会可行性: 公众接受度
        │
步骤7: 替代方案生成与比较
  ├─ 识别政策工具箱中的替代工具
  ├─ 市场自发解决方案的可能性
  ├─ 无为而治的基准方案
  └─ 所有替代方案在同一框架下比较
```

## 3. 政策分类与工具匹配

### 3.1 政策五分类

| 类型 | 工具 | 传导机制 | 适用场景 | 局限性 |
|------|------|---------|---------|--------|
| **财政政策** | 税收、转移支付、公共支出 | 直接改变收入和支出 | 需求管理、再分配 | 政治摩擦大、时滞长 |
| **货币政策** | 利率、准备金、公开市场 | 改变信用的价格和可得性 | 通胀控制、周期平抑 | 零下限约束、分配效应 |
| **监管政策** | 准入限制、标准、处罚、补贴 | 改变行为约束和激励 | 外部性纠正、信息不对称 | 合规成本、监管俘获 |
| **信息政策** | 信息披露、警示标签、公共教育 | 改变信息和认知 | 不对称信息问题 | 效果有限、行为偏差影响 |
| **行为政策** | 默认选项、框架、社会规范 | 利用行为偏误引导选择 | 低成本大规模行为改变 | 家长主义争议、效果不确定 |

### 3.2 工具选择原则

```
最优工具应满足: 最小扭曲 + 最高效率 + 最低执行成本 + 最强政治可行性

匹配自检:
1. 市场失灵的根源是什么？→ 工具必须精准针对失灵根源
2. 工具会创造什么新的激励扭曲？→ 每种工具都创造自己的扭曲
3. 是否有比直接干预更轻的工具？→ 从信息/行为工具开始，渐进升级
```

## 4. 传导链分析模型

### 4.1 传导链结构

```
政策 → 变量1 → 行为1 → 市场调整 → 最终效果
  │       │       │        │
  ├─ 强化 ←───┼────────┼────────┤
  ├─ 削弱 ←───┼────────┼────────┤ 每一步都可能出现:
  └─ 偏移 ←───┼────────┼────────┤ - 传导中断（变量不敏感）
              │        │        │ - 行为替代（其他行为变化）
              └────────┴────────┤ - 价格过滤（弹性稀释）
                                │ - 时滞衰减（长期传导常数 < 短期）
```

### 4.2 传导衰减检查清单

对每一级传导检查：
1. 该级传导的弹性是多少？（1%政策变化 → ?%该级变量变化）
2. 是否存在抵消效应？（其他政策或市场力量反向作用）
3. 传导的辐射范围？（全部/大部分/部分/少数）
4. 传导的时间滞后？（即时/月/季/年）
5. 传导衰减了多少？（初始强度 → 最终强度之比）

**评估标准**: 如果三级传导后初始强度的残留率 < 30%，政策效果高度不确定。

## 5. 福利效应量化框架

### 5.1 福利三角分析

```
消费者剩余变化 ΔCS: 消费者福利变化
生产者剩余变化 ΔPS: 生产者福利变化
政府收入变化 ΔGR: 税收/补贴/支出净变化
外部性变化 ΔEXT: 正/负外部性的货币化估值
社会总福利变化 ΔTS = ΔCS + ΔPS + ΔGR + ΔEXT
```

### 5.2 公平性评估矩阵

| 群体 | 政策前状态 | 政策后状态 | 净变化 | 变化方向 |
|------|-----------|-----------|--------|---------|
| 最低20%收入 | ... | ... | ... | 获益/受损/中性 |
| 次低20%收入 | ... | ... | ... | 获益/受损/中性 |
| 中间20%收入 | ... | ... | ... | 获益/受损/中性 |
| 次高20%收入 | ... | ... | ... | 获益/受损/中性 |
| 最高20%收入 | ... | ... | ... | 获益/受损/中性 |

**公平性裁决**:
- 进步性政策: 净收益随收入递减（穷人获益比例 > 富人）
- 倒退性政策: 净收益随收入递增（富人获益比例 > 穷人）
- 中性政策: 净收益与收入无关

## 6. 意外后果检测框架

### 6.1 五类意外后果

| 类型 | 机制 | 检测方法 |
|------|------|---------|
| 回弹效应 | 效率提高→成本下降→需求增加→资源消耗反弹 | 检验长期弹性是否显著 > 短期弹性 |
| 替代效应 | 规制A → 行为人改用未规制B | 识别所有可替代方案，检查是否被覆盖 |
| 挤出效应 | 公共支出 → 替代私人支出而非补充 | 检验总支出（公共+私人）是增加还是仅转移 |
| 补偿行为 | 安全装置 → 风险行为增加 | 检验风险补偿弹性 |
| 科尔奈效应 | 软预算约束 → 效率下降 | 检验是否存在无法退出的救助预期 |

### 6.2 意外后果预防清单

```
□ 如果我是被规制者，我会如何规避这条政策？（套利思维）
□ 这项政策创造的最大激励是什么？它可能偏离目标吗？（激励校准）
□ 5年后这项政策可能以什么方式被扭曲？（伊什么尼克演化）
□ 政策失败时的退出机制是什么？（可逆性检验）
□ 谁会用这项政策装满自己的口袋？（寻租检测）
```

### 6.3 五类意外后果分类体系（详细机制与检测方法）

> **能力卡**: MC-173 Unintended-Consequences

#### 6.3.1 回弹效应（Rebound Effect）

```
机制链: 效率提高 → 单位成本下降 → 需求增加 → 资源消耗反弹
经典案例: 汽车燃油效率提高 → 驾驶里程增加 → 总油耗未降反升
量化检测:
  - 短期弹性 ε_s: 效率变化1% → 短期需求变化%
  - 长期弹性 ε_l: 效率变化1% → 长期需求变化%
  - 回弹率 R = (ε_l - ε_s) / ε_s × 100%
  - R > 50% → 严重回弹，政策效果大幅稀释
  - R > 100% → 逆火效应（Jevons悖论），政策适得其反
决策规则:
  - if 回弹率 R < 20% → 政策有效，回弹可忽略
  - if 20% ≤ R < 50% → 政策部分有效，需补充需求侧措施
  - if R ≥ 50% → 政策效果存疑，必须同时实施需求控制
```

#### 6.3.2 替代效应（Substitution Effect）

```
机制链: 规制行为A → 行为人转向未规制行为B → B的风险/成本可能更高
经典案例: 禁止酒精 → 地下私酿酒（甲醇中毒风险更高）
检测方法:
  1. 列出被规制行为的所有可替代方案（至少5个）
  2. 评估每个替代方案的风险/成本等级（1-5）
  3. 识别替代方案是否被政策覆盖
  4. 计算替代风险指数 SRI = Σ(替代方案风险 × 采纳概率)
决策规则:
  - if SRI < 被规制行为风险 → 替代效应可控
  - if SRI ≥ 被规制行为风险 → 替代效应抵消政策收益，需扩大规制范围
```

#### 6.3.3 挤出效应（Crowding Out Effect）

```
机制链: 公共支出增加 → 替代私人支出 → 总支出未增，仅从私人转公共
经典案例: 政府增加教育支出 → 家庭减少教育储蓄 → 总教育投入不变
检测方法:
  1. 计算政策前私人支出水平 P_before
  2. 计算政策后私人支出水平 P_after
  3. 计算公共支出增量 ΔG
  4. 挤出率 CR = (P_before - P_after) / ΔG
决策规则:
  - if CR < 0.3 → 挤出效应小，公共支出有效补充
  - if 0.3 ≤ CR < 0.7 → 部分挤出，需评估净增量
  - if CR ≥ 0.7 → 严重挤出，公共支出几乎完全替代私人支出
```

#### 6.3.4 补偿行为（Compensating Behavior / Peltzman Effect）

```
机制链: 安全装置/措施 → 感知风险降低 → 风险行为增加 → 实际风险反弹
经典案例: 汽车安全带 → 驾驶更激进 → 行人事故率上升
检测方法:
  1. 识别安全措施改变的风险感知（感知风险变化 ΔP_perceived）
  2. 估算风险补偿弹性（行为变化率 / 感知风险变化率）
  3. 计算净安全效应 = 直接安全收益 - 补偿行为增加的风险
决策规则:
  - if 净安全效应 > 0 → 安全措施总体有效
  - if 净安全效应 ≤ 0 → 安全措施被补偿行为完全抵消，需配套行为约束
```

#### 6.3.5 软预算约束（Soft Budget Constraint / Kornai Effect）

```
机制链: 救助预期 → 预算约束软化 → 效率下降 → 道德风险累积
经典案例: 国企亏损 → 政府补贴 → 缺乏改革动力 → 持续低效
检测方法:
  1. 识别是否存在"无法退出"的救助机制（财政补贴/信贷展期/隐性担保）
  2. 评估救助频率（连续N年获得补贴 → 软预算约束信号）
  3. 检测效率指标趋势（ROE/ROA是否持续下降但仍获资源）
  4. 计算软预算约束指数 SBCI = 补贴金额 / 经营亏损
决策规则:
  - if SBCI > 0.5 且持续 ≥ 3年 → 软预算约束确认
  - if SBCI > 0.8 → 严重软预算约束，需强制破产/重组机制
```

### 6.4 寻租检测预防清单

> **能力卡**: MC-173 Unintended-Consequences

```
寻租检测五问:
1. 政策是否创造了人为稀缺性？（许可证/配额/审批 → 租金来源）
2. 政策的合规成本是否构成进入壁垒？（高合规成本 → 保护在位者）
3. 政策执行者是否有自由裁量权？（裁量权 → 寻租机会）
4. 政策收益是否集中在少数人，成本分散在多数人？（集中收益+分散成本 → 最易寻租）
5. 政策是否有明确的日落条款？（无终止日期 → 寻租制度化风险）

寻租预防措施:
□ 尽量使用市场机制替代行政分配
□ 合规成本设定上限，定期审查是否过高
□ 自由裁量权必须有透明标准和申诉机制
□ 收益-成本分布必须公开评估
□ 所有政策必须有日落条款（默认5年到期，需主动续期）
```

## 7. 常见陷阱

1. **意图与效果混淆**: 用"政策想做什么"代替"政策实际做了什么"。**纠正**: 严格区分宣称目标与实际效果，后者必须基于证据而非意图。
2. **局部均衡思维**: 只分析政策对直接目标市场的影响，忽略一般均衡效应。**纠正**: 至少识别3个最可能被间接影响的相关市场。
3. **平均效应掩盖分布**: 只关注"平均效果"，忽略不同群体之间的异质性。**纠正**: 五等分公平性评估矩阵是强制输出项。
4. **政策可行性忽略**: 设计了"最优政策"但在政治/行政上完全不可行。**纠正**: 可行性检验是强制步骤，不可行政策必须标注为"理论预案"。
5. **基准方案缺失**: 评估政策效果时只用政策前作为比较基准，忽略"不实施此政策"的演进路径。**纠正**: 构建"无为而治"的基准方案，政策效果 = 政策路径 - 基准路径。

## 9. 内化方法论：福利传导分析（Welfare-Transmission）

### 方法论原理

福利传导分析的核心公式为 **ΔTS = ΔCS + ΔPS + ΔGR + ΔEXT**，即社会总福利变化等于消费者剩余变化、生产者剩余变化、政府收入变化与外部性变化之和。这一方法论之所以必要，是因为政策评估中最常见的错误是"选择性核算"——只计算政策对目标群体的影响而忽略其他福利分量。例如，价格管制可能增加了消费者剩余（ΔCS > 0），但同时减少了生产者剩余（ΔPS < 0）和政府收入（ΔGR < 0），且可能产生短缺的外部性成本（ΔEXT < 0），净效果可能是负的。福利三角公式强制要求所有分量必须被显式评估，防止选择性失明。

### 执行步骤

1. **界定政策前基准**：记录政策实施前的市场均衡状态（均衡价格 P₀、均衡数量 Q₀），计算基准消费者剩余 CS₀ = ∫[P₀, P_max] D(p)dp、基准生产者剩余 PS₀ = ∫[P_min, P₀] (P₀ - S(p))dp、基准政府收入 GR₀、基准外部性 EXT₀
2. **预测政策后新均衡**：根据政策对供需曲线的位移/旋转，计算新均衡（P₁, Q₁），标注位移来源（税收左移供给、补贴右移需求、管制改变斜率等）
3. **计算ΔCS**：ΔCS = CS₁ - CS₀ = ∫[P₁, P_max] D(p)dp - ∫[P₀, P_max] D(p)dp。若需求曲线为线性 D(p) = a - bp，则 ΔCS = (P₀ - P₁)(Q₁ + Q₀)/2
4. **计算ΔPS**：ΔPS = PS₁ - PS₀。若供给曲线为线性 S(p) = c + dp，则 ΔPS = (P₁ - P₀)(Q₁ + Q₀)/2
5. **计算ΔGR**：ΔGR = 政策后政府净收入 - 政策前政府净收入。税收场景：ΔGR = t × Q₁（t为单位税额）；补贴场景：ΔGR = -s × Q₁（s为单位补贴额）；管制场景：ΔGR = 合规收费 - 执法成本
6. **计算ΔEXT**：ΔEXT = 外部性货币化值的变化。正外部性增加（如教育补贴的社会回报）→ ΔEXT > 0；负外部性减少（如碳排放税减少排放）→ ΔEXT > 0；负外部性增加 → ΔEXT < 0。货币化方法：社会成本法（SCC）、支付意愿法（WTP）、疾病成本法（COI）
7. **汇总ΔTS**：ΔTS = ΔCS + ΔPS + ΔGR + ΔEXT。若 ΔTS > 0，政策净增福利；若 ΔTS < 0，政策净损福利；若 ΔTS ≈ 0，政策为纯再分配
8. **分配效应检验**：即使 ΔTS > 0，仍需检验福利增量在不同群体间的分配。计算各收入五等分群体的 ΔCS_i、ΔPS_i、ΔGR_i、ΔEXT_i，判定政策是进步性/倒退性/中性

### 决策规则

| 条件 | 判定 | 行动 |
|------|------|------|
| ΔTS > 0 且分配进步性 | 强力支持 | 政策兼具效率与公平，建议实施 |
| ΔTS > 0 但分配倒退性 | 有条件支持 | 政策有效率但需配套再分配措施补偿受损群体 |
| ΔTS ≈ 0 且分配进步性 | 再分配支持 | 政策为纯再分配且方向正确，基于公平理由支持 |
| ΔTS ≈ 0 且分配倒退性 | 反对 | 政策既无效率增益又加剧不平等 |
| ΔTS < 0 但分配进步性 | 争议性 | 效率损失但公平改善，需评估社会对效率-公平权衡的偏好 |
| ΔTS < 0 且分配倒退性 | 强力反对 | 政策既损效率又损公平 |
| 任一分量数据不可得 | 穷尽重试评估 | 缺失分量标注为"未量化"，ΔTS 标注为"部分估算"，置信度穷尽重试 |
| ΔEXT 货币化方法争议大 | 敏感性分析 | 使用3种货币化方法分别计算，报告结果范围而非点估计 |

## 10. 内化方法论：公平分配分析（Fairness-Distribution）

### 方法论原理

公平分配分析的方法论基础是：**效率分析回答"饼有多大"，公平分析回答"饼怎么分"——两者缺一不可**。即使一项政策增加了总福利，如果增量全部流向最富有的20%群体，该政策在分配正义层面仍可能是不正当的。本方法论通过收入五等分分析、基尼系数计算和代际/区域公平评估，系统性地检验政策的分配效应。分配正义四原则（平等主义、功利主义、罗尔斯主义、应得主义）提供了不同的评判标准，同一政策在不同原则下可能得到截然不同的评价，因此必须显式声明所采用的原则并说明理由。

### 执行步骤

1. **收入五等分法分析**：将受影响人群按收入从低到高排列，等分为五组（Q1最低-Q5最高），计算每组的政策前收入份额和政策后收入份额，计算每组因政策导致的净收入变化（绝对值和占组收入比例）
2. **基尼系数计算**：
   - 方法一（几何法）：G = 1 - 2∫₀¹ L(p)dp，其中 L(p) 为洛伦兹曲线
   - 方法二（代数法）：G = (2/n²μ) Σᵢ<ⱼ (yⱼ - yᵢ)，其中 n 为样本量，μ 为均值，yᵢ 为个体收入
   - 方法三（协方差法）：G = 2cov(yᵢ, rᵢ)/(nμ)，其中 rᵢ 为收入排序
   - 计算政策前 G₀ 和政策后 G₁，ΔG = G₁ - G₀
3. **代际公平评估**：识别政策成本和收益在代际间的分配——当前代承担成本 vs 后代享受收益（如基础设施投资），或当前代享受收益 vs 后代承担成本（如环境破坏）。计算各代的净现值 NPV_gen = Σ(收益_t - 成本_t)/(1+r)^t，使用社会贴现率（通常1-3%，而非市场贴现率）
4. **区域公平评估**：按地理区域分解政策影响，计算各区域的净收益/净损失，识别区域间是否存在系统性偏差（如城市获益而农村受损）。计算区域基尼系数 G_region 评估区域分配不均度
5. **分配正义四原则检验**：
   - **平等主义原则**：所有群体的净收益是否相等？→ 计算各群体净收益的方差，方差越小越平等
   - **功利主义原则**：总福利是否最大化？→ 已由ΔTS判定
   - **罗尔斯主义原则**：最不利群体（Q1）是否获益？→ 若 Q1 净收益 > 0 则通过
   - **应得主义原则**：收益是否与贡献/努力匹配？→ 评估政策收益是否流向"应得者"
6. **综合公平裁定**：根据所采用的主导原则（默认罗尔斯主义，但需显式声明），给出政策的公平性裁定

### 决策规则

| 条件 | 判定 | 行动 |
|------|------|------|
| ΔG < 0（基尼系数下降） | 分配改善 | 政策减少不平等，公平性正面 |
| ΔG ≈ 0（基尼系数不变） | 分配中性 | 政策未改变不平等程度 |
| ΔG > 0（基尼系数上升） | 分配恶化 | 政策加剧不平等，需配套补偿措施 |
| Q1 净收益 > 0（罗尔斯通过） | 弱势群体获益 | 即使总分配恶化，最不利者获益仍具正当性 |
| Q1 净收益 < 0 且 Q5 净收益 > 0 | 倒退性分配 | 政策使富人更富、穷人更穷，强烈反对 |
| 代际 NPV 某代 < 0 | 代际不公平 | 受损代需通过跨代转移支付获得补偿 |
| 区域基尼系数上升 | 区域不平衡加剧 | 需区域补偿机制或政策调整 |
| 四原则判定结果矛盾 | 原则冲突 | 显式列出各原则下的判定，由决策者选择价值立场 |

## 11. 内化方法论：传导衰减分析（Transmission-Attenuation）

### 方法论原理

传导衰减分析的核心洞察是：**政策从纸面到实际效果的传导过程中，初始意图会经历系统性衰减，且衰减不是随机的而是由5种可识别的机制驱动的**。如果不显式检测和量化这些衰减机制，政策评估将系统性地高估政策效果。5种衰减机制为：(1) 弹性衰减——目标变量对政策工具的弹性低于预期；(2) 替代衰减——行为人转向未受政策影响的替代方案；(3) 时滞衰减——传导时间过长导致政策效果被其他变化淹没；(4) 抵消衰减——其他政策或市场力量反向作用；(5) 适应性衰减——行为人随时间适应政策，初始效果逐渐消退。残留率 = 最终效果/初始预期效果，是衡量传导效率的核心指标。

### 执行步骤

1. **绘制完整传导链**：从政策工具到最终目标，标注每一级传导节点：政策工具 → 中间变量₁ → 中间变量₂ → ... → 最终目标变量
2. **逐级检测5种衰减机制**：
   - **弹性衰减检测**：对每级传导，估计该级弹性 εᵢ = (%Δ输出变量)/(%Δ输入变量)。若 εᵢ < 0.5，标记为"高弹性衰减"；若 0.5 ≤ εᵢ < 0.8，标记为"中弹性衰减"；若 εᵢ ≥ 0.8，标记为"低弹性衰减"
   - **替代衰减检测**：对每级传导，识别行为人的替代方案列表。若存在低成本替代方案，标记为"高替代衰减"；若替代方案存在但成本较高，标记为"中替代衰减"；若无可行替代方案，标记为"低替代衰减"
   - **时滞衰减检测**：对每级传导，估计传导时间 tᵢ。若总传导时间 Σtᵢ > 政策有效期50%，标记为"高时滞衰减"；若 20%-50%，标记为"中时滞衰减"；若 < 20%，标记为"低时滞衰减"
   - **抵消衰减检测**：对每级传导，检查是否存在反向政策或市场力量。若存在强反向力（方向相反且量级 > 50%），标记为"高抵消衰减"；若存在弱反向力（量级 < 50%），标记为"中抵消衰减"；若无反向力，标记为"低抵消衰减"
   - **适应性衰减检测**：对每级传导，评估行为人适应政策的速度。若适应期 < 政策有效期30%，标记为"高适应性衰减"；若 30%-60%，标记为"中适应性衰减"；若 > 60%，标记为"低适应性衰减"
3. **计算逐级残留率**：对每级传导，残留率 Rᵢ = εᵢ × (1 - 替代衰减系数) × (1 - 时滞衰减系数) × (1 - 抵消衰减系数) × (1 - 适应性衰减系数)。总残留率 R_total = Π Rᵢ
4. **三级残留率预警判定**：根据总残留率 R_total 判定预警等级
5. **设计补偿策略**：针对每种已识别的衰减机制，设计对应的补偿策略
6. **重新估算政策效果**：政策实际效果 = 初始预期效果 × R_total

### 决策规则

| 残留率 R_total | 预警等级 | 含义 | 行动 |
|----------------|---------|------|------|
| R_total ≥ 70% | 绿灯 | 传导高效，衰减可控 | 正常推进，常规监测 |
| 40% ≤ R_total < 70% | 黄灯 | 传导中等衰减，需关注 | 识别主要衰减源，设计针对性补偿策略 |
| R_total < 40% | 红灯 | 传导严重衰减，政策效果高度不确定 | 重新评估政策工具选择，考虑替代方案或增加政策力度 |

| 衰减机制 | 主要衰减源 | 补偿策略 |
|---------|-----------|---------|
| 弹性衰减 | 目标变量对工具不敏感 | 增加工具力度或更换更敏感的工具 |
| 替代衰减 | 行为人有低成本替代方案 | 扩大政策覆盖范围，堵住替代通道 |
| 时滞衰减 | 传导链过长 | 缩短传导链或使用前置指标监测 |
| 抵消衰减 | 反向政策/市场力量 | 协调政策一致性或对冲反向力量 |
| 适应性衰减 | 行为人快速适应 | 设计动态调整机制或定期更新政策参数 |

| L2 部分量化 | 部分级传导数据可得，其余需估计 | 对有数据的级精确计算，对无数据的级使用典型值范围估算（如弹性0.3-0.7），输出残留率区间 |
| L3 定性评估 | 仅知传导链结构，无量值数据 | 对每级标注5种衰减机制的定性等级（高/中/低），用最差情况估算残留率下界 |
| L4 类比推断 | 无本政策传导数据 | 引用同类型政策的历史传导效率研究，标注"类比推断" |
