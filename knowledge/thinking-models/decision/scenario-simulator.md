# 场景推演与替代方案生成引擎 -- 决策分析系统的动态演化模拟中枢

> **模块标识**: `knowledge/thinking-models/decision/scenario-simulator`
> **职责**: 作为决策分析系统的动态演化模拟中枢，负责对决策选项进行多情景推演、替代方案生成、决策树构建和敏感性分析，与 `knowledge/thinking-models/decision/decision-matrix` 双向互动，共同构成完整的决策分析体系
> **依赖**: `knowledge/thinking-models/decision/decision-matrix`、`knowledge/research-methods`、`knowledge/cognitive-framework`
> **核心能力**: 场景模拟（最佳/最坏/最可能三情景）、替代方案生成（5种策略×3方案）、决策树构建、蒙特卡洛仿真、敏感性分析、动态反馈适配

## 一、模块定位

### 1.1 在决策框架中的角色

```
decision-matrix (核心引擎)
 │
 ├── 维度一~五评估 ──── 量化评分与排名
 │
 └── 双向调用 场景模拟、替代方案、决策树、敏感性分析
 │
 ┌──────────────────────────────────────┐
 │ scenario-simulator (本模块) │
 │ │
 │ ┌────────────┬──────────┬──────────┐ │
 │ │ 场景模拟 │ 替代方案 │ 决策树 │ │
 │ │ (三情景) │ (5策略) │ (多级) │ │
 │ ├────────────┼──────────┼──────────┤ │
 │ │ 蒙特卡洛 │ 敏感性 │ 动态 │ │
 │ │ 仿真 │ 分析 │ 反馈 │ │
 │ └────────────┴──────────┴──────────┘ │
 └──────────────────────────────────────┘
```

### 1.2 核心处理流程

```
决策选项输入 → 确定性等级评估(1-5) → 触发对应推演深度
 │
 ├── 确定性高(4-5): 基础三情景推演
 ├── 确定性中(2-3): 增强推演（5情景+决策树+敏感性分析）
 └── 确定性低(1): 深度推演（全部能力激活+蒙特卡洛仿真）
 │
 └── 推演结果 → 场景评估 → 替代方案生成 → 反馈至 decision-matrix
```

## 二、多情景推演引擎

### 2.1 基本三情景推演框架

| 情景类型 | 乐观权重 | 中性权重 | 悲观权重 |
|---------|---------|---------|---------|
| 确定性高(4-5) | 0.25 | 0.50 | 0.25 |
| 确定性中(2-3) | 0.30 | 0.40 | 0.30 |
| 确定性低(1) | 0.35 | 0.30 | 0.35 |

#### 期望值计算

```
E(D) = W_opt × V_opt + W_neu × V_neu + W_pes × V_pes
```

#### 情景偏离度

```
SD = max(|V_opt - V_neu|, |V_pes - V_neu|)
SD >= 30 → 高风险选项，建议增加场景推演
```

### 2.2 深度增强推演流程

```
步骤1: 确定基准假设 → 步骤2: 定义变量范围 → 步骤3: 三情景定量推演
步骤4: 敏感度分析 → 步骤5: 情景偏离度评估 → 步骤6: 生成推演报告
```

#### 推演变量清单

每个情景推演至少覆盖：宏观经济变量、行业趋势变量、竞争格局变量、技术发展变量、政策监管变量。

### 2.3 蒙特卡洛仿真

#### 触发条件
仅当确定性等级 == 1 时执行。仿真迭代次数: 1000-5000次（根据变量复杂度自适应）。

#### 实现步骤
1. 识别关键不确定变量
2. 为每个变量定义概率分布（正态/均匀/三角/对数正态/指数）
3. 独立随机抽样生成输入组合
4. 对每组输入执行推演，记录输出分布
5. 计算统计量（均值、标准差、置信区间、在险值）

#### 输出分布解读
```
分布形态:
正态 → 结果集中在均值附近，确定性较高 | 高峰态 → 结果高度集中
长尾 → 存在极端可能性，需关注 | 双峰 → 存在两种不同的可能状态
平坦 → 高度不确定，各结果可能性相近
```

## 三、替代方案生成引擎

### 3.1 五种生成策略

| 策略 | 目标 | 生成逻辑 |
|------|------|---------|
| 极端策略 | 追求最大可能收益 | 将所有优势最大化 |
| 保守策略 | 追求最大安全保障 | 将所有风险最小化 |
| 折中策略 | 平衡收益与风险 | 取各选项优点的中间值 |
| 创新策略 | 探索新可能性 | 引入原方案框架外的元素 |
| 逆向策略 | 从目标反推路径 | 从理想结果反推实现路径 |

### 3.2 替代方案评估框架

#### 三维评估维度

```
新颖度评分 = Σ(与新框架元素占比 × 可行性) | 可行性评分 = Σ(实施条件满足度 × 权重)
协同度评分 = Σ(与原最优方案互补度 × 权重)
综合评分 = 0.35×新颖度 + 0.35×可行性 + 0.30×协同度
```

#### 评估结果处理

综合评分 >= 70 → 推荐纳入候选（标记为 RECOMMENDED）
综合评分 50-69 → 可选纳入（标记为 OPTIONAL）
综合评分 < 50 → 仅供参考（标记为 REFERENCE）

## 四、决策树构建

### 4.1 决策树结构规范

```
节点类型:
□ 决策节点（正方形）- 需要做出选择
○ 机会节点（圆形）- 存在不确定性
△ 结果节点（三角形）- 最终收益/成本值

路径标注: 决策路径(实线)、概率(0-1)、收益/成本
```

### 4.2 期望值计算

```
叶节点值 = 收益 - 成本
机会节点值 = Σ(P_i × 子节点值_i)
决策节点值 = max(各分支值)

遍历算法: 后序遍历，从叶节点向根节点计算
```

### 4.3 规则系统

| 规则 | 说明 |
|------|------|
| 最大深度 <= 5层 | 从根到叶的边数，防组合爆炸 |
| 同级备选数量 <= 5 | 每个决策节点的备选分支数 |
| 同级结果状态数量 <= 5 | 每个机会节点的可能结果数 |
| 概率批量 != 0 | 所有分支的概率必须非零 |
| 同级概率之和 = 1.0 | 同父节点的机会子节点概率和 |

## 五、双向接口规范

### 5.1 decision-matrix → scenario-simulator 请求

| 条件 | 请求类型 |
|------|---------|
| 确定性>=4 | 基础三情景 + 替代方案 |
| 确定性2-3 | 增强五情景 + 决策树 + 敏感性分析 + 替代方案 |
| 确定性==1 | 全深度（蒙特卡洛+增强推演+决策树+敏感性+替代方案） |

### 5.2 scenario-simulator → decision-matrix 回传

场景模拟结果 → 更新综合评分中"长期影响"维度的不确定性权重
情景偏离度 → 触发"风险评估"维度加成
替代方案 → 纳入"利弊分析"维度的比较基准
敏感性分析 → 标记关键变量供长期影响维度分析

## 六、质量自检清单

- 所有选项均执行情景推演
- 情景推演变量 >= 3，有具体数据和逻辑链条
- 推演至少覆盖最佳/最坏/最可能三种情景
- SD >= 30 时已增加推演深度
- 决策树已生成，节点属性正确
- 替代方案 >= 3，新颖度/可行性/协同度均已评分
- 概率和为1.0，期望值计算正确
- 输出标注了确定性等级、置信区间、关键假设

## 八、场景推演决策规则（MC-145 Scenario-Expected-Value / MC-146 Monte-Carlo-Decision-Tree）

| 条件 | 判定 | 行动 |
|------|------|------|
| 情景偏离度 SD ≥ 30 | 高风险选项 | 增加推演深度至5情景+决策树+敏感性分析 |
| 情景偏离度 SD < 15 | 低风险选项 | 基础三情景推演即可 |
| 确定性等级 = 1 | 极高不确定性 | 触发蒙特卡洛仿真（1000-5000次迭代） |
| 确定性等级 2-3 | 中等不确定性 | 增强推演（5情景+决策树+敏感性分析） |
| 确定性等级 4-5 | 低不确定性 | 基础三情景推演 |
| 期望值 E(D) > 0 且 SD < 30 | 正期望可接受 | 推荐执行，标注关键假设 |
| 期望值 E(D) < 0 | 负期望 | 不推荐执行，除非有非量化因素补偿 |
| 蒙特卡洛双峰分布 | 两种可能状态 | 拆分为两个子场景独立分析 |
| 蒙特卡洛长尾分布 | 极端可能性存在 | 评估在险值（VaR），制定极端情况预案 |
| 决策树最大深度 > 5层 | 组合爆炸风险 | 截断至5层，标注"深度截断" |
| 替代方案综合评分 ≥ 70 | 推荐纳入 | 标记为 RECOMMENDED |
| 替代方案综合评分 < 50 | 仅供参考 | 标记为 REFERENCE |

| 重试层级 | 条件 | 替代方案 |

## 十一、STEEP场景分析（MC-165 STEEP-Scenario）

### 方法论原理

STEEP场景分析的方法论基础是：**宏观环境变化是所有决策的背景条件，忽略宏观趋势的决策如同在移动的地板上建造房屋**。STEEP框架（Social社会、Technological技术、Economic经济、Environmental环境、Political政治）提供了系统化的宏观环境扫描结构，确保场景推演不遗漏关键外部驱动力。这一方法论之所以必要，是因为最常见的场景分析失败是"微观近视"——只关注行业/组织内部变量，忽略宏观环境变化对决策前提的根本性改变。

### 执行步骤

1. **STEEP五维扫描**：对每个维度识别3-5个关键趋势和1-2个潜在突变
2. **趋势交叉分析**：识别不同维度趋势之间的交互效应（如技术趋势×经济趋势）
3. **关键不确定性识别**：从趋势中提取2-3个最大不确定性作为场景轴
4. **场景构建**：基于关键不确定性构建2×2或3×3场景矩阵
5. **场景叙事**：为每个场景编写完整叙事，包含因果链和时序逻辑

### 决策规则

| STEEP维度 | 趋势确定性 | 分析深度 |
|-----------|-----------|---------|
| 高确定性趋势 | 确定性 > 80% | 纳入所有场景的基准假设 |
| 中等不确定性 | 确定性 40-80% | 作为场景分化的关键轴 |
| 高不确定性 | 确定性 < 40% | 构建极端场景的触发条件 |

### 输出规范

```yaml
steep_scenario:
  dimensions:
    social: {trends: ["趋势"], disruptions: ["突变"]}
    technological: {trends: ["趋势"], disruptions: ["突变"]}
    economic: {trends: ["趋势"], disruptions: ["突变"]}
    environmental: {trends: ["趋势"], disruptions: ["突变"]}
    political: {trends: ["趋势"], disruptions: ["突变"]}
  key_uncertainties: ["关键不确定性"]
  scenario_matrix:
    - name: "场景名称"
      axis_values: {axis1: "值", axis2: "值"}
      narrative: "场景叙事"
      probability: 0.0-1.0
      implications: ["对决策的影响"]
```

### 穷尽重试策略

| 重试层级 | 条件 | 替代方案 |
|---------|------|---------|
| L1 完整STEEP+场景矩阵 | 五维趋势均可评估 | 完整5步，输出场景矩阵和叙事 |
| L2 部分STEEP扫描 | 部分维度数据不可得 | 对可得维度做完整分析，缺失维度标注"未扫描" |
| L3 趋势列举 | 无法做交叉分析 | 仅列举各维度关键趋势，标注"无交叉分析" |
| L4 直觉场景 | 无STEEP数据 | 基于经验构建直觉场景，标注"无STEEP基础" |

## 十二、决策树期望值分析（MC-167 Decision-Tree-EV）

### 决策规则

| 条件 | 判定 | 行动 |
|------|------|------|
| 最优路径期望值 > 次优路径20%+ | 明确最优 | 推荐最优路径，标注关键假设 |
| 最优与次优路径差距 < 10% | 路径接近 | 标注"高度接近"，结合场景分析决策 |
| 所有路径期望值 < 0 | 全部负期望 | 不推荐任何路径，重新定义问题 |
| 机会节点概率不确定（±20%） | 敏感性高 | 触发敏感性分析，识别概率阈值 |
| 决策节点含不可逆选择 | 不可逆决策 | 增加延迟选项（等待更多信息），标注"不可逆" |

### 穷尽重试策略

| 重试层级 | 条件 | 替代方案 |
|---------|------|---------|
| L1 完整决策树 | 概率和收益均可量化 | 完整决策树+期望值回溯计算 |
| L2 定性决策树 | 收益不可量化 | 使用定性评分（+3到-3），标注"定性决策树" |
| L3 决策节点列举 | 无法构建完整树 | 仅列举关键决策节点和选项，标注"无树结构" |
| L4 决策选项清单 | 仅知选项 | 列举选项和基本利弊，标注"无树分析" |

> 知识来源: MC-167 Decision-Tree-EV

## 十三、替代方案评估（MC-168 Alternative-Assessment）

### 决策规则

| 条件 | 判定 | 行动 |
|------|------|------|
| 替代方案综合评分 ≥ 70 | 推荐纳入候选 | 标记 RECOMMENDED，纳入决策矩阵 |
| 替代方案综合评分 50-69 | 可选纳入 | 标记 OPTIONAL，视资源情况决定 |
| 替代方案综合评分 < 50 | 仅供参考 | 标记 REFERENCE，不纳入正式评估 |
| 替代方案与原方案高度互补 | 协同效应 | 评估组合方案的综合效果 |
| 替代方案与原方案高度冲突 | 互斥关系 | 仅选择其一，或寻找折中方案 |

### 穷尽重试策略

| 重试层级 | 条件 | 替代方案 |
|---------|------|---------|
| L1 完整三维评估 | 新颖度/可行性/协同度均可评分 | 完整三维评分+综合排名 |
| L2 二维评估 | 仅可评估两个维度 | 评估可得维度，缺失维度给默认中值50，标注"部分评估" |
| L3 定性评估 | 无法量化评分 | 做定性优劣势分析，标注"定性评估" |
| L4 方案列举 | 仅可生成方案 | 列举方案和基本描述，标注"无评估" |

> 知识来源: MC-168 Alternative-Assessment
