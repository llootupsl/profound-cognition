# 类比推理模型 — 从已知领域到未知领域的结构映射

> **模块标识**: `knowledge/thinking-models/general/analogical-reasoning`
> **来源**: Gentner 结构映射理论、T04（比较分析）、T15b（跨域共振分析）
> **依赖**: `knowledge/thinking-models/general/critical-thinking`、`knowledge/thinking-models/general/first-principles`、`knowledge/research-methods`
> **父模型**: `knowledge/thinking-models/general/critical-thinking`

---

## 1. 定义

类比推理（Analogical Reasoning）是一种从已知领域（源域）的结构关系映射到未知领域（目标域）的推理方法。它不是简单的属性相似性匹配，而是深层结构关系的迁移——当两个领域在高阶关系上具有同构性时，源域中已验证的因果机制和解决方案可以迁移到目标域。Gentner 的结构映射理论指出：关系映射优先于属性映射，系统性映射优先于孤立映射。

**核心法则**: 有效的类比不是"看起来像"，而是"关系结构同构"——源域中的因果机制在目标域中是否仍然成立，是类比有效性的最终判据。

---

## 2. 核心概念

| 概念 | 定义 | 示例 |
|------|------|------|
| **源域** | 已有充分知识和验证结论的领域 | "生物免疫系统"作为源域 |
| **目标域** | 需要理解或解决问题的领域 | "计算机网络防御"作为目标域 |
| **结构关系** | 领域内部元素之间的因果、功能、层级等关系 | "抗体识别并中和入侵者" |
| **属性映射** | 表面特征的对应（颜色、大小、材质等） | "都是'防御系统'"——属性级类比，较弱 |
| **关系映射** | 深层结构的对应（因果、功能、系统等） | "识别→响应→记忆"——关系级类比，较强 |
| **系统性原则** | 互相关联的关系网络比孤立关系更值得映射 | 完整的免疫应答链比单个"识别"关系更可靠 |
| **映射有效性** | 类比迁移的结论在目标域中是否成立 | 免疫类比能否预测网络防御的未知现象 |

## 3. 执行流程

```
问题输入 → 识别源域 → 提取结构关系 → 映射到目标域 → 验证映射有效性
    │          │            │              │               │
    ▼          ▼            ▼              ▼               ▼
 定义目标域  搜索已知领域  关系优先提取   逐关系映射     三个层级验证
 的核心问题  中的结构     属性映射穷尽重试   标注映射强度   输出映射报告
            相似领域
```

### 3.1 步骤一：识别源域

1. **提取目标域核心关系**: 目标域中的关键问题是什么？涉及哪些核心关系？
2. **搜索候选源域**: 在已知领域中搜索具有相似关系结构的领域
3. **源域筛选标准**:
   - 源域的核心关系已被充分验证
   - 源域与目标域在关系层面具有结构同构性
   - 源域的知识深度足以支撑映射
4. **多源域策略**: 至少识别2个候选源域，避免单一类比偏误

### 3.2 步骤二：提取结构关系

遵循 Gentner 结构映射理论的三条原则：

**原则一：关系优先原则**
```
映射优先级: 因果关系 > 功能关系 > 时序关系 > 空间关系 > 属性相似
示例: "病毒入侵→免疫识别→抗体产生→免疫记忆"（因果链）
      优先于 "都是'系统'"（属性）
```

**原则二：系统性原则**
```
互相关联的关系网络 > 孤立的关系对
示例: 完整的"识别→响应→记忆→适应"链
      优先于 单独的"识别"关系
```

**原则三：一一对应原则**
```
源域和目标域的元素映射应为一一对应，避免多对一或一对多
示例: 源域的"抗体" → 目标域的"防火墙规则"（一一对应）
      而非 源域的"抗体+T细胞" → 目标域的"防火墙"（多对一，映射模糊）
```

### 3.3 步骤三：映射到目标域

1. **逐关系映射**: 将源域的每个核心关系映射到目标域
2. **标注映射强度**:

| 映射强度 | 定义 | 判定标准 |
|---------|------|---------|
| 强映射 | 关系结构完全同构 | 因果机制、功能角色、时序逻辑均对应 |
| 中映射 | 关系结构部分同构 | 核心关系对应，但存在1-2处结构差异 |
| 弱映射 | 仅有属性相似 | 表面特征相似，但深层关系不同 |
| 伪映射 | 表面相似但结构冲突 | 属性相似但因果机制矛盾 |

3. **映射冲突处理**: 当映射出现冲突时，不强行映射，标注为"映射断裂点"
4. **创新性映射**: 映射不仅是复制，还可以在目标域中发现源域未显化的新关系

### 3.4 步骤四：验证映射有效性

三个层级的验证：

**层级一：内部一致性验证**
```
目标域中映射后的关系网络是否自洽？
- 映射后的因果链是否完整？
- 映射后的系统行为是否符合目标域已知事实？
```

**层级二：预测力验证**
```
类比映射能否在目标域中生成可验证的新预测？
- 从源域迁移的机制能否预测目标域的未知现象？
- 预测是否可证伪？
```

**层级三：边界条件验证**
```
类比在什么条件下会失效？
- 源域和目标域的关键差异是什么？
- 这些差异是否会导致映射失效？
- 映射的有效边界在哪里？
```

## 4. 常见陷阱

1. **属性类比偏误**: 基于表面属性相似性进行类比，忽略深层结构差异。**纠正**: 强制执行关系优先原则，属性映射必须穷尽重试处理。
2. **单一类比依赖**: 只使用一个源域进行类比，忽视替代类比可能得出不同结论。**纠正**: 至少使用2个候选源域，比较不同类比的结论一致性。
3. **过度映射**: 将源域的所有特征都映射到目标域，包括不适用的部分。**纠正**: 每个映射必须标注映射强度，弱映射和伪映射不得作为推理依据。
4. **忽略映射断裂**: 发现映射冲突后仍强行推理。**纠正**: 映射断裂点是强制输出项，必须分析断裂原因并评估对结论的影响。
5. **类比结论当作事实**: 类比推理的结论是假说性质，需要独立验证。**纠正**: 每个类比结论必须附带"独立验证路径"。

## 6. 与任务节点的协同

### 6.1 与 T04（比较分析）的集成

当 T04 执行比较分析时，类比推理作为发现跨领域结构相似性的核心方法：
- T04 的比较维度设计可参考类比推理的关系映射结果
- 类比推理的"结构同构"判定为 T04 的比较提供深层依据
- T04 中发现的差异点可反馈为类比推理的"映射断裂点"

### 6.2 与 T15b（跨域共振分析）的集成

当 T15b 执行跨域共振分析时，类比推理框架提供结构化分析工具：
- T15b 的"共振"概念对应类比推理的"结构同构"
- 类比推理的映射强度分级为 T15b 的共振强度评估提供量化标准
- T15b 的跨域迁移建议基于类比推理的映射有效性验证结果

### 6.3 与第一性原理的互补

- 第一性原理将问题拆解到公理层，寻找不可再分的基本事实
- 类比推理在关系层寻找跨域同构，将已知机制迁移到新领域
- 两者结合：先用第一性原理确认目标域的基本结构，再用类比推理从源域迁移解决方案

  exhaust-retry: "无历史案例库时，跳过 CBR 循环，仅输出类比推理结论"

### 7.4 MC-184 ABLkit-CBRkit 4要素内化

**方法论原理**：类比推理是跨域知识迁移的核心机制，CBR(Case-Based Reasoning)通过检索相似案例来推理新问题。ABLkit提供SME/FAM算法进行量化结构映射，CBRkit提供案例推理四步循环（检索→复用→修正→保留），两者结合实现了从"直觉类比"到"算法化类比推理"的升级。

**执行步骤**：
1. 问题表征：提取目标域问题的关键特征，编码为命题网络结构
2. 案例检索：从历史案例库中计算相似度（结构相似度+语义相似度+上下文相似度），检索最相似案例
3. 案例适配：分析源域与目标域的差异→生成适配规则→将源域解决方案迁移到目标域
4. 方案验证：对适配后的方案执行约束检查，验证是否满足目标域的边界条件和约束
5. 案例存储：将验证通过的新案例入库，附元数据（问题描述、解决方案、效果评估）

**决策规则**：
- if 相似度>0.8 → 直接复用（源域方案几乎完全适用目标域）
- if 0.5<相似度<0.8 → 适配修改（需要调整源域方案以适应目标域差异）
- if 相似度<0.5 → 抽象层推理（放弃具体案例映射，在更高抽象层寻找结构对应）

**输出规范**：
```yaml
cbr_analysis:
  problem_representation: {key_features: [str], proposition_network: str}
  case_retrieval:
    - case_id: str
      source_domain: str
      similarity_score: float
      similarity_breakdown: {structural: float, semantic: float, contextual: float}
  case_adaptation:
    - source_case: str
      adaptation_rules: [{difference: str, adaptation: str}]
      adapted_solution: str
  verification: {constraints_checked: [str], passed: bool, violations: [str]}
  case_storage: {stored: bool, case_id: str, metadata: dict}
  degradation_note: str|null
```

**穷尽重试策略**：L1 CBR完整推理（ABLkit SME/FAM映射+CBRkit四步循环+约束验证）→L2 手动案例检索（人工识别相似案例+手动适配，无算法化映射）→L3 类比映射（仅识别源域-目标域的结构对应关系，无案例库支持）→L4 纯文字类比（直觉类比推理，无系统化方法，标注method='intuitive')

## 8. 结构映射决策规则（MC-151 Structural-Mapping）

| 条件 | 判定 | 行动 |
|------|------|------|
| 映射强度为"强映射" | 结构同构可靠 | 可作为推理依据，输出类比结论 |
| 映射强度为"中映射" | 部分同构 | 可作为辅助推理，标注"部分结构对应" |
| 映射强度为"弱映射" | 仅属性相似 | 不可作为推理依据，仅作启发参考 |
| 映射强度为"伪映射" | 表面相似但结构冲突 | 禁止推理，标注"伪类比风险" |
| 存在映射断裂点 | 映射不完整 | 标注断裂点，评估对结论的影响 |
| 候选源域 < 2个 | 单一类比偏误风险 | 强制搜索更多源域，至少2个 |
| 内部一致性验证失败 | 映射后不自洽 | 修正映射或穷尽重试映射强度 |
| 预测力验证通过 | 类比可生成新预测 | 提升类比置信度，标注可验证预测 |
| 边界条件验证失败 | 类比在特定条件下失效 | 标注有效边界，限制类比适用范围 |

> 知识来源: MC-151 Structural-Mapping

| 重试层级 | 条件 | 替代方案 |
|---------|------|---------|
| L1 完整结构映射 | 源域和目标域关系可提取、映射可验证 | 完整4步+三层验证 |
| L2 部分结构映射 | 部分关系无法提取 | 对可提取关系做映射，不可提取部分标注"关系未知" |
| L3 属性类比 | 无法做关系映射 | 仅做属性级类比，标注"穷尽重试为属性类比，推理力弱" |
| L4 类比方向提示 | 仅知源域和目标域 | 标注类比方向，建议后续深入分析 |

## 10. 比较-显著性分析（MC-164 Comparison-Significance）

### 方法论原理

比较-显著性分析的方法论基础是：**类比推理的有效性不仅取决于结构同构性，还取决于比较的统计显著性——两个领域的相似性是否超出了随机期望**。当类比基于大量特征比较时，需要区分"系统性相似"（超出随机期望的结构性对应）和"偶然相似"（随机产生的表面重合）。这一方法论之所以必要，是因为最常见的类比错误是"过度解读偶然相似"——将随机重合的特征当作深层结构同构的证据。

### 执行步骤

1. **特征枚举**：列出源域和目标域的所有可比特征
2. **相似特征计数**：统计两个领域中相似的特征数量
3. **随机期望计算**：在零假设下，计算随机产生该相似度的期望值
4. **显著性判定**：若实际相似度显著高于随机期望 → 结构性相似；否则 → 偶然相似

### 决策规则

| 显著性水平 | 判定 | 行动 |
|-----------|------|------|
| p < 0.01 | 高度显著相似 | 类比推理可靠，可作为强推理依据 |
| p < 0.05 | 显著相似 | 类比推理较可靠，可作为中等推理依据 |
| p < 0.10 | 边缘显著 | 类比推理弱，仅作启发参考 |
| p ≥ 0.10 | 不显著 | 相似性可能为偶然，禁止类比推理 |

### 输出规范

```yaml
comparison_significance:
  source_domain: "源域"
  target_domain: "目标域"
  features_compared: 0
  similar_features: 0
  random_expectation: 0.0
  significance_level: "p_value"
  conclusion: "highly_significant/significant/marginal/not_significant"
  analogical_strength: "strong/moderate/weak/unreliable"
```

### 穷尽重试策略
