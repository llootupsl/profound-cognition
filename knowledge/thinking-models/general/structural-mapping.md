# 结构映射

> 知识来源: MC-151 结构映射 (Structural-Mapping)

## 方法论原理

结构映射的方法论基础是：**有效的类比不是"看起来像"，而是"关系结构同构"——源域中的因果机制在目标域中是否仍然成立，是类比有效性的最终判据**。Gentner 的结构映射理论指出：关系映射优先于属性映射，系统性映射优先于孤立映射。结构映射三原则（关系优先/系统性/一一对应）确保类比推理从表面相似性深入到深层结构同构，避免最常见的类比错误——基于属性相似性进行推理而忽略深层结构差异。

## 执行步骤

1. **识别源域**：提取目标域核心关系，搜索已知领域中具有相似关系结构的领域，至少识别2个候选源域
2. **提取结构关系**：遵循三条原则——关系优先（因果>功能>时序>空间>属性）、系统性（互相关联的关系网络>孤立关系对）、一一对应（源域和目标域元素映射应为一一对应）
3. **映射到目标域**：逐关系映射，标注映射强度（强映射/中映射/弱映射/伪映射），映射冲突标注为"映射断裂点"
4. **验证映射有效性**：三层验证——内部一致性验证（映射后关系网络是否自洽）、预测力验证（能否生成可验证的新预测）、边界条件验证（映射在什么条件下失效）

## 决策规则

| 条件 | 判定 | 行动 |
|------|------|------|
| 映射强度为"强映射" | 结构同构可靠 | 可作为推理依据，输出类比结论 |
| 映射强度为"中映射" | 部分同构 | 可作为辅助推理，标注"部分结构对应" |
| 映射强度为"弱映射" | 仅属性相似 | 不可作为推理依据，仅作启发参考 |
| 映射强度为"伪映射" | 表面相似但结构冲突 | 禁止推理，标注"伪类比风险" |
| 存在映射断裂点 | 映射不完整 | 标注断裂点，评估对结论的影响 |
| 候选源域 < 2个 | 单一类比偏误风险 | 强制搜索更多源域，至少2个 |
| 内部一致性验证失败 | 映射后不自洽 | 修正映射或穷尽重试替代映射强度 |
| 预测力验证通过 | 类比可生成新预测 | 提升类比置信度，标注可验证预测 |
| 边界条件验证失败 | 类比在特定条件下失效 | 标注有效边界，限制类比适用范围 |


## 穷尽重试策略

| 级别 | 条件 | 方案 |
|------|------|------|
| L1 | 源域和目标域关系可提取、映射可验证 | 完整4步+三层验证 |
| L2 | 部分关系无法提取 | 对可提取关系做映射，不可提取部分标注"关系未知" |
| L3 | 无法做关系映射 | 仅做属性级类比，标注"穷尽重试为属性类比，推理力弱" |
| L4 | 仅知源域和目标域 | 标注类比方向，建议后续深入分析 |
