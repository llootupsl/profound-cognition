# 文学领域引擎 -- Literature Domain Engine

> **模块标识**: `knowledge/domains/literature-engine`
> **职责**: 为Profound Cognition提供文学领域的深度认知分析能力，覆盖文学批评、文本分析、文学史和创作理论。

---

## 1. 核心分析框架

### 维度一：文本形式与诗学分析（Textual Form and Poetics Analysis）

**定义**: 对文学文本的形式特征——语言、结构、修辞和叙事技巧——进行精细的系统化分析。

**具体分析方法**:
- **语音层-语义层-句法层的分层细读**: 从语音层（韵律、格律、头韵、半谐音等的选择模式）、语义层（词汇选择、意象系统、隐喻网络的编织）和句法层（句式长度和复杂度、排比、倒装等修辞句式）三个层次逐级分析文本的语言肌理
- **叙事学分析**: 应用Genette的叙事话语分析框架——区分故事时间与叙事时间的操纵（顺序、时长、频率）、叙述聚焦（零聚焦/内聚焦/外聚焦）和叙述层次（故事内叙述/故事外叙述/元叙述）
- **文本间性映射**: 识别文本中的引用、典故、戏仿、拼贴等文本间关系，分析文本如何通过与前文本（precursors）的对话来创造意义——这种对话是致敬、颠覆还是创造性误读？
- **体裁惯例与偏离**: 分析作品对其所属体裁（小说、诗歌、戏剧、散文）惯例的遵循与偏离——偏离的形式是否创造了有意义的"陌生化"效果（Shklovsky），还是仅仅是实验的炫耀？

### 维度二：主题与意义的阐释学分析（Thematic and Hermeneutic Analysis）

**定义**: 对文本的主题世界和深层意义进行系统化的阐释，从文本证据出发构建有说服力的解读。

**具体分析方法**:
- **主题复现模式追踪**: 追踪核心主题、意象和母题在文本中的复现和变形模式——一个意象从何处首次出现，在何处重回，在何处发生意义转变
- **深层结构的对立与中介**: 使用Greimas的符号矩阵或Levi-Strauss的二元对立分析，识别文本表面下的深层意义对立结构（如自然vs文化、生vs死、秩序vs混沌），分析文本如何"中介化"这些对立
- **多义性vs确定性**: 分析文本意义是倾向于"封闭"（通过叙事收束提供明确的道德/价值判断）还是"开放"（保持多义性和解释的无限可能），以及这种开/闭策略的美学和意识形态含义
- **表层阅读与症候阅读**: 区分文本的"表层意义"（文本明确在说什么）和"症候意义"（文本在不经意间暴露了什么——矛盾、沉默、回避和过度强调），后者常比前者更揭示文本的意识形态立场

### 维度三：文学的历史与社会语境分析（Historical and Social Contextual Analysis）

**定义**: 将文学作品置于其产生的历史时刻和社会结构中进行语境化分析，理解文本与其时代之间的复杂互动。

**具体分析方法**:
- **历史时刻的具体化**: 不是笼统地将文本归属于一个时代标签（如"维多利亚时期"），而是具体定位文本写作和发表时的精确历史事件、社会辩论和意识形态斗争，分析文本如何介入这些具体语境
- **生产条件的文学社会学**: 分析文学作品的物质生产条件——出版制度、审查机制、文学市场、期刊文化、稿酬制度——如何影响文学的形式和内容选择
- **意识形态批判**: 从文本中识别其默认的意识形态预设——文本"认为理所当然"的是什么？文本的主体位置召唤读者认同一个什么样的世界观？
- **接受史与经典化过程**: 分析一部作品在文学史上的接受轨迹——它最初是被如何接受的，何时被经典化或去经典化，这个过程中文学制度的权力运作（批评家、大学课程、选集编辑、文学奖）

### 维度四：读者反应与审美经验分析（Reader Response and Aesthetic Experience）

**定义**: 分析文学作品的读者端——阅读过程中发生的认知、情感和审美体验，以及不同读者群体的差异化接受。

**具体分析方法**:
- **隐含读者的结构化**: 使用Iser的隐含读者理论，分析文本预设的"理想读者"的位置——文本"假设"读者拥有什么样的知识和价值观？文本留下了哪些"空白"等待读者去填充？
- **情感反应的叙事机制**: 分析文本通过什么叙事策略引发特定的情感反应——读者对角色的"共情"是通过什么叙事装置（自由间接引语、内心独白、空间隐喻）被建构的？
- **阅读的认知过程**: 从认知诗学角度分析阅读过程中的认知操作——读者如何构建和更新"故事世界"的心理模型，如何在阅读中形成和修正预期
- **经验读者的差异化接受**: 分析不同经验读者（不同阶层、性别、种族、时代）对同一文本的不同解读，警惕将"作为某个特定群体的我的阅读"等同于"普遍阅读"

### 维度五：比较文学与跨文化诗学（Comparative Literature and Cross-Cultural Poetics）

**定义**: 在跨文化、跨语言和跨媒介的框架中分析文学的传播、翻译和变形。

**具体分析方法**:
- **影响研究与平行研究**: 区分实证性的"影响研究"（有证据表明文本A确实影响了文本B）和类比性的"平行研究"（在没有影响证据的两个文本/传统中发现相似模式——这种发现的价值在于揭示共同的深层人类经验或结构性条件）
- **翻译的文学性分析**: 将文学翻译视为一种"创造性背叛"（creative treason）——分析翻译中发生了什么"遗失"、什么"增益"、什么"变形"，以及这些转换如何在目标文化中重新生产文学效果
- **世界文学的权力结构**: 分析"世界文学"的建构中的权力不平等——某些语言和文学传统被视为"普遍的"（源语言），某些被视无"被翻译的"（目标语言却很少翻译出去）；中心文学向边缘的单向辐射vs边缘文学的逆流
- **跨媒介叙事**: 分析文学作品在其他媒介（电影、戏剧、电子游戏、图像小说）中的改编——不同媒介的"叙事语法"如何决定了哪些可以转换、哪些必须改变

## 2. 关键变量清单

| 序号 | 变量名 | 定义 | 与领域的关系 |
|------|--------|------|-------------|
| 1 | 叙事聚焦模式(Narrative Focalization) | 叙述者提供信息的视角限制程度（零聚焦/内聚焦/外聚焦） | 决定读者信息获取和情感认同的核心叙事参数 |
| 2 | 叙述者可靠性(Narrator Reliability) | 叙述者提供的信息在文本世界内是否可信 | 不可靠叙述是现代文学的关键技法 |
| 3 | 文本间性密度(Intertextual Density) | 文本中引用、典故、戏仿等文本间关系的密度 | 衡量文本的"对话性"和传统意识 |
| 4 | 语言难度(Linguistic Difficulty) | 文本在词汇、句法、修辞层面的可读性障碍 | 影响阅读体验和受众范围 |
| 5 | 叙事时间操控(Temporal Manipulation) | 故事时间与叙事时间的偏离程度（顺序、时长、频率） | 决定叙事节奏和信息释放策略 |
| 6 | 人物复杂度(Character Complexity) | 人物内在矛盾、道德模糊性和心理深度的综合衡量 | 影响读者情感投入和"真实性"感知 |
| 7 | 体裁混合度(Genre Hybridity) | 作品混合不同文学体裁惯例的程度 | 衡量文学创新和规范挑战 |
| 8 | 隐含读者位置(Implied Reader Position) | 文本预设的理想读者的知识结构、价值观和审美能力 | 决定文本的准入条件和阅读效果 |
| 9 | 意识形态显隐度(Ideological Explicitness) | 作品的政治/道德立场是公开声明的还是潜藏编码的 | 影响解读空间和政治安全性 |
| 10 | 经典地位(Canonical Status) | 作品在文学经典中的位置（核心经典/边缘经典/非经典/反经典） | 反映文学制度的权力分配 |
| 11 | 翻译系数(Translation Coefficient) | 作品被翻译的语言数量 | 衡量世界文学中的传播广度 |
| 12 | 文学批评多样性(Critical Diversity) | 该作品引发/容纳的不同批评流派的解读数量 | 反映文本的多义性和阐释潜力 |
| 13 | 初始接受与当代接受差异(Reception Gap) | 作品在发表时的接受与其当代接受之间的差异 | 揭示审美标准和意识形态的历时变迁 |
| 14 | 陌生化效果(Defamiliarization Effect) | 文本通过形式手法的"陌生化"对读者感知习惯的挑战程度 | 衡量文学性的核心变量（俄国形式主义） |
| 15 | 情感强度(Emotional Intensity) | 文本引发的情感反应的强度和复杂度 | 影响阅读体验和文学价值判断 |
| 16 | 文学技巧密度(Literary Technique Density) | 单位文本中文学技巧的使用频率 | 衡量文本的技艺密度 |
| 17 | 文化特殊性vs普适性(Cultural Specificity vs Universality) | 作品的意义在多大程度上依赖特定文化知识vs在多大程度上跨文化可理解 | 影响跨文化传播和翻译可行性 |
| 18 | 创作时期风格代表性(Period Style Representativeness) | 作品对该时期主导文学风格的典型程度 | 文学史定位的关键维度 |

## 3. 领域内主流争议

### 争议一：作者意图的地位——解释的"锚"还是"谬误"？

**各方观点**:
- **意图主义（传统阐释学）**: 认为文本意义最终锚定在作者的意图之中。理解文本就是恢复作者意在传达的意义。脱离作者意图的解释是"过度解读"（overreading），失去了客观的判断标准。
- **反意图主义（新批评、Beardsley & Wimsatt的"意图谬误"）**: 认为文本一旦发表就脱离了作者成为独立的存在。作者的私人意图无论在实践上（如何获知？作者可能说谎、遗忘、自欺）还是理论上（文学作为公共艺术品的意义应由文本本身承载）都不应该是解释的标准。
- **修辞意图主义（Booth、后结构主义修正）**: 否认可以"恢复"作者的心理意图，但承认我们可以从文本中推断一个"隐含作者"——即文本的结构和修辞选择中所体现的价值和态度立场。这个"隐含作者"不是现实中的作者，而是一个由文本暗示的"作者功能"。

**核心分歧点**: 当文本证据和作者（声称的或传记材料揭示的）意图发生冲突时，哪一个应该是解释的控制性标准？如果"作者已死"（Barthes），那么是什么（如果有的话）阻止解释变成读者任意投射的主观活动？

### 争议二：文学经典的形成——艺术价值还是政治权力？

**各方观点**:
- **审美自律派（Bloom, "西方正典"）**: 认为文学经典的形成主要基于作品的审美力量——原创性、语言力量、对后世作家的影响力、普遍的认知价值。莎士比亚被经典化不是因为他是白人男性，而是戏剧史上无与伦比的成就。
- **经典建构派（新历史主义、后殖民批评、女性主义批评）**: 认为经典不是在审美真空中形成的——哪些作品被接纳为"经典"很大程度上取决于特定历史时期掌握文化权力的群体的偏好和利益。女性作家、非白人作家、非西方文学传统长期被系统性地排除在"伟大传统"之外，不是因为缺乏才华，而是因为文化守门制度的结构性排斥。
- **制度动力学派（Guillory）**: 认为经典的建构不能简单地归因于"审美"或"政治"，需要通过分析文学制度的具体运作——大学课程设置、文选编纂、出版市场、文学奖——来理解经典形成的制度机制。关键问题不是"这部作品到底好不好"，而是"通过什么制度机制，我们开始关心这个问题的"。

**核心分歧点**: 如果经典的形成包含政治权力的成分，那么在承认这一点之后，我们应该做什么？是"拓充经典"（加入更多被排除的声音），还是"废弃经典"（拒绝任何中心的/权威的作品列表），还是"批判性使用经典"（教经典的同时教"经典为什么是经典"的问题本身）？

## 4. 经典分析案例

### 案例一：《堂吉诃德》与小说体裁的诞生

**案例简述**: 塞万提斯的《堂吉诃德》（1605/1615）被广泛认为是"第一部现代小说"。它通过一个沉迷于骑士小说而混淆文学与现实的人物，同时创造并解构了小说的核心矛盾——虚构与现实、理想与经验之间的张力。

**分析要点**: 展示了元小说的"自我意识"——堂吉诃德在第二部中遭遇了读过第一部的人，文本反思了自身的创作和接受；小说作为"对话性"体裁（Bakhtin）——多种社会语言和意识形态在同一文本中相互竞争而没有单一权威声音。

**与分析维度的关联**: 文本形式分析（VD01）、主题阐释分析（VD02）

### 案例二：鲁迅《狂人日记》与现代中国文学的开端

**案例简述**: 鲁迅1918年发表的《狂人日记》被认为是中国现代文学的开端之作。通过一个"狂人"（精神分裂者）的自述，小说以极端陌生化的视角揭示了传统礼教社会的"吃人"本质，将传统的"疯癫/理性"二元对立反转。

**分析要点**: 展示了文学形式创新（日记体、不可靠叙述者）如何与思想启蒙深度整合；"狂人"的叙述位置提供的批判距离——以"疯子"的视角说话比以"启蒙知识分子"的视角说话更安全也更具有情感冲击力。

**与分析维度的关联**: 文本形式分析（VD01）、历史-社会语境分析（VD03）

### 案例三：《百年孤独》的魔幻现实主义与世界文学

**案例简述**: 加西亚·马尔克斯的《百年孤独》（1967年）通过布恩迪亚家族七代人的故事和虚构城镇马孔多，将拉美历史的殖民创伤、政治动荡和社会变迁编码为"魔幻"叙事，成为全球范围内"魔幻现实主义"文学的标志。

**分析要点**: 展示了"魔幻"不是逃避现实而是对现实的极端表现——在拉美，独裁者的荒谬、香蕉公司的屠杀和官方历史的沉默，在"现实主义"的描绘中反而可能显得不够真实；作品的"世界文学"成功——如何成为全球读者理解"拉美"的代名词，以及被"去拉美化"地解读为其普遍故事的风险。

**与分析维度的关联**: 主题阐释分析（VD02）、比较文学分析（VD05）

### 案例四：艾米莉·狄金森诗歌的"隐私诗学"

**案例简述**: 艾米莉·狄金森（1830-1886）生前仅匿名发表了约10首诗，去世后发现近1800首。她的诗歌以极致凝练的形式、非正统的大写和破折号、以及爆炸性的内在强度打破了19世纪美国诗歌的惯例，现在被认为是美国文学最伟大的诗人之一。

**分析要点**: 展示了"没有公开出版的伟大文学"的可能性——狄金森的案例挑战了文学史以"出版"和"同时代接受"为中心的叙事模式；私人书写（她的诗稿是手工缝制的"小册子"）与公开艺术之间的边界。

**与分析维度的关联**: 读者反应分析（VD04）、历史-社会语境分析（VD03）

### 案例五：《洛丽塔》的不可靠叙述与伦理挑战

**案例简述**: 纳博科夫的《洛丽塔》（1955）由一个恋童者Humbert Humbert以第一人称叙述，以华丽的辞藻和自嘲的幽默讲述他对12岁女孩的性剥削。小说引发了旷日持久的争论——这是美化恋童癖的色情文学，还是对叙述者操控读者的伦理批判？

**分析要点**: 展示了"不可靠叙述"的极端案例——Humbert的叙述精美到让许多读者（包括早期批评者）"忘记"了他在描述犯罪；文学的美学价值与伦理立场的冲突——一部"写得极好"的小说是否可能因为其"写得太好"而成为问题？

**与分析维度的关联**: 文本形式分析（VD01）、读者反应分析（VD04）

### 案例六：非洲口头文学传统的书面化与"文学"定义

**案例简述**: 在非洲文学谱系中，"文学"的边界问题尤为尖锐——大部分非洲语言的文学传统是以口头形式存在的（史诗、颂歌、谚语、故事）。将这些口头传统转化为书面文字的过程（人类学家的田野记录->文学选集->学校教材的"民族文学"），不仅是媒介转换，更是意义、权力和权威性的转换。

**分析要点**: 展示了"文学"概念本身的西方中心性——当我们将"文学"等同于"书面文本"时，我们已经将口头的、表演的、集体的文学传统排除在外；口头文学的"表演性"——在书面记录中丧失的节奏、互动和身体体验。

**与分析维度的关联**: 比较文学分析（VD05）、历史-社会语境分析（VD03）

## 5. 与通用认知框架的接口

### 九层研究底座接入

| 研究层 | 与文学领域的关联 | 特殊说明 |
|--------|-----------------|---------|
| L1 语义层 | 文学语言的多义性、语义密度、隐喻分析 | 文学语言的"意义"不等于日常语言的"指称" |
| L2 逻辑层 | 叙事逻辑、论证结构、思想实验 | 文学中的逻辑是"情感逻辑"而非形式逻辑 |
| L3 证据层 | 文本内证与外证的区分 | "新批评"以来的核心方法论——文本优先于作者传记 |
| L4 因果层 | 文学影响、文学史演变的因果 | 文学影响的因果极其复杂，不应简化为"X影响了Y" |
| L5 数学层 | 文学统计、文体计量学、远读 | 大数据方法在文学分析中的新范式 |
| L6 历史层 | 文学史、风格演变、接受史 | 文学的共时结构分析和历时演变分析的结合 |
| L7 社会层 | 文学社会学、文学制度 | 文学生产、传播和经典化的社会条件 |
| L8 哲学层 | 美学、阐释学、文学本体论 | "什么是文学？"的本体论追问 |
| L9 元认知层 | 阅读过程的自我反思、情感反应的来源追踪 | "我为什么喜欢/讨厌这个角色？"的元分析 |

### 对认知流水线各步骤的特殊要求

1. **输入解析步骤**: 文学分析的第一步是明确区分"文本"和"关于文本的言说"——文本是分析的原始数据，批评文献、作者访谈和文学史背景是辅助信息。不应该让辅助信息替代了对文本的原始接触。

2. **维度抽取步骤**: 文学分析应同时从形式维度（语言、结构、叙事技巧）和内容维度（主题、情感、意识形态）抽取分析维度，形式与内容的分离只能是分析性的（在实际文本中不可分割）。

3. **证据收集步骤**: 文学分析的"证据"主要是文本自身的具体段落、词汇选择、叙事决策。每个解释性主张必须被锚定在可引用的文本证据上——"我感觉这篇小说很悲伤"不是证据，"小说中32次提到了'灰'这个颜色"是证据。

4. **模式识别步骤**: 文学中的模式识别应区分"作者意图的模式"（作者有意识地组织的结构）和"非意图但客观存在的模式"（读者/批评家发现的、可能超越了作者意识的文本结构）。两者在分析上同样有效。

5. **推理综合步骤**: 文学解读的综合需要在对立理论之间寻找"最佳解释"——不是所有解读都同样好，一个更好的解读是：(a)能够涵盖更多文本细节而不遗漏反例，(b)与已知的历史和社会语境一致，(c)具有美学上的启示力。

6. **对抗验证步骤**: 对每个文学解读应检查：(a)是否忽视了文本中与我的解读相矛盾的证据？(b)是否将文化特殊性当作普适性？(c)是否将自己的当代价值观不加反思地投射到不同历史时期的文本上？

7. **跨域关联步骤**: 文学与哲学、历史、心理学等的跨域关联需要经过"文学性"转化——不是将文学作为其他学科的示例材料，而是追问文学作为一种特殊的认知方式能够提供什么其他学科不能提供的东西。

8. **洞察涌现步骤**: 文学洞察应该具有"回看文本"的诱导力——一个好的文学分析应该让人想回到文本重新阅读，用分析中获得的视角去重新体验文本。

### 推荐思维模型

| 思维模型 | 适用场景 | 简要说明 |
|---------|---------|---------|
| 细读法(Close Reading) | 文本分析 | 对文本的语言、结构和修辞进行精致关注 |
| 叙事学框架(Genette) | 叙事分析 | 时间、聚焦、声音、层次的叙事分析工具箱 |

## 7.5 多视角研究综合方法论 (TC-029 STORM)

### 7.5.1 方法论原理

多视角研究综合的核心认知假设是——单一视角的研究必然遗漏其他视角可见的信息和论据，只有通过系统性地生成和整合多个专家视角，才能逼近对研究主题的"全息"理解。STORM方法论将研究综合分解为四个阶段：视角生成（从哪些角度看）、交叉验证（不同视角的发现是否一致）、矛盾识别（不一致意味着什么）、综合框架构建（如何统一）。这种方法论使我们从"单一叙事"升级为"多声部复调"——不同视角的共识增强可信度，矛盾揭示深层复杂性。

> 知识来源: TC-029 [STORM]

### 7.5.2 执行步骤

1. **视角生成规则**：
   - 学科视角：根据研究主题涉及的核心学科，生成3-5个学科专家视角
   - 立场视角：为每个议题生成支持、反对、中立三种立场视角
   - 利益相关者视角：识别受研究主题影响的不同群体，生成其视角
   - 时间视角：从历史、现状、未来三个时间维度生成视角
   - 视角数量控制：总视角数 ≤ 8个，避免信息过载
2. **交叉验证步骤**：
   - 对每对视角，比较其对同一子问题的回答
   - 标记一致性等级：完全一致/部分一致/不一致/互补
   - 一致性发现 → 增强该结论的可信度
   - 互补性发现 → 扩展该结论的适用范围
3. **矛盾识别方法**：
   - 识别不同视角对同一问题的矛盾回答
   - 分析矛盾来源：数据差异/理论框架差异/价值立场差异/时间尺度差异
   - 对每个矛盾标注：矛盾类型、矛盾强度（强/中/弱）、可调和性
4. **综合框架构建流程**：
   - 以共识点为框架骨架，以互补点为框架扩展
   - 以矛盾点为框架张力点（保留矛盾，不强行调和）
   - 标注综合框架的覆盖率和盲区

> 知识来源: TC-029 [STORM]

### 7.5.3 决策规则

| 条件 | 决策 |
|------|------|
| 研究主题涉及3+学科 | 生成学科视角，每个学科一个专家视角 |
| 研究主题存在明显争议 | 生成对立立场视角（支持/反对） |
| 视角间一致性 > 80% | 减少视角数量，聚焦差异最大的视角 |
| 视角间矛盾 > 50% | 增加中立视角，分析矛盾根源 |
| STORM服务不可用 | 穷尽重试：手动多视角提问（引用 exhaust-retry-protocol.md） |

> 知识来源: TC-029 [STORM]

## 8. TC-095 Shadow-Loom 叙事因果推理方法论

> **能力卡片**: TC-095 Shadow-Loom | 叙事因果推理引擎
> **方法论来源**: 俄国形式主义叙事学（Propp, Shklovsky, Tomaševskij）+ Judea Pearl因果推理框架 + 反事实微积分
> **内化目标**: 将叙事因果推理从隐含的文学直觉转化为可操作、可验证、可穷尽重试的系统化分析流程

### 8.1 核心原理：fabula/syuzhet分离方法论

#### 8.1.1 理论基础

俄国形式主义叙事学区分了叙事的两个基本层面：

- **fabula（故事/素材）**: 事件按因果-时间顺序排列的原始序列，是"发生了什么"的客观重构。fabula是叙事的深层因果结构，独立于叙述方式而存在。
- **syuzhet（情节/叙述）**: 叙述者对fabula素材的选择、排列和呈现方式，是"如何讲述"的艺术操作。syuzhet通过时间操纵（倒叙、预叙、频率变化）、视角选择和信息控制来组织叙事体验。

**分离的操作意义**: fabula/syuzhet分离不是简单的"内容vs形式"二分，而是揭示叙事艺术的因果逻辑——syuzhet的每一次偏离fabula的操作（倒叙、省略、重复、延迟）都服务于特定的因果推理目的：制造悬念、隐藏关键因果链、引导读者形成错误的因果假设。

#### 8.1.2 fabula重构操作步骤

```
Step 1: 事件提取
  - 遍历全文，提取所有叙事事件节点 E = {e1, e2, ..., en}
  - 每个事件节点记录：{时间戳, 空间位置, 参与角色, 事件类型, 信息状态}
  - 事件类型分类：动作事件 / 心理事件 / 环境事件 / 言语事件

Step 2: 时间线还原
  - 将syuzhet中的叙述顺序映射到fabula时间轴
  - 标记时间偏离：倒叙(analepsis) / 预叙(prolepsis) / 省略(ellipsis) / 暂停(pause) / 场景(scene) / 概述(summary)
  - 生成fabula时间线：T_fabula = sort(E, by=chronological_order)

Step 3: 因果链重建
  - 在fabula时间线上建立事件间的因果连接
  - 因果关系类型：必要条件 / 充分条件 / 贡献因素 / 阻碍因素
  - 生成fabula因果图：G = (E, C)，其中C为因果边集合

Step 4: syuzhet偏离标注
  - 对比fabula因果图与syuzhet叙述顺序，标注每次偏离
  - 分析偏离的叙事功能：信息隐藏 / 悬念制造 / 误导 / 主题强化 / 情感操控
  - 生成偏离功能映射表
```

#### 8.1.3 文学分析中的应用规则

| 规则ID | 规则名称 | 规则内容 | 适用场景 |
|--------|---------|---------|---------|
| SL-R01 | 因果完整性检验 | fabula重构后，检查是否存在无因果前件的事件节点——孤立的叙事事件可能暗示隐藏的因果链或叙述者故意省略 | 悬疑/推理文学 |
| SL-R02 | 偏离动机推断 | 对syuzhet的每次偏离fabula的操作，必须推断至少一个叙事功能——无功能的偏离是叙述失误或需要更深层的阐释 | 所有叙事文学 |
| SL-R03 | 信息不对称标注 | 标记读者与角色之间的信息不对称点——读者知道而角色不知道（戏剧性反讽）或角色知道而读者不知道（悬念） | 叙事张力分析 |
| SL-R04 | 多重fabula冲突 | 当存在不可靠叙述者时，允许多个fabula版本并存，标注版本间的冲突点及其对因果推理的影响 | 不可靠叙述分析 |
| SL-R05 | 因果链权重评估 | 对fabula因果图中的每条因果边赋予权重(0-1)，区分强因果（无此因则无此果）和弱因果（此因仅贡献于此果） | 因果重要性排序 |

### 8.2 Pearl因果阶梯3层在叙事分析中的应用

#### 8.2.1 因果阶梯定义与叙事映射

Pearl的因果阶梯（Ladder of Causation）包含三个层级，对应三种推理模式：

| 阶梯层级 | 原始定义 | 叙事分析映射 | 典型问题 | 数学表达 |
|----------|---------|-------------|---------|---------|
| **L1 关联** (Association) | P(y\|x) — 观察到X时Y的概率 | 叙事事件的共现模式与相关性分析 | "这个事件出现时，另一个事件是否也出现？" | P(事件B\|事件A) |
| **L2 干预** (Intervention) | P(y\|do(x)) — 对X进行干预时Y的概率 | 叙事修改实验——改变某个叙事决策，推演后果变化 | "如果作者做了不同的叙事选择，故事会如何变化？" | P(结局\|do(叙事决策)) |
| **L3 反事实** (Counterfactual) | P(y_x\|x', y') — 在已观察到X=x'的条件下，假设X=x时Y的值 | 叙事假设推理——在已知叙事结局的条件下，假设关键事件未发生 | "如果角色没有做出那个决定，故事会走向何处？" | P(结局'\|反事实: 事件e_i未发生) |

#### 8.2.2 L1关联层：叙事共现模式分析

**操作步骤**:
1. 在fabula因果图上计算事件对的共现概率
2. 识别高共现事件对——这些是叙事中的"因果习惯"或"主题配对"
3. 区分因果共现（A导致B）与共同原因共现（C同时导致A和B）
4. 输出叙事关联矩阵：M[i][j] = P(e_j | e_i)

**文学分析应用**:
- 识别叙事中的"因果惯性"——某些事件组合在特定体裁中几乎必然共现（如侦探小说中"密室"与"诡计"的共现）
- 发现反常规的共现模式——作者可能通过打破因果惯性来创造叙事创新

#### 8.2.3 L2干预层：叙事修改实验

**操作步骤**:
1. 选择干预点：确定要修改的叙事决策节点 e_i
2. 定义干预操作：do(e_i = e_i')，将事件e_i替换为替代事件e_i'
3. 在fabula因果图上执行干预：切断所有指向e_i的因果边，保留从e_i出发的因果边
4. 沿因果图正向传播干预效果，计算每个下游事件的概率变化
5. 比较干预前后的叙事轨迹差异

**文学分析应用**:
- 评估叙事决策的因果重要性——干预后变化越大的决策，因果重要性越高
- 分析作者的叙事选择空间——同一fabula可以产生多少不同的syuzhet
- 验证"必然性"主张——文学批评中常声称某事件"必然发生"，干预实验可检验此主张

#### 8.2.4 L3反事实层：叙事假设推理

**操作步骤**:
1. 确定反事实前提：在已知实际叙事轨迹(x', y')的条件下
2. 构建反事实世界：假设关键事件e_i未发生（或以不同方式发生）
3. 使用结构因果模型(SCM)计算反事实结果：保留实际世界中非e_i因果路径上的噪声项，仅修改e_i及其下游
4. 生成反事实叙事轨迹：描述"如果...则..."的替代故事线
5. 对比实际叙事与反事实叙事，提取叙事意义差异

**文学分析应用**:
- 揭示叙事的"脆弱点"——哪些事件的改变会导致叙事意义的根本变化
- 分析悲剧的"不可避免性"——反事实推理可检验悲剧结局是否真的无法避免
- 理解读者的"如果"思维——读者在阅读中自发进行的反事实推理是叙事参与的核心机制

### 8.3 反事实微积分的叙事推演

#### 8.3.1 核心概念

反事实微积分（Counterfactual Calculus）将反事实推理形式化，为叙事假设提供严格的计算框架：

- **反事实命题**: CF = "如果事件e_i以方式e_i*发生（而非实际方式e_i'），则结局Y将以方式y*发生（而非实际方式y'）"
- **反事实概率**: P(Y_{e_i*} = y* | E_i = e_i', Y = y') — 在观察到实际事件和结局的条件下，反事实结局的概率
- **叙事反事实距离**: d(CF) = |实际叙事轨迹 - 反事实叙事轨迹| — 衡量反事实偏离实际叙事的程度

#### 8.3.2 叙事反事实推演步骤

```
Step 1: 反事实前提设定
  输入: 实际fabula因果图 G_actual, 关键事件 e_i, 反事实替代 e_i*
  操作: 定义反事实世界 W_cf 的初始条件

Step 2: 因果链截断与重连
  操作:
    - 截断: 移除所有指向 e_i 的因果边（e_i 的前件不变，但 e_i 本身被替换）
    - 重连: 将 e_i* 连接到 e_i 的下游因果边
    - 保留: 所有与 e_i 无因果路径的事件保持不变（结构因果模型的"最小修改"原则）

Step 3: 下游传播计算
  操作:
    - 沿因果图正向传播 e_i* 的影响
    - 对每个下游事件 e_j，计算:
      P(e_j | e_i*) vs P(e_j | e_i') — 概率变化量
    - 标记"因果敏感事件"（概率变化 > 阈值θ的事件）

Step 4: 叙事轨迹生成
  操作:
    - 将因果敏感事件按时间排列，生成反事实叙事轨迹
    - 标注轨迹分歧点（实际与反事实首次分离的事件）
    - 标注轨迹收敛点（实际与反事实重新汇合的事件，如果存在）

Step 5: 意义差异提取
  操作:
    - 比较实际叙事与反事实叙事的主题表达差异
    - 识别"因果关键事件"——其反事实替代导致主题意义根本改变的事件
    - 输出反事实分析报告
```

#### 8.3.3 叙事反事实推理规则

| 规则ID | 规则名称 | 规则内容 | 约束条件 |
|--------|---------|---------|---------|
| CF-R01 | 最小修改原则 | 反事实推理仅修改干预事件的因果下游，不修改无因果路径的事件 | 遵循Pearl结构因果模型 |
| CF-R02 | 叙事一致性约束 | 反事实叙事轨迹必须保持与fabula世界设定的一致性（物理规律、角色性格、社会规则） | 排除"魔法"式反事实 |
| CF-R03 | 角色能动性保留 | 反事实推理应保留角色的核心性格特征和决策倾向，仅改变外部条件或关键选择 | 避免角色OOC |
| CF-R04 | 叙事意义守恒检验 | 如果反事实叙事与实际叙事产生相同的主题意义，则该反事实推理的阐释价值为零 | 反事实必须产生意义差异 |
| CF-R05 | 多重反事实比较 | 对同一关键事件应生成至少2个反事实替代，比较不同替代的叙事后果 | 避免单一反事实的偏颇 |

```
function generate_perspectives(research_topic, num_perspectives=5):
    # 步骤1：生成候选视角
    candidate_perspectives = LLM.generate(
        prompt=f"Given the research topic '{research_topic}', "
               f"list {num_perspectives * 3} distinct analytical perspectives "
               f"that would provide comprehensive coverage. "
               f"Include perspectives from different disciplines, "
               f"methodologies, and stakeholder viewpoints."
    )

    # 步骤2：视角去重与多样性最大化
    # 使用语义嵌入计算视角间相似度
    embeddings = [embed(p) for p in candidate_perspectives]
    selected = []
    for candidate, emb in zip(candidate_perspectives, embeddings):
        # 检查与已选视角的最大相似度
        max_sim = max(cosine_similarity(emb, embed(s)) for s in selected) \
                  if selected else 0
        if max_sim < 0.7:  # 多样性阈值
            selected.append(candidate)
        if len(selected) >= num_perspectives:
            break

    # 步骤3：为每个视角生成专家角色
    perspectives = []
    for p in selected:
        expert = LLM.generate(
            prompt=f"Define an expert persona for the perspective '{p}' "
                   f"on topic '{research_topic}'. Include: expertise domain, "
                   f"key questions they would ask, methodological preferences."
        )
        perspectives.append({
            perspective: p,
            expert_persona: expert,
            questions: generate_perspective_questions(p, research_topic)
        })

    return perspectives

function generate_perspective_questions(perspective, topic):
    # 每个视角生成3-5个深度问题
    questions = LLM.generate(
        prompt=f"From the perspective of '{perspective}', "
               f"generate 5 deep research questions about '{topic}'. "
               f"Questions should be specific, answerable, and non-overlapping."
    )
    return questions
```

```
交叉验证核心流程（storm/cross_validation.py）:

function cross_validate_findings(perspectives, findings_per_perspective):
    # findings_per_perspective: Dict[perspective, list[Finding]]

    # 步骤1：提取各视角的核心主张
    core_claims = {}
    for perspective, findings in findings_per_perspective.items():
        claims = []
        for finding in findings:
            claim = LLM.generate(
                prompt=f"Extract the core claim from this finding: '{finding}'. "
                       f"State as a single declarative sentence."
            )
            claims.append(claim)
        core_claims[perspective] = claims

    # 步骤2：跨视角一致性检验
    consistency_report = {
        consistent: [],      # 多视角一致的主张
        complementary: [],   # 互补但不矛盾的主张
        contradictory: []    # 矛盾的主张
    }

    all_claims = [(p, c) for p, claims in core_claims.items() for c in claims]

    for i, (p1, c1) in enumerate(all_claims):
        for p2, c2 in all_claims[i+1:]:
            relation = LLM.classify(
                prompt=f"Classify the relationship between these two claims:\n"
                       f"Claim A (from {p1}): {c1}\n"
                       f"Claim B (from {p2}): {c2}\n"
                       f"Is the relationship: CONSISTENT, COMPLEMENTARY, or CONTRADICTORY?"
            )
            consistency_report[relation].append({
                claim_a: c1, perspective_a: p1,
                claim_b: c2, perspective_b: p2
            })

    # 步骤3：矛盾解决
    resolved_contradictions = []
    for contradiction in consistency_report.contradictory:
        resolution = LLM.generate(
            prompt=f"Two perspectives contradict:\n"
                   f"{contradiction.claim_a} vs {contradiction.claim_b}\n"
                   f"Propose a resolution or explain the conditions "
                   f"under which each claim holds."
        )
        resolved_contradictions.append({
            contradiction, resolution
        })

    return {consistency_report, resolved_contradictions}
```

```
function build_synthesis_framework(topic, perspectives, findings, cross_validation):
    # 步骤1：识别综合维度
    dimensions = LLM.generate(
        prompt=f"Based on findings from {len(perspectives)} perspectives "
               f"on '{topic}', identify 3-5 key dimensions that organize "
               f"the findings into a coherent framework."
    )

    # 步骤2：映射各视角发现到维度
    dimension_mapping = {}
    for dimension in dimensions:
        relevant_findings = []
        for perspective, finding_list in findings.items():
            for finding in finding_list:
                relevance = LLM.classify(
                    prompt=f"Is this finding relevant to dimension '{dimension}'?\n"
                           f"Finding: {finding}"
                )
                if relevance == "YES":
                    relevant_findings.append({
                        finding, perspective
                    })
        dimension_mapping[dimension] = relevant_findings

    # 步骤3：构建综合叙事
    synthesis = LLM.generate(
        prompt=f"Write a comprehensive synthesis on '{topic}' organized by "
               f"these dimensions: {dimensions}. For each dimension, integrate "
               f"findings from multiple perspectives, noting agreements, "
               f"complements, and resolved contradictions. "
               f"Cross-validation results: {cross_validation.consistency_report}"
    )

    return {
        dimensions, dimension_mapping, synthesis,
        confidence: compute_synthesis_confidence(cross_validation)
    }

function compute_synthesis_confidence(cross_validation):
    total = len(cross_validation.consistency_report.consistent) + \
            len(cross_validation.consistency_report.complementary) + \
            len(cross_validation.consistency_report.contradictory)
    if total == 0:
        return "LOW"
    consistent_ratio = len(cross_validation.consistency_report.consistent) / total
    contradiction_ratio = len(cross_validation.consistency_report.contradictory) / total
    if consistent_ratio > 0.6 and contradiction_ratio < 0.1:
        return "HIGH"
    elif contradiction_ratio < 0.3:
        return "MEDIUM"
    else:
        return "LOW"
```
