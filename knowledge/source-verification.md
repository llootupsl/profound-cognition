## 概述

本文档定义来源核实的标准流程，包括一手来源判断、转引标注、存档版本使用和时效性判断。所有需要标注来源的任务节点均遵循此流程。

## 一、一手来源判断

### 什么是"一手来源"
直接由信息产生者发布的、未经中间机构转述或加工的原始信息。

### 一手来源判断规则
1. **数据类**：是否为发布机构官网/数据库直接下载的数据？而非引用该数据的第三方文章
2. **法律类**：是否为法律/法规/判决书的原文？而非新闻报道中的引用片段
3. **声明类**：是否为官方渠道（官网、官方社交媒体认证账号）发布的原文？而非媒体转述
4. **研究类**：是否为论文/报告的原文全文？而非新闻稿或摘要解读

### 判定流程
```
信息来源 → 是否有原始出处链接？
  ├── 是 → 原始出处是否为发布机构官方渠道？
  │     ├── 是 → 一手来源（primary）
  │     └── 否 → 二手来源（secondary），需标注转引渠道
  └── 否 → 判断为二手来源，需评估可靠性
```

---

## 二、转引标注规则

### 何时需要标注转引
当使用的信息来源于中间媒体或非原始发布渠道时，必须标注转引关系。

### 标注格式
```
格式：原始来源：[发布机构，发布日期，URL]（转引自：[中介来源名称，访问日期]）
```

### 转引标注示例
- ✅ 正确："据国家统计局 2026 年 1 月发布的数据，GDP 增速为 5.2%（原始来源：国家统计局，2026-01-17，www.stats.gov.cn/xxx）（转引自：Reuters 报道，2026-01-18）"
- ❌ 错误："据国家统计局数据，GDP 增速为 5.2%"（未标注转引，且未给出原始 URL）

### 铁律
- 转引来源的可靠性在标注中降一级（引用 L0 来源的 L1 媒体文章在转引标注中视为 L1）
- 禁止对转引信息做二次加工或解读后仍标注为原始来源

## 三、存档版本使用原则

### 何时需要存档版本
1. 引用的网页可能在未来被修改或删除
2. 引用的内容有多个版本，需指定特定版本
3. 引用的是实时更新的数据库快照

### 存档格式

| 存档方式 | 适用场景 | 格式 |
|---------|---------|------|
| archive.org | 网页长期存档 | `https://web.archive.org/web/YYYYMMDDHHMMSS/https://原始URL` |
| archive.today | 快速网页快照 | `https://archive.today/YYYYMMDDHHMMSS/原始URL` |
| PDF 存档 | 官方报告的版本固化 | 注明 PDF 的文件名、发布日期和版本号 |

### 使用原则
- 涉及具有时效性的数据（经济数据、统计年鉴等）时，必须注明数据的发布日期和覆盖时间段
- 引用已经发生变更的政策时，必须注明引用的版本日期
- 存档版本的引用不影响来源等级（存档 L0 来源仍为 L0）

## 四、来源时效性判断

### 时效性分级
| 领域 | 高时效要求 | 中时效要求 | 低时效要求 |
|-----|-----------|-----------|-----------|
| 经济金融 | ≤ 1 个月 | ≤ 6 个月 | ≤ 2 年 |
| 科技 | ≤ 3 个月 | ≤ 1 年 | ≤ 3 年 |
| 政治/政策 | ≤ 1 个月 | ≤ 6 个月 | 视政策周期 |
| 历史 | N/A（越旧越好） | N/A | N/A |
| 文化/文学 | 视分析需求 | 视分析需求 | 无时效限制 |
| 法律 | 以现行法律为准 | 以最新修订为准 | 历史分析除外 |

### 判定规则
- 若来源的发布日期晚于事件发生日期超过 3 个月，需在标注中注明时间差
- 对于"高时效要求"领域，超过时效上限的来源应穷尽重试替代使用（如 L0→L1）

## 五、不可用来源标注规范

### 当来源被标记为 "unavailable" 时
若某事实的核实来源确实无法获取（如付费墙、链接失效、语言障碍等），必须在标注中包含以下字段：

```yaml
unavailable_source:
  search_query: "尝试搜索的关键词"
  search_method: "使用的搜索方式（Web Search / 数据库查询 / 其他）"
  attempt_count: 搜索尝试次数（≥ 3 次方可标记 unavailable）
  reason: "无法获取的具体原因（如：原始链接 404 / 需要付费订阅 / 仅提供非英文版本）"
  closest_alternative: "最接近的可用替代来源"
```

### 铁律
- **禁止不经搜索直接标注 unavailable**
- 搜索尝试次数 < 3 次时不得标记为 unavailable
- 每次搜索尝试应记录搜索词和搜索方式
- 若存在可用的替代来源，禁止标记为 unavailable

## 六、来源核实自检清单

每条关键事实在标注来源前，必须通过以下自检：

- [ ] 是否为一手来源？若是二手来源，是否已标注转引关系？
- [ ] 来源的发布日期是否符合该领域的时效性要求？
- [ ] 若来源可能变动，是否已提供存档版本？
- [ ] 来源 URL 是否可在当前时刻访问？
- [ ] 若标记为 unavailable，是否已完成 ≥ 3 次搜索尝试并记录详情？
- [ ] 来源等级（L0-L3）的判定是否符合 evidence-standards.md 的标准？
