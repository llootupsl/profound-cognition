# TC-128: Chroma — 向量数据库

## 基本信息
- **名称**: Chroma
- **类别**: 向量数据库
- **语言**: Python
- **版本要求**: >=0.5
- **许可证**: Apache 2.0
- **仓库**: https://github.com/chroma-core/chroma

## 核心能力
- 嵌入式向量数据库（无需独立服务）
- 支持语义搜索与相似度匹配
- 与 LangChain/LlamaIndex 集成
- 适合原型与中小规模数据
