# TC-130: Semantic Scholar API — 学术文献搜索 API

## 基本信息
- **名称**: Semantic Scholar API
- **类别**: 学术文献搜索 API
- **语言**: Python（REST API）
- **版本要求**: >=1.0
- **许可证**: Apache 2.0
- **仓库**: https://github.com/allenai/s2-folks
- **维护方**: Allen Institute for AI

## 核心能力
- 学术文献元数据检索（标题/摘要/引用/作者/DOI）
- 论文引用网络遍历（citations / references 双向）
- 语义化论文搜索（支持自然语言查询）
- 批量论文检索（最多 500 篇/请求）

## 在 profound-cognition 中的用途
- **T02 研究底座**: T02 研究底座核心检索源；当前使用 PaperQA2 + Semantic Scholar API + OpenAlex API 组合，Semantic Scholar API 作为论文引用网络遍历与元数据增强的主入口待激活
- **状态**: 待激活
- **对应 v5.1.0 报告项**: 第四章 4.3.11 节

## 消费节点

## 失败回退策略

- **触发条件**: 工具不可用、调用超时、输出质量不达标、依赖缺失
- **回退路径**: 降级到 LLM 内建能力，标注 [INTERNAL_REASONING]
- **回退声明**: 回退后失去工具增强能力，但保证流程不中断（EXHAUST 铁律）
- **穷尽重试**: 按 L1_FULL → L2_PARTIAL → L3_TEXT_ONLY → L4_SERVICE_DOWN 逐级降级

## 效果度量

| 度量指标 | 定义 | 目标值 |
|----------|------|--------|
| 执行成功率 | 成功调用次数 / 总调用次数 | >= 0.95 |
| 平均延迟 | 单次调用平均耗时 | <= 5s |
| 输出质量分 | Supervisor 评分（0-1） | >= 0.8 |
| 穷尽重试触发率 | 触发降级的调用次数 / 总调用次数 | <= 0.1 |
