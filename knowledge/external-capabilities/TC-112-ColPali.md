# TC-112: ColPali — 多模态检索

## 基本信息
- **名称**: ColPali
- **类别**: 多模态检索
- **语言**: Python
- **版本要求**: >=0.1
- **许可证**: Apache 2.0
- **仓库**: https://github.com/illuin-tech/colpali
- **维护方**: illuin-tech

## 核心能力
- 基于 ColBERT 的多模态检索（视觉文档检索）
- 页面级向量索引
- 无需 OCR 的直接图像检索

## 在 profound-cognition 中的用途
- **T05 证据搜索**: T05 证据搜索节点备选；当前主路径使用 SearXNG + Crawl4AI 组合，ColPali 作为多模态文档检索备选待激活
- **状态**: 待激活

## 消费节点

## 失败回退策略

- **触发条件**: 工具不可用、调用超时、输出质量不达标、依赖缺失
- **回退路径**: 降级到 LLM 内建能力，标注 [INTERNAL_REASONING]
- **回退声明**: 回退后失去工具增强能力，但保证流程不中断（EXHAUST 铁律）
- **穷尽重试**: 按 L1_FULL → L2_PARTIAL → L3_TEXT_ONLY → L4_SERVICE_DOWN 逐级降级

## 效果度量

| 度量指标 | 定义 | 目标值 |
|----------|------|--------|
| 执行成功率 | 成功调用次数 / 总调用次数 | >= 0.95 |
