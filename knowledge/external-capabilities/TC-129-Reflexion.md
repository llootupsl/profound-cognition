# TC-129: Reflexion — LLM 自我反思框架

## 基本信息
- **名称**: Reflexion
- **类别**: LLM 自我反思框架
- **语言**: Python
- **版本要求**: >=0.1
- **许可证**: MIT
- **仓库**: https://github.com/noahshinn/reflexion

## 核心能力
- LLM 自我反思（self-reflection）强化学习
- 通过反思轨迹（reflection trace）迭代改进 Agent 输出
- 与 ReAct / Tree-of-Thought 等基础 Agent 模式互补
- 自我评估 + 反馈记忆 + 下一轮改进闭环

## 在 profound-cognition 中的用途
- **I01 迭代深化**: I01 迭代深化备选增强；当前主路径使用 CoVe（Chain-of-Verification，T17 已实现）+ 信息增益收敛判据（ΔInfo < ε），Reflexion 可作为迭代深化阶段的自我反思增强待激活

## 失败回退策略

- **触发条件**: 工具不可用、调用超时、输出质量不达标、依赖缺失
- **回退路径**: 降级到 LLM 内建能力，标注 [INTERNAL_REASONING]
- **回退声明**: 回退后失去工具增强能力，但保证流程不中断（EXHAUST 铁律）
- **穷尽重试**: 按 L1_FULL → L2_PARTIAL → L3_TEXT_ONLY → L4_SERVICE_DOWN 逐级降级

## 效果度量

| 度量指标 | 定义 | 目标值 |
