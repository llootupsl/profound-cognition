## 基本信息

> ★核心方法论已内化于 tasks/TM02_causal_verification.md，本文件仅作快速引用入口

- **名称**: Pyro
- **类别**: 概率编程
- **语言**: Python
- **版本要求**: ≥1.8
- **安装**: pip install pyro-ppl
- **许可证**: Apache 2.0
- **仓库**: https://github.com/pyro-ppl/pyro

## 核心能力
- 贝叶斯建模
- MCMC 采样 (HMC, NUTS)
- 变分推断 (SVI)
- 后验预测检验
