# TC-111: Docling — 文档解析

## 基本信息
- **名称**: Docling
- **类别**: 文档解析
- **语言**: Python
- **版本要求**: >=0.1
- **许可证**: MIT
- **仓库**: https://github.com/DS4SD/docling
- **维护方**: DS4SD

## 核心能力
- 文档布局分析（DLA）与结构化输出
- 支持 PDF/DOCX/HTML/PPTX 多格式
- 与 LlamaIndex 集成

## 在 profound-cognition 中的用途
- **Marker 备选**: T02 文档解析备选；作为 Marker 的备选方案，Docling 在多格式支持上更优，待激活
- **状态**: 待激活

## 失败回退策略

- **触发条件**: 工具不可用、调用超时、输出质量不达标、依赖缺失
- **回退路径**: 降级到 LLM 内建能力，标注 [INTERNAL_REASONING]
- **回退声明**: 回退后失去工具增强能力，但保证流程不中断（EXHAUST 铁律）
- **穷尽重试**: 按 L1_FULL → L2_PARTIAL → L3_TEXT_ONLY → L4_SERVICE_DOWN 逐级降级
