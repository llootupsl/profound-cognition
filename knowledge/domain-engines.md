## 1. 概述

领域引擎是 Profound Cognition 框架的领域知识底座。每个引擎封装了特定学科领域的核心分析框架、关键争议和认知方法论，供认知流水线在分析问题时按需激活。

当前共有 35 个领域引擎，覆盖人文社科与自然科学核心领域。

## 3. 激活原则

1. **按需激活**: 仅激活与问题领域直接相关的引擎，避免无关引擎干扰分析精度。
2. **最少激活**: 默认推荐 1-3 个核心引擎，最多不超过 5 个。
3. **交叉验证**: 当两个引擎的分析结论出现冲突时，优先执行跨引擎协同分析而非简单取舍。
4. **领域自限**: 每个引擎的适用范围受其方法论边界约束，不得将领域特有框架不加转化地应用于其他领域。

## 4. 引擎内部结构规范

每个领域引擎文件遵循统一结构：

```
# 引擎标题
> 元数据（版本、标识、职责）

1. 核心分析框架
   - 维度一至维度N（方法论展开）
2. 关键争议与前沿问题
3. 经典案例库（含分析要点）
4. 对认知流水线的特殊要求
```

## 5. 维护原则

- 新增引擎必须符合统一模板结构
- 引擎版本与框架版本同步
- 过时或不活跃的引擎应在索引中标注弃用但保留文件供追溯
