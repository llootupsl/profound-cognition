# 文章原型自动判定

## 概述

在 Phase 0 初始化中，当 output_type == 'wechat_article' 时，Orchestrator 根据用户输入自动判定五种公众号文章原型，将结果注入 T00 大纲生成，实现原型感知的差异化输出。

---

## 五原型判定逻辑

### 原型1：调查实验型 (investigative_experiment)

**判定信号（满足任2条即触发）：**
- 用户输入包含亲自下场信号：`我试了`、`我测试`、`我买了`、`我亲手`、`我实验`、`我用了X个月`、`亲测`、`实测`
- 用户描述了一个有时间线的亲自实验过程
- 用户输入包含对比测试意图：`A vs B`、`对比`、`横向测评`
- 研究对象为具体产品/服务，且用户声称有第一手体验

**大纲结构权重：**
- 过程叙事：40%（时间线 + 实验设置 + 过程细节）
- 发现递进：30%（逐步揭示发现，设置悬念）
- 结果分析：30%（数据总结 + 意外发现 + 反思）

### 原型2：产品体验型 (product_experience)

**判定信号（满足任2条即触发）：**
- 研究对象为具体产品/工具/服务
- 用户描述中包含体验词：`体验`、`使用感受`、`上手`、`试用`
- 用户输入中没有亲自实验信号但有使用体验（区别于调查实验型）
- 用户关注点偏向主观感受而非客观数据

**大纲结构权重：**
- 场景演示：35%（什么场景下使用、解决了什么问题）
- 真实感受：30%（好的、不好的、意外的地方）
- 对比分析：25%（与其他同类产品对比）
- 结论建议：10%（适合谁、不适合谁）

### 原型3：现象解读型 (phenomenon_interpretation)

**判定信号（满足任2条即触发）：**
- 用户输入描述了一个现象/趋势/社会观察
- 用户意图包含解读词：`为什么`、`背后`、`解读`、`分析原因`、`怎么看`
- 研究对象非具体产品，而是抽象概念或社会现象
- 用户表达了好奇心驱动的探索意图

**大纲结构权重：**
- 现象锚定：15%（精准描述现象，引起共鸣）
- 好奇心展开：15%（为什么这个现象值得关注？）
- 深层研究：40%（数据、案例、跨域分析）
- 哲学升维：30%（从现象到本质，从个案到规律）

### 原型4：工具分享型 (tool_sharing)

**判定信号（满足任2条即触发）：**
- 用户输入涉及工具/Prompt/方法论/资源的分享
- 用户意图包含分享词：`分享`、`推荐`、`发现了好东西`、`安利`
- 用户提到具体的效率提升或痛点解决
- 输出意图是帮助他人而非展示自我

**大纲结构权重：**
- 个人故事：20%（如何发现这个工具的，痛点到解决方案）
- 工具展示：40%（核心功能演示 + 使用场景 + 效果数据）
- 效果惊艳：30%（实际效果展示、数据前后对比）
- 使用指引：10%（快速上手步骤、注意事项）

### 原型5：方法论分享型 (methodology_sharing)

**判定信号（满足任2条即触发）：**
- 用户输入涉及系统性教学意图：`如何做`、`经验总结`、`N条心得`、`方法论`、`框架`
- 用户声称有系统性的经验积累（非一次性体验）
- 输出结构偏向教程/指南风格
- 用户表达了"教会他人"而非"展示自己"的意图

**大纲结构权重：**
- 谦逊铺垫：10%（我是怎么走上这条路的、踩过的坑）
- 方法展开：60%（每节 = 观点 + 案例 + 行动 + 学习曲线）
- 总结升华：20%（提炼核心原则）
- 行动回扣：10%（读者今天就能做的事）

---

## 判定冲突裁决

当多个原型的判定信号同时触发时，按以下优先级裁决：

```
调查实验型 > 工具分享型 > 产品体验型 > 现象解读型 > 方法论分享型
```

若有亲自实验信号 → 调查实验型（最高优先级，因为是第一手数据）
若仅有工具推荐信号 → 工具分享型
若仅有产品体验信号 → 产品体验型
若为抽象现象分析 → 现象解读型
若为系统性教程 → 方法论分享型

默认（无法判定时）：现象解读型

---

## Phase 0 集成

在 Phase 0 中（T01 完成后、T00 执行前），Orchestrator 执行以下判定：

1. 若 output_type == 'wechat_article'，执行文章原型判定
2. 将判定结果注入:

   ```yaml
   context_package:
     article_archetype: "investigative_experiment|product_experience|phenomenon_interpretation|tool_sharing|methodology_sharing"
     article_archetype_signals: ["触发的判定信号列表"]
     article_archetype_confidence: 0.0-1.0
   ```

3. T00 大纲生成时读取 article_archetype，按对应权重结构生成差异化大纲
