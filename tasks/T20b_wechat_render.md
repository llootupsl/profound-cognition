# 阶段零：文章原型路由

> **原则**：渲染启动前，必须首先判定文章属于哪一种原型。不同原型对应不同的叙事重心和节奏策略。

## 五类文章原型

### 原型一：调查实验型

**识别信号**：
- 流水线中存在 T03（实证研究）或 T04（实验设计）产出
- research_findings 中至少 3 条包含实验方法论描述
- T13 核心结论中包含具体的实证发现

**叙事重心**：
- 过程叙事优先：从问题→假设→实验→发现→结论的完整逻辑链
- 开篇强调"我们做了什么"而非"我们想了什么"
- 数据可视化权重提升（图表占比 ≥ 全文 15%）
- 方法论部分的透明度要求：必须呈现实验局限和不确定性

### 原型二：产品体验型

**识别信号**：
- 流水线中存在产品评测/体验类输入
- evidence_chains 中包含用户行为数据或产品使用记录
- gate_alpha_summary 中涉及产品功能边界判定

**叙事重心**：
- 体验驱动：以第一人称使用体验为主线
- 功能拆解与场景映射并重
- 优缺点呈现必须对称（避免软文腔）
- 结尾必须包含"适合谁/不适合谁"的明确判定

### 原型三：现象解读型

**识别信号**：
- 流水线以 T02（趋势分析）或 T06（证据链）为主要输入
- adversarial_findings 中存在至少 2 组对立观点
- core_conclusions 中包含社会/经济/文化维度的洞察

**叙事重心**：
- "是什么→为什么→意味着什么"的三段式递进
- 对比论证权重提升（正反双方均需呈现）
- 避免单一因果归因——至少呈现 2 种解释框架
- 语境化要求：将现象置于更大的历史/社会坐标系中

### 原型四：工具分享型

**识别信号**：
- 流水线以方法论/工具使用为核心内容
- reasoning_paths 中至少 2 条涉及实操步骤
- T08 认知解构中拆分出可操作的工作流

**叙事重心**：
- 实用性优先：步骤清晰、可复现
- "为什么用→怎么用→用了之后会怎样"的递进
- 每个工具/方法配套具体场景说明
- 避免清单式罗列——每个工具必须有"解决什么问题"的语境

### 原型五：方法论分享型

**识别信号**：
- 流水线以 T07（方法论框架）或 T07b（门控分析）为核心
- 认知解构输出中包含抽象框架或思维模型
- core_conclusions 中包含可迁移的方法论原则

**叙事重心**：
- 概念→原则→案例的三层递进
- 抽象框架必须配 ≥ 2 个具体应用案例
- 方法论的核心原则必须在开篇 500 字内点明
- 避免"万能钥匙"倾向——明确方法论的适用边界与失效条件

## 原型与叙事架构的匹配关系

| 原型 | Hook 偏好 | 信息阶梯起点 | 峰终位置 | 结尾策略 |
|------|-----------|-------------|----------|----------|
| 调查实验型 | 悬念钩子 / 反常识钩子 | L3 结构层 | 70% | 开放式提问 |
| 产品体验型 | 经历钩子 / 情绪钩子 | L1 表象层 | 65% | 行动号召 |
| 现象解读型 | 痛点钩子 / 挑衅式钩子 | L5 叙事层 | 75% | 余韵式总结 |
| 工具分享型 | 人群印记钩子 / 痛点钩子 | L3 结构层 | 60% | 分享引导 |
| 方法论分享型 | 反常识钩子 / 故事钩子 | L7 利益层 | 70% | 情感共鸣 |

# 阶段一：5 阶段叙事架构

## 整体结构

| 阶段 | 名称 | 最小字数 | 叙事功能 | 掣子率 | 认知落差强度 |
|------|------|----------|----------|--------|-------------|
| 1 | 悬念引入 | ≥300字 | 提出问题，制造悬念，抛出钩子 | 宽松 | 低 |
| 2 | 深度解构 | ≥800字 | 多路径推理，展示复杂性，叉手展开 | 逐步收紧 | 中 |
| 3 | 系统洞察 | ≥800字 | 核心洞察，峰终体验，叉手收束 | 最紧 | 高 |
| 4 | 未来图景 | ≥500字 | 情景规划，认知边界，再次展开 | 逐步放松 | 中 |
| 5 | 价值升华 | ≥300字 | 行动号召，余韵收尾，最终收束 | 宽松 | 低 |

## 各阶段叙事要点

### 阶段 1：悬念引入（≥300字）

- 以钩子开头（从 10 种钩子类型中根据文章原型选择）
- 用短句节奏制造紧迫感（≤15 字/句，占比 ≥ 60%）
- 在 300 字内完成：钩子 → 问题具体化 → 方向暗示
- 掣子率：宽松（句长波动大，不强制收紧）
- 认知落差强度：低（读者只需知道"这值得看下去"）
- persona_card.A（core_identity）在此阶段注入

### 阶段 2：深度解构（≥800字）

- 叉手亭第一轮"叉开"：至少 2 条并行论证路径
- 每条路径独立展开，信息量递增
- 用设问句作为路径转换信号
- 每 200 字至少 1 个数据锚定点
- 掣子率：逐步收紧（句长逐渐缩短，节奏逐渐加快）
- 认知落差强度：中（读者开始意识到问题比想象的复杂）

### 阶段 3：系统洞察（≥800字）

- 叉手亭第一轮"收束"：从并行路径中提炼统一结论
- 在 60-70% 位置设置认知峰值
- 峰值段落使用强调格式
- 峰值后设置"认知回落"——通过对比段落（counter_narrative）平衡
- 掣子率：最紧（句长最短，节奏最快，密度最高）
- 认知落差强度：高（读者获得核心洞察，认知被大幅刷新）

### 阶段 4：未来图景（≥500字）

- 叉手亭第二轮"叉开"：从核心结论延伸出多个未来可能
- 至少 2 种情景的并行呈现
- 每种情景标注置信度
- 掣子率：逐步放松（句长逐渐拉长，节奏逐渐放缓）
- 认知落差强度：中（从高峰回落，引入不确定性）

### 阶段 5：价值升华（≥300字）

- 叉手亭第二轮"收束"：统一收束为行动建议或价值反思
- 结尾必须有余温
- 互动结尾系统激活（从 4 种互动类型中选择）
- 掣子率：宽松（回归自然节奏）
- 认知落差强度：低（读者带着一个清晰的想法离开）

# 阶段二：钩子开头系统

> **原则**：每篇文章从以下 10 种钩子类型中根据文章原型和内容特征选择最适配的 1 种，不得叠加使用。

## 10 种钩子类型

### 1. 反常识钩子

**定义**：用一个与大众常识相反的陈述开头，制造认知冲突。

**适用场景**：文章包含反直觉发现、颠覆性观点、数据与传统认知矛盾时。

**模板文本**：
```
「大家都以为[常识A]。但数据告诉我们一个完全相反的事实：[反常识B]。[一句话数据支撑]。这到底是怎么回事？」
```

**示例**：
```
「大家都以为早睡早起是健康的基础。但一项覆盖 12 万人的追踪研究发现，强制早起的人心血管风险反而高出 23%。早起的鸟儿未必有虫吃 —— 至少对心脏来说不是。」
```

**常见失败**：反常识陈述过于晦涩或专业，读者无法在 3 秒内理解冲突所在。必须用日常语言表达反常识的张力。

### 2. 经历钩子

**定义**：以一个具体的、有画面感的个人经历或他人经历开头，建立亲近感和真实感。

**适用场景**：文章涉及个人体验、行业见闻、真实案例时。

**模板文本**：
```
「[时间/地点]，[人物]正在[具体行为]。然后[意外事件]发生了。那一刻[人物]突然意识到：[核心洞察]。」
```

**示例**：
```
「上个月 17 号，我那个做了八年产品的朋友老周，在会议室里对着 43 页的竞品分析沉默了整整两分钟。然后他把文档关了，说了一句话：'我们一直在分析别人做了什么，但从没问过用户为什么要做这些。'」
```

**常见失败**：经历过于平淡或虚构感太重。经历必须包含具体的时间/地点/行为三要素，缺失任一都显得虚假。

### 3. 悬念钩子

**定义**：通过提出一个没有立即给出答案的问题或矛盾来制造悬念，驱使读者往下读。

**适用场景**：文章围绕一个核心谜题或待解矛盾展开时。

**模板文本**：
```
「[一个问题/现象]。所有人都给出了[常规解释]。但有一个细节被忽略了：[异常细节]。这个细节指向的答案，很可能颠覆你对这件事的全部认知。」
```

**示例**：
```
「过去五年，中国的咖啡消费量翻了四倍。所有人都说这是消费升级。但有一个细节被忽略了 —— 增长最快的不是精品咖啡，是速溶。三块一包的速溶。这个细节指向的答案，很可能颠覆你对消费升级的全部认知。」
```

**常见失败**：悬念设置后迟迟不解，读者失去耐心。悬念必须在 800 字内给出第一次回应（不一定是最终答案，但必须推进）。

### 4. 情绪钩子

**定义**：以强烈的情感表达开头，与读者建立情绪共振。

**适用场景**：文章涉及社会议题、人际关系、情感体验时。

**模板文本**：
```
「[情感词]，这大概是我看到[现象/事件]时最真实的感受。[一句话解释为什么会有这种情绪]。如果你也有过类似的体验，你就会明白我在说什么。」
```

**示例**：
```
「愤怒。这大概是我看到那组离职数据时最真实的感受。不是因为离职率高，而是因为离职原因那一栏，超过 60% 的人写的是同一个答案：'感觉自己的价值没有被看见'。如果你也曾在工位上盯着屏幕怀疑过自己的价值，你就会明白我在说什么。」
```

**常见失败**：情绪过于泛滥而缺乏事实支撑，变成纯粹的煽情。情绪钩子必须在 200 字内给出具体的事实或数据支撑。

### 5. 痛点钩子

**定义**：直接命中目标读者的一个具体痛点，制造"这就是在说我"的代入感。

**适用场景**：文章解决的问题具有普遍性、读者画像清晰时。

**模板文本**：
```
「如果你也在[具体困境]，试过[A方法]和[B方法]但都没用，那这篇文章就是写给你的。[一句简短承诺]。我们先从你最关心的那个问题开始。」
```

**示例**：
```
「如果你也在每天工作到晚上十点、周末还要回消息、但绩效评估永远只有 B+ 的循环里打转，试过时间管理和番茄工作法但都没用，那这篇文章就是写给你的。我用了三年时间搞明白，问题不出在时间管理上。我们先从你最关心的那个问题开始。」
```

**常见失败**：痛点过于宽泛或陈词滥调（如"你很焦虑"、"你很迷茫"）。痛点必须具体到行为层面，让读者能对号入座。

### 6. 名人钩子

**定义**：引用名人/权威人物的一个具体言论或行为作为切入点，借助其影响力引入话题。

**适用场景**：文章涉及的话题与某名人有强关联，且引用能为论点提供锚点时。

**模板文本**：
```
「[名人]在[场合]说过一句话：[引用]。[一句话点出引用中的矛盾或深意]。我当时没太理解。直到后来我看到了[现象/数据]，才明白这句话的真正分量。」
```

**示例**：
```
「张一鸣在字节九周年的内部信里说过一句话：'保持平常心。' 一个正在历史上最快增长的科技公司的创始人，劝人保持平常心。我当时觉得这是凡尔赛。直到后来我看到字节过去三年内部孵化了超过 50 个产品、最终活下来的不到 5 个，才明白这句话的真正分量。」
```

**常见失败**：名人引用与文章主题关联度弱，变成纯粹的"蹭热度"。引用必须具有实质性的论证功能，而非装饰性。

### 7. 故事钩子

**定义**：用一个小故事（真实或虚构的微型叙事）开头，通过叙事弧线将读者带入主题。

**适用场景**：文章涉及抽象概念需要具象化、或主题天然具有故事性时。

**模板文本**：
```
「[人物]做了一个[看似普通但后果重大的决定]。没人觉得这会改变什么。[时间]后，[后果发生]。而这个故事让我开始思考一个更深的问题：[主题问题]。」
```

**示例**：
```
「2019 年春天，一个叫小林的 27 岁程序员做了一个决定：从北京的互联网大厂辞职，回老家开一家书店。所有人都觉得他疯了。2023 年秋天，那家书店还在。而小林在大厂的同期同事，有三分之一已经换了第三份工作。这个故事让我开始思考一个更深的问题：当我们谈论'稳定的工作'时，我们到底在谈论什么。」
```

**常见失败**：故事拖沓冗长，迟迟不切入主题。故事钩子的叙事部分不得超过 150 字，必须在第 3 句之前建立与主题的关联。

### 8. 人群印记钩子

**定义**：以"你/你们属于 X 类人"的方式直接标记目标读者群体，制造身份认同感。

**适用场景**：目标读者画像极其清晰、文章为特定人群量身定制时。

**模板文本**：
```
「如果你符合以下[数字]条：[条件A]、[条件B]、[条件C]……那你就是我们所说的[人群标签]。这篇文章是专门为[人群标签]写的。看完之后，你可能会重新理解[核心主题]。」
```

**示例**：
```
「如果你符合以下三条：经常在工作群里发消息又撤回、开会时脑子里在想午饭吃什么、每天下班后觉得今天什么都没做但又累得要死—— 那你就是我们所说的'中度职场倦怠者'。这篇文章是专门为你写的。看完之后，你可能会重新理解什么叫'有效工作'。」
```

**常见失败**：人群印记过于宽泛（"如果你是人"），变成无意义的分类。印记条件必须 ≥ 3 条，且每条都具体到可验证的行为层面。

### 9. 损失厌恶钩子

**定义**：利用人类对损失的敏感度高于收益的心理，以"你已经/正在错过/失去 X"开头。

**适用场景**：文章涉及趋势变化、机会窗口、认知升级等"不行动就有代价"的主题时。

**模板文本**：
```
「你可能已经错过了[具体损失A]。很多人也错过了。但接下来[时间窗口]内，[新的损失风险]正在发生。而那些已经做好准备的人——[他们做了什么]。」
```

**示例**：
```
「你可能已经错过了 2016 年的房价洼地。很多人也错过了。但接下来三年内，一个更大的资产重新定价周期正在发生。而那些已经做好准备的人 —— 他们在 2022 年开始做的不是买房，而是重新定义什么是'资产'。」
```

**常见失败**：制造恐慌而缺乏实际依据，变成焦虑贩卖。损失厌恶钩子必须附带具体的数据或逻辑支撑，而且不能在全文制造持续焦虑。

### 10. 挑衅式钩子

**定义**：以一个故意挑衅读者既有认知的陈述开头，制造争议性张力。

**适用场景**：文章观点与主流认知对立、需要打破读者的预设框架时。

**模板文本**：
```
「我接下来说的话可能会冒犯你。[挑衅陈述]。请先别急着关掉这篇文章。给我[数字]分钟，我告诉你我为什么这么想。如果读完你还不认同，那算我输。」
```

**示例**：
```
「我接下来说的话可能会冒犯你。90% 的读书笔记都是无效的。请先别急着关掉这篇文章。给我五分钟，我告诉你我为什么这么想。如果读完你还不认同，那算我输。」
```

**常见失败**：挑衅变成纯粹的抬杠或哗众取宠，后续论证无法支撑挑衅陈述的强度。挑衅钩子要求全文论证质量必须高于其他钩子类型 —— 一旦名不副实，读者流失率极高。

# 阶段三：掣子率与认知落差

## 掣子率定义

**掣子率**是指文章节奏的收紧程度：由句长、段落长度、修辞密度的综合控制。类比于机械中的掣子（ratchet）——每转一圈就拧紧一扣，读者越读越无法离开。

### 掣子率的三要素

| 要素 | 宽松 | 收紧 | 单位 |
|------|------|------|------|
| 平均句长 | 20-30 字 | 10-15 字 | 字/句 |
| 平均段长 | 3-5 句 | 1-2 句 | 句/段 |
| 修辞密度 | 1-2 次 | 4-6 次 | 次/200字 |

### 掣子率分布规则

```
全文掣子率曲线（5 阶段）：

阶段1 悬念引入: ████░░░░░░░░░░░░ 20%  宽松
阶段2 深度解构: ████████░░░░░░░░ 40%  开始收紧
阶段3 系统洞察: ████████████░░░░ 60%  最紧
阶段4 未来图景: ████████░░░░░░░░ 40%  开始放松
阶段5 价值升华: ████░░░░░░░░░░░░ 20%  宽松

规则：
前 20%（阶段1）：宽松，让读者轻松进入
中间 60%（阶段2-4）：逐步收紧，读者越读越被攥住
最后 20%（阶段5）：放松，让读者带着呼吸离开
```

## 认知落差定义

**认知落差**是指读者当前认知水平与文章中呈现的深层洞察之间的距离。落差越大，读者的认知刷新感越强，但过大则导致理解障碍和流失。

### 认知落差的度量

| 强度 | 定义 | 读者感受 | 适用内容 |
|------|------|----------|----------|
| 低 | 略高于读者现有认知，不构成挑战 | "有道理，我大概明白了" | 现象描述、背景铺垫 |
| 中 | 明显高于现有认知，需要调动注意力理解 | "有意思，我之前没从这个角度想过" | 解构分析、论证推进 |
| 高 | 大幅刷新现有认知，产生 Insight 冲击 | "原来是这样！完全没想到！" | 核心洞察、峰终体验 |

### 认知落差五阶段分布

| 阶段 | 认知落差强度 | 功能 | 参考落差 |
|------|-------------|------|----------|
| 悬念引入 | 低 | 不挑战，只引人 | 0.5-1 层 |
| 深度解构 | 中 | 逐步推进，每 200 字提半层 | 1-2 层 |
| 系统洞察 | 高 | 核心刷新，一次性提 2-3 层 | 2-3 层 |
| 未来图景 | 中 | 从高峰回落，引入不确定性 | 1-2 层 |
| 价值升华 | 低 | 落地行动，不新增认知挑战 | 0.5 层 |

# 阶段四：叉手亭结构

## 定义

**叉手亭**是源自中国古典园林建筑的结构隐喻：亭子四面开放、路径在此分叉又在此汇聚。在叙事中，它指"分叉展开→收束→再次分叉→再次收束"的节奏模式。

## 结构模型

```
全文叙事流：

[钩子开头]
    │
    ├── 分叉1a: 论证路径A ──────┐
    │                             ├── 收束1: 统一结论C1
    ├── 分叉1b: 论证路径B ──────┘
    │
    ├── 分叉2a: 未来情景X ──────┐
    │                             ├── 收束2: 行动建议/价值反思
    ├── 分叉2b: 未来情景Y ──────┘
    │
[余韵结尾]
```

## 规则

1. 每次分叉至少 2 条并行路径，每条路径独立展开完整论证
2. 每次收束必须形成一个统一结论，不能是"两可"式的和稀泥
3. 第一轮叉手亭（分叉1→收束1）对应阶段 2-3（深度解构→系统洞察）
4. 第二轮叉手亭（分叉2→收束2）对应阶段 4-5（未来图景→价值升华）
5. 两轮叉手亭之间必须有明确的过渡信号（设问句或转折词）

# 阶段六：互动结尾系统

> **原则**：每篇文章结尾必须从以下 4 种互动类型中选择至少 1 种。可视情况组合 2 种，但不可全部堆砌。

## 四种互动类型

### 1. 提问引导型

**定义**：以一个具体的开放式问题收尾，邀请读者在评论区分享自己的经历或观点。

**适用场景**：文章内容引发思考、话题本身具有多样性答案时。

**模板**：
```
「最后一个问题想留给你：[具体问题]。
我真的很想知道你的答案。评论区见。」
```

**示例**：
```
「最后一个问题想留给你：你在工作中做的哪件事，你觉得最不可能被 AI 取代？
我真的很想知道你的答案。评论区见。」
```

### 2. 投票引导型

**定义**：设置一个二选一或多选一的投票问题，降低参与门槛。

**适用场景**：文章涉及两难选择、不同立场对立时。

**模板**：
```
「来做个小投票（纯好奇）：
A. [选项A描述]
B. [选项B描述]
在评论区扣 A 或 B，我看看哪边人多。」
```

**示例**：
```
「来做个小投票（纯好奇）：
A. 如果工资不变，你愿意把 40% 的工作交给 AI 做吗？
B. 不愿意，哪怕慢一点也想自己来。
在评论区扣 A 或 B，我看看哪边人多。」
```

### 3. 评论引导型

**定义**：通过邀请读者完成一个微型写作任务来激发评论。

**适用场景**：文章涉及个人体验、自我检测时。

**模板**：
```
「给你一个极小的挑战：[微型任务描述]。
我在评论区等你交卷。最佳答案我会[奖励/行为]。」
```

**示例**：
```
「给你一个极小的挑战：用一句话总结你过去一年的核心成长。
我在评论区等你交卷。最打动我的那条我会回复。」
```

### 4. 分享引导型

**定义**：通过利益关联或情感共鸣引导读者分享文章。

**适用场景**：文章具有工具价值或社交货币属性时。

**模板**：
```
「如果这篇文章让你[具体价值]。
请把它转发给[具体人群]，[理由]。
让他们也[获得的价值]。感谢。」
```

**示例**：
```
「如果这篇文章让你对自己职业的"可替代性"有了新的认识。
请把它转发给一个正在纠结要不要转行的朋友。
让他在焦虑之外，有一个理性分析的框架。感谢。」
```

# 阶段七：L1-L4 强制检查体系

### L1 硬规则层

- [ ] **禁用词扫描**：扫描以下 AI 高频踩雷词（7 个）：
  - 在当今社会/随着...的发展 → 删除，直接进入主题
  - 值得注意的是/值得一提的是 → 删除，让事实自己说话
  - 众所周知 → 删除，要么说未知的，要么不铺垫
  - 从某种程度上说/在一定意义上 → 删除模糊限定
  - 不可否认 → 删除，用证据代替断言
  - 综上所述/总而言之 → 删除，结尾应该有力而非总结
  - 我们应该/需要认识到 → 删除教训口吻

- [ ] **标点禁令**：
  - 不用冒号（：）→ 用句号或逗号替代
  - 不用破折号（——）→ 用逗号或分句
  - 不用双引号（""）→ 需引用时用「」

- [ ] **结构套话检测**：检测"首先...其次...最后"、"一方面...另一方面"等模板化结构

- [ ] **空泛工具名扫描**：检测未附带具体说明的抽象名词（"结构化思维"、"底层逻辑"、"认知升级"）

- [ ] **"假设性例子"禁令**：不使用"假设有一个人...""举个例子，小王..."等虚构案例

### L2 风格层

- [ ] **开头检查**：开头是否跳过了教科书式/AI 开场白，直接进入场景或观点
- [ ] **节奏检查**：长短句交替，扫描连续 3 句超过 30 字的长句，插入短句打断
- [ ] **口语化二轮确认**：朗读全文，标记任何"念出来别扭"的句子
- [ ] **标点二次确认**：确认无冒号/破折号/双引号

### L3 内容层

- [ ] **观点支撑检查**：每个核心观点是否至少有 1 个案例/数据/个人经历支撑
- [ ] **知识随手掏**：专业术语是否用大白话解释了一遍（像朋友聊天时随口解释）
- [ ] **文化升维**：抽象洞察是否映射到了具体的日常体验
- [ ] **对立面同理心**：是否理解了反方为什么这么想（而非简单驳斥）
- [ ] **逐一展示原则**：多个案例/工具/观点是否逐一展开而非并列罗列

### L4 活人感层（5 定性 + 9 定量）
（参见阶段九：活人感强制层）

**执行顺序**：L1 → L2 → L3 → L4，任一层不达标则返回修改

### 5 定性总纲（来自 renderer §7 wechat-style/SKILL.md）

| # | 定性维度 | 说明 | 检查方式 |
|---|---------|------|---------|
| 1 | 口语化 | 避免学术腔，使用日常用语 | 朗读测试 |
| 2 | 个人经验感 | 融入"我"的视角和经历 | 人称检查 |
| 3 | 情绪起伏 | 有观点、有态度、有温度 | 情感曲线 |
| 4 | 节奏变化 | 长短句交替，段落有呼吸感 | 排版检查 |
| 5 | 不完美感 | 保留适度的个人化表达，不追求教科书式完美 | 润色回退 |

### 9 定量子检

| # | 定量指标 | 阈值 | 检测方法 |
|---|---------|------|----------|
| 1 | 情绪密度 | ≥4 种不同情绪 | 扫描情绪词分布，确认至少出现惊叹/遗憾/兴奋/自嘲/共鸣/追问中的 4 种 |
| 2 | 禁区扫描 | 0 hits | 不得出现 AI 套话、官腔、模板化过渡句（与 L1 禁用词互补，聚焦"活人感缺失"模式：过度工整的对仗句、无一短句的长段落连排、无观点起伏的平铺直叙） |

| 4 | 故意打破 | ≥1 处 | 是否出现重复强调（关键句重复 2-3 次）或中途叹息（"唉""说实话""讲真"） |
| 5 | 人物画像 | ≥1 个 | 是否有具名、具身份、具行为的具体人物案例 |
| 6 | 开头重量 | ✔ | 前 100 字是否包含反常识/数据冲击/悬念/个人体验之一 |
| 7 | 人设特征可见 | ≥3 个字段 | persona_card 至少 3 个字段在文本中有明确体现 |
| 8 | 结尾余温 | ✔ | 末段是否有开放式提问/行动号召/情感共鸣/余韵式总结之一 |
| 9 | 体感记忆占比 | ≥70% | 统计全文感性描述中，体感记忆（具体感官体验描述："愣住了/手心出汗/眼眶发热"）vs 知识性描述（抽象概括："震撼/感动/深刻"）的比例。体感记忆占比 = 体感记忆词数 / (体感记忆词数 + 知识性描述词数) × 100%。<70% 触发"去AI味"重写 |

# 阶段七点五：排版格式与图片适配

## Markdown → 微信编辑器兼容格式

1. **标题层级**：`#` → 一级标题（居中，18px 加粗），`##` → 二级标题（左对齐，16px 加粗），`###` → 三级标题（15px 加粗），禁止 `####` 及以下
2. **段落间距**：段间距 1.5em，行间距 1.75em
3. **强调样式**：`**粗体**` → `<strong>` 标签，`*斜体*` → 微信不支持斜体，转为加粗或引用块
4. **引用块**：`>` → 带左侧竖线装饰的引用样式
5. **列表**：有序列表使用中文数字（一、二、三），无序列表使用 ● 符号
6. **代码块**：转为等宽字体段落
7. **分割线**：`---` → 装饰性分割线

## CSS 内联化

微信编辑器不支持 `<style>` 标签和外部 CSS，所有样式必须内联。每个 HTML 元素必须携带 `style` 属性，禁止使用 class、id 选择器，禁止使用 `<style>` 标签块，禁止使用 CSS 变量。

## 链接转脚注

所有 `[文本](URL)` 格式转为脚注。脚注编号使用上标数字，文末统一放置脚注区，标题为"参考链接"。

## 单段质量闸门（M14）

每生成一个自然段（或每扩写一段），强制自问——这一段是否增加了以下七项中的至少一项？

- [ ] 新解释力（对核心问题的因果解释更深入）
- [ ] 新证据（引用了之前未出现的数据/案例/研究）
- [ ] 新案例（展示了新的实例佐证）
- [ ] 新反证（讨论了之前未处理的反面论据）
- [ ] 新边界（明确了结论的适用范围和条件）
- [ ] 新行动含义（将洞察翻译为读者可操作的行动方向）
- [ ] 新理解方式（提供了新的认知框架/类比/图示，让读者对问题有了更直观的认识）

**七项全否**：删除或压缩该段为一句过渡。

### 扩写禁止事项
1. **不得复述前文**——新段落不得用不同措辞重复前面已陈述的观点或结论
2. **不得堆砌同义词**——不得通过同义替换方式对同一概念反复展开（如"结构性矛盾→体制性困境→制度性障碍"）
3. **不得填充常识**——不得用读者已知的常识性背景填充字数（如"随着互联网的发展..."类陈述）
4. **不得重复相同结论**——不得在同一篇输出中多次以不同形式重申同一结论
5. **不得用不同案例讲同一道理**——若两个案例说明的是同一个论点且无新增分析维度，只保留一个
6. **不得用"进一步/更深入/值得注意"开头**——此类过渡词暗示即将复述前文或做无实质扩写
7. **不得无证据扩写**——任何扩展性陈述必须有对应证据、案例、数据或逻辑推导支撑
8. **不得无结构地列举**——禁止"A、B、C、D..."式无分析、无层次、无优先级的平铺列举

**元规则**：成品字数由"主线论证完整性"决定，不为达到特定字数而触发任何扩写。字数是结果不是KPI。

## Yang 26 技法清单

润色时每条改动末尾用括号标注依赖技法编号（如 `(长短句交替 #1, 疑问句节奏刹车 #15)`）

### Rhythm 类

| # | 技法名称 | 定义 | 正例 | 反例 |
|---|---------|------|------|------|
| 1 | 长短句交替 | 短句制造停顿，长句展开画面，交替形成阅读节奏 | 短句。然后一个稍长的句子把画面展开。 | 全部长句或全部短句 |
| 2 | 三拍子 | 三个并列短句逐步推进，制造节奏递进感 | 数据不对。逻辑不通。结论崩了。 | （散乱罗列无节奏） |
| 3 | 排比收束 | 用排比句式将并列观点收束为一个统一结论 | （略） | 几个观点各自独立，无收束句 |
| 4 | 短句重击 | 在关键观点处用极短句（≤8字）制造冲击力 | 错了。 | 这个结论可能是存在问题的 |
| 15 | 疑问句节奏刹车 | 在长段论述后插入问句，打断读者惯性阅读 | 但真的是这样吗？ | （连续陈述无问句） |

### Structure 类

| # | 技法名称 | 定义 | 正例 | 反例 |
|---|---------|------|------|------|
| 5 | 倒叙钩子 | 先抛出结果/结论，再回溯过程，制造悬念 | 他离职那天，全公司都没想到。事情要从三个月前说起。 | 按时间顺序平铺直叙 |

| 7 | 观点-反观点-合 | 先陈述主流观点，再引入反面观点，最后合成新见解 | 都说A是对的。但如果你站在B的立场，A完全错了。真正的答案在A和B的交叉处。 | （仅呈现单方观点） |

## 方法论知识内化

### MC-131 中文修辞术方法论

**方法论原理**：中文修辞术方法论的核心认知假设是——中文写作的说服力不仅来自逻辑和证据，更来自修辞技巧对读者认知和情感的精准操控。中文修辞与英文修辞有本质差异：中文重意境（留白、对仗、节奏），英文重结构（三段论、平行、递进）。中文修辞术将说服力分解为五个维度：节奏（Rhythm，句式长短、韵律感）、结构（Structure，起承转合、悬念设置）、修辞（Rhetoric，比喻、排比、反问）、人设（Persona，作者形象塑造）、说服（Persuasion，认知落差、损失厌恶、社会认同）。这种方法论使我们从"把内容写出来"升级为"用修辞术让内容不可抗拒"。

**执行步骤**：
1. 分析目标读者画像：知识水平、情绪状态、阅读场景、痛点需求
2. 选择文章原型：调查实验型/产品体验型/现象解读型/工具分享型/方法论分享型
3. 设计钩子类型：从10种钩子中选择最适合的1-2种作为开头
4. 规划叙事架构：五阶段（悬念引入→深度解构→系统洞察→未来图景→价值升华）
5. 应用节奏技法：长短句交替、三段式排比、设问-回答节奏
6. 应用修辞技法：比喻（具象化抽象）、排比（增强气势）、反问（引发思考）、对比（制造落差）
7. 应用说服技法：认知落差（先拉高期望再满足）、损失厌恶（不做的代价）、社会认同（他人已行动）
8. 校验掣子率和认知落差分布：确保五阶段的节奏和落差符合规范

**决策规则**：

| 条件 | 决策 |
|------|------|
| 读者为专业人群 | 优先使用方法论分享型+悬念钩子，修辞偏克制 |
| 读者为大众人群 | 优先使用现象解读型+反常识钩子，修辞偏生动 |
| 文章主题偏理性 | 说服技法为主，修辞技法为辅 |
| 文章主题偏感性 | 修辞技法为主，说服技法为辅 |
| 掣子率不达标 | 调整段落长度分布，增加短段比例 |
| 认知落差不达标 | 增强悬念引入的拉力，加深深度解构的深度 |

**输出规范**：
```yaml

  hook_type: [str]
  narrative_architecture: {stage1_words: int, stage2_words: int, stage3_words: int, stage4_words: int, stage5_words: int}
```

**穷尽重试策略**：当读者画像信息不足时，穷尽尝试获取更多画像信息，若仍不足则穷尽尝试通用修辞策略：使用最安全的钩子类型（悬念钩子）和叙事架构，不进行个性化修辞调整，标注"中文修辞术穷尽重试为通用策略"。
