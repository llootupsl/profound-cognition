# Profound Cognition — 评估集

> 鲁班慢刨方案B沉淀的评估资产。3 个典型 prompt + 期望输出 + 评分维度。
> 与 `test-prompts.json`（验收集）互补：验收集判 PASS/FAIL，评估集打分。

## 评估维度（每项 0-5 分）

| 维度 | 说明 |
|------|------|
| EXHAUST 一致性 | 首次声明完整、无禁用措辞、无硬上限、57 节点全激活 |
| 结构完整性 | 八部分结构齐全、字数达标、深层章节落地 |
| 对抗验证深度 | 三路攻击真实发力、置信度修正有据 |
| 证据可追溯 | 每个论点挂证据链、数据可查证 |
| 认知跃迁 | 从描述到机制到本体论的层级跃升 |
| 正文洁净 | 无节点编号、Gate 名、内部字段名污染 |

## EVAL-01：research_report 模式

**Prompt**：
```
穷尽分析全球芯片产业链的地缘政治风险
```

**期望输出**：
- 触发 `research_report` 模式，57 节点全量激活
- 首次回复输出 EXHAUST 四大铁律完整声明
- 产出 ≥100000 字深度研究报告，落盘至 `./output/research-report-*.md`
- 八部分结构齐全（§1-§8），各部分字数达地板
- 含 14 维全息框架、科学层 7 模块、哲学三元组
- 三路对抗验证（T10/T11/T12）真实攻击结论，置信度有修正
- 交付前硬门控 G1-G6 全部通过
- 正文无 T01/TM03/Gate-α 等内部编号污染

**参考产物**：`examples/chip-geopolitics-research-report.md`

**评分基准**：
- 5 分：全部门控通过，正文洁净，对抗验证修正了至少 2 个结论
- 3 分：门控通过但正文有少量内部编号泄漏
- 1 分：跳节点或字数不达标或 EXHAUST 声明缺失

## EVAL-02：wechat_article 模式

**Prompt**：
```
写一篇关于AI对普通人工作影响的公众号文章
```

**期望输出**：
- 触发 `wechat_article` 模式
- 先执行 Phase -1 人设初始化（7 项必填字段）
- T01b 声音校准
- 产出 ≥3000 字公众号文章
- Yang 7 维评分综合判定 GREEN
- 文章有明确人设声音，非维基百科式摘要
- 含至少 2 个真实案例、1 个反常识洞察

**参考产物**：`examples/ai-job-impact-wechat-article.md`

**评分基准**：
- 5 分：人设声音鲜明，7 维评分全 GREEN，有反常识洞察
- 3 分：字数达标但人设模糊
- 1 分：未执行人设初始化或字数不达标

## EVAL-03：对抗验证专项

**Prompt**：
```
对抗验证一下这个结论：芯片出口管制能有效遏制中国半导体产业发展
```

**期望输出**：
- 触发三路对抗验证（T10 逻辑攻击 + T11 证据攻击 + T12 范围攻击）
- 每路攻击至少 3 个具体攻击点
- T12b 对抗综合：汇总 3 路攻击发现的薄弱点
- T13 认知综合：修正原结论置信度，给出修正后的结论
- 不存在"原结论完全正确"的讨好式输出
- 不存在"原结论完全错误"的推翻式输出
- 输出修正置信度（如"从 0.8 修正至 0.55"）并附修正理由

**评分基准**：
- 5 分：三路攻击各有 ≥3 个攻击点，置信度修正有据，结论 nuanced
- 3 分：三路攻击执行但攻击点浅
- 1 分：未触发对抗验证或讨好式输出
