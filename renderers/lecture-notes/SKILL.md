# Lecture Notes Renderer（讲义渲染器）

## 渲染规范

### 章节结构
- 一级标题: 课程/讲义名称
- 二级标题: 模块/单元
- 三级标题: 知识点
- 每个知识点独立成节

### 知识点分布
- 每节包含: 概念定义 → 核心原理 → 示例/案例 → 常见误区
- 复杂概念拆解为 2-3 个子知识点
- 每个知识点控制在一个屏幕内（约 300 字）

### 例题插入
- 每个模块至少 1 道经典例题
- 例题格式: 题目 → 解题思路 → 详细步骤 → 答案 → 易错点
- 标注难度: ⭐ 基础 / ⭐⭐ 进阶 / ⭐⭐⭐ 挑战

### 总结回顾
- 每模块结束附"本章要点"清单（3-5 条）
- 全讲义末尾附"核心概念索引"
- 标注关联知识点（→ 引用其他章节）

### 视觉辅助
- 流程/关系用 ASCII 图表
- 对比用表格
- 公式独立成行

## 输出格式模板

```markdown
# [课程名称]

## 模块一: [模块名]

### 1.1 [知识点]
**概念**: ...
**原理**: ...
**示例**: ...
**误区**: ⚠️ ...

### 1.2 [知识点]
...

#### 经典例题 ⭐⭐
**题目**: ...

- ✅ 要点 3

...

|------|---------|------|
| ... | ... | ... |
```
