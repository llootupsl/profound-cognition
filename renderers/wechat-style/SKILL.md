# 微信公众号文章风格写作协议

## 一、8+1 类钩子框架

公众号文章开篇必须使用以下钩子类型之一捕获读者注意力：

### 核心钩子（8类）
| 钩子类型 | 适用场景 | 示例模式 |
|---------|---------|---------|
| 情感钩子 | 个人成长、关系、心理 | "你有没有过这样的时刻..." |
| 认知钩子 | 知识科普、行业分析 | "90%的人都不知道的真相..." |
| 悬念钩子 | 故事、案例 | "直到最后一刻，我才明白..." |
| 反转钩子 | 观点文章、评论 | "你以为X，其实是Y" |
| 共鸣钩子 | 职场、生活、社会 | "这届年轻人太XX了" |
| 紧迫钩子 | 时效性内容 | "就在昨天，X发生了..." |
| 权威钩子 | 专业分析 | "研究了X个案例后发现..." |
| 稀缺钩子 | 独家观点 | "很少有人谈到的X真相" |

### 增强钩子（+1类）
| 钩子类型 | 适用场景 | 示例模式 |
|---------|---------|---------|
| 冲突钩子 | 争议话题 | "X和Y，到底谁是对的？" |

## 二、信息阶梯（Information Ladder）

正文按信息阶梯组织，确保阅读流畅性：

```
L1 钩子（开篇） → L2 背景铺垫 → L3 核心论点 → L4 证据展开 → L5 观点升华 → L6 行动号召
```

每层过渡需自然，使用过渡句而非生硬分段。

## 三、峰终定律（Peak-End Rule）

- **峰值**：文章中部安排一个"认知高峰"——最核心的洞察或最有力的案例
- **终值**：结尾用金句或行动号召收束，给读者留下强记忆锚点

## 四、传播张力

以下元素增强文章传播性：
- 反常识观点（需有数据支撑）
- 故事化案例（避免纯说教）
- 可引用的金句（每500字至少1句）
- 互动引导（文末提问或投票）

## 五、行动号召（CTA）

文末必须包含以下之一：
- 关注引导
- 转发话术提示
- 留言互动邀请
- 相关阅读推荐

## 六、字段消费规则（Yang's 12 字段系统，附 A-J 旧版对照）

渲染时需消费 persona_card 12 字段 + 2 derived_from 字段：

### persona_card 字段消费规则

| 字段 | 字段名（A-J 别名） | 消费方式 |
|------|-------------------|----------|
| 1 | identity (→A_core_identity) | 在开头 Hook 中体现身份视角："作为一个[identity]…" |
| 2 | core_values (→B_core_values) | 在价值判断段落中体现立场倾向：开放/保守/批判/建设/中立/激进/务实/理想 |
| 3 | personal_stories (→C_personal_stories) | 在叙事段落中自然引用个人经历片段，clarity_status='完整'的故事优先使用 |
| 4 | catchphrase (→D_verbal_tics) | 在文本中自然嵌入 2-3 个标志性表达 |
| 5 | emotion_expression (→I_emotional_expressions) | 在情感表达处使用指定表达方式：克制/适度/丰富/强烈/内敛/外放/层次/爆发 |
| 6 | self_deprecation | 在自省/转折段落中使用指定自嘲风格：无/轻微/适度/明显/频繁/点睛/反差/贯穿 |
| 7 | knowledge_zones (→E_knowledge_breadth) | 在相关领域段落中自然展露专业深度 |
| 8 | cultural_refs | 在类比和比喻中引用用户指定的文化参照系 |
| 9 | humor_style | 控制全文幽默元素的类型和密度 |
| 10 | reader_name (→H_reader_name) | 调整对读者的称呼方式，控制亲疏距离感 |
| 11 | ending_pref | 选择结尾策略：开放式提问/行动号召/情感共鸣/余韵式总结/分享引导 |
| 12 | style_ref (→F_writing_style_ref) | 选择叙事主线：故事驱动/数据驱动/逻辑驱动/情绪驱动/混合 |
| ★ | communication_style (derived) | 全文措辞基调对齐：正式/轻松/犀利/温和/幽默/讽刺/热情/冷静 |
| ★ | emotional_baseline (derived) | 全文情绪底色对齐：理性/热血/冷静/温暖/悲观/乐观/矛盾/沉稳 |

## 七、L4 活人感 5 项定性指标

| 指标 | 说明 | 检查方式 |
|------|------|---------|
| 口语化 | 避免学术腔，使用日常用语 | 朗读测试 |
| 个人经验感 | 融入"我"的视角和经历 | 人称检查 |
| 情绪起伏 | 有观点、有态度、有温度 | 情感曲线 |
| 节奏变化 | 长短句交替，段落有呼吸感 | 排版检查 |
| 不完美感 | 保留适度的个人化表达，不追求教科书式完美 | 润色回退 |

## 八、Moka 卡片选择规则

基于人设 `identity`（即 A_core_identity）选择对应的 Moka 卡片风格：

| identity | Moka 卡片风格 | 配色 |
|----------|-------------|------|
| 学者型 | 简约学术卡 | 黑白灰 + 单点缀色 |
| 实践者型 | 案例拆解卡 | 暖色调 + 数据可视化 |
| 叙事者型 | 故事流卡 | 柔和渐变 + 手写体点缀 |
